## 根因分析

### 候选根因 #1（置信度：high）

鸿蒙应用在“新建本地草稿并发送第一条消息”这一具体操作中，构造了 0.0.334 新增的 `kind: start` 会话命令。该命令把消息放在 `input` 内且没有顶层 `delivery`；服务器仍运行 0.0.333，旧处理器把请求当作扁平会话输入解析，并在检查顶层 `delivery` 时直接返回 400 `Missing delivery`。

**证据：**

- Nginx 四次记录同一 `/inputs` 请求均为 HTTP 400，且响应长度均为 72 字节。
- `{"ok":false,"error":{"code":"BAD_REQUEST","message":"Missing delivery"}}` 的 UTF-8 长度精确为 72 字节；同处理器其他 400 响应长度均不同。
- 鸿蒙当前源码在草稿首条消息路径构造 `kind: start`，协议定义明确表明 `start` 不含 `delivery`。
- 服务器实测 `xopc --version` 为 0.0.333；该版本 `/inputs` 路由仍调用 `submitSessionInput` 并要求顶层 `delivery`。
- 0.0.334 源码已将该路由切换为 `handleSessionCommand`，能解析 `kind: start`。
- 当前新协议相关定向测试通过：3 个测试文件、6 个用例全部通过。

**证据来源：**

- `runtime_log`: `/var/log/nginx/qm.xopc.io.access.log`
- `runtime_log`: `diagnosis/mem_buffer_20260927_162507.txt`
- `code`: `apps/mobile-harmony/entry/src/main/ets/repository/chatRepository.ets`
- `code`: `packages/gateway-contract/src/session-input-command.ts`
- `code`: Git 提交 `ec24f3176`（0.0.333）中的 `src/gateway/hono/routes/session-input-handler.ts`
- `code`: Git 提交 `a70da5e4c`（0.0.334）中的 `src/gateway/hono/routes/agent-stream.ts`

### 候选根因 #2（置信度：high）

部署时 npm 最新版仍是 0.0.333，而当前鸿蒙包使用的是随后合入的嵌入式草稿协议，形成客户端与服务器的发布版本偏差；DNS、TLS、Nginx、CORS、配对和认证链路不是本次故障点。

**证据：**

- 请求通过 HTTPS/HTTP2 到达认证后的 `/api/sessions/:id/inputs` 业务路由，服务端返回确定的业务校验 400，而不是连接、跨域或认证错误。
- npm 0.0.334 的发布时间为 2026-09-27 08:22:06 UTC，晚于服务器安装 0.0.333；新会话协议支持随 0.0.334 发布。

**证据来源：**

- `code`: xopc 0.0.333 与 0.0.334 发布提交差异

## 修复建议

### 针对候选根因 #1

1. 将服务器 `@xopcai/xopc` 从 0.0.333 升级至 0.0.334，并重启 `xopc-gateway.service`。
2. 确认 `xopc --version` 输出 0.0.334，且 systemd 服务状态为 active。
3. 使用鸿蒙端重新新建会话并发送第一条消息；预期 `/inputs` 返回 202，不再出现 72 字节的 `Missing delivery`。
4. 检查 Nginx access log、Gateway 日志和会话列表，确认会话已创建且输入已进入队列。
5. 若失败，保留同一 `clientMessageId` 重试并核对 0.0.334 的 receipt；不要回退客户端协议字段。

**参考文档：**

- https://www.npmjs.com/package/@xopcai/xopc/v/0.0.334

### 针对候选根因 #2

1. 后续移动端发布与 Gateway 发布使用同一个兼容版本基线，升级顺序优先 Gateway、后客户端。
2. 在移动端连接成功后增加 Gateway 协议版本/能力检测；版本不兼容时直接提示升级服务器，避免把协议不兼容表现为泛化的“400”。
3. 在部署流程中记录已安装的精确 xopc 版本，避免使用发布时间交界处的隐式 `latest`。

**参考文档：**

- https://www.npmjs.com/package/@xopcai/xopc

# Product

## Register

product

## Users

Solo builders, independent operators, and technical knowledge workers using xopc as a personal AI workstation. They are usually inside a focused work session: chatting with agents, managing sessions, configuring channels, reviewing logs, tuning model/provider setup, or maintaining long-running automation.

## Product Purpose

xopc Web is the gateway console for a personal AI operating system. It exists to make agent work inspectable, configurable, and repeatable without forcing users into raw config files. Success means users can understand current runtime state, adjust agent capabilities, and recover from setup issues quickly while staying in flow.

## Brand Personality

Calm, precise, restrained. The interface should feel like a quiet control surface for serious work: familiar enough to trust, dense enough for repeated use, and intelligent without performative AI decoration.

## Anti-references

Avoid marketing-page composition, decorative AI gradients, oversized hero sections, colorful dashboards, glassy panels, novelty controls, and settings pages that hide important operational state behind vague copy. Avoid preserving legacy configuration concepts when the product model has moved on.

## Design Principles

- Configuration follows the runtime model: one global Agent default plus explicit per-Agent overrides is the source of truth.
- Make operational state scannable before making it decorative.
- Prefer familiar product affordances over invented controls.
- Use blue only for primary action, selection, and AI/state signals.
- Keep migration boundaries explicit: removed legacy settings should disappear from normal workflows.

## Accessibility & Inclusion

Target WCAG AA contrast for text and controls. Support keyboard navigation, visible focus states, reduced motion, readable density controls, and clear error states. Avoid color-only communication for status, risk, or selected state.

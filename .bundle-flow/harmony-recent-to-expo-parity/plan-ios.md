# iOS implementation plan

1. Consume the same shared task/project work hierarchy, local search and status filters as Android.
2. Consume the same automation search/filter hierarchy and chat reference/thumbnail presentation.
3. Preserve iOS safe-area, VoiceOver labels, native image preview and image editing behavior.
4. Run shared tests/typecheck/lint and an iOS simulator/generic build when the installed Xcode environment permits it.

No Xcode project file change or platform-specific source is required.

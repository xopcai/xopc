## 产品接入（2026-10-03）

正式 React 组件位于 `web/src/components/brand/loopi.tsx`，弹簧动效和生命周期在 `loopi-motion.ts`，材质与暗色适配在 `loopi.css`。官网独立仓库的 `components/brand/` 保持这三个文件一致；修改后须同步并在两个项目分别构建。样稿仍用于设计探索，生产接入以 React 组件为准。

- 官网首屏循环展示倾听、好奇、专注、等待、开心，并提供轻触回应；不显示播放/暂停控件。循环仅为角色演示，不表示真实任务完成。
- Onboarding 根据真实步骤显示倾听、工作、等待确认、完成或安慰，不自动确认或推进用户操作。
- 用户理解入口与页面使用同一角色，保留用户自己的头像与身份信息。
- 侧栏头像默认静止，仅悬停、键盘聚焦时回应；其他装饰性实例入场约 4 秒后安静下来。
- 交互主角持续自然眨眼、轻微呼吸。所有实例支持系统减少动态效果、后台与离屏停止，卸载时清理监听器。
- 表情正向不旋转；圆环与核心分层响应，不重新引入气球高光或整体机械摇晃。

回归测试：`web/src/components/brand/__tests__/loopi.test.tsx`。视觉夹具：`/onboarding-visual.html?stage=setup|work|profile&mode=light|dark`。

## 造型与情绪

石墨灰长弧代表 AI 执行，蓝色短弧代表人的意图和判断。80/20 是产品愿景，不是效率承诺或真实任务进度。圆环沿用品牌源 SVG；生成图不能作为精确弧长依据。

白色核心承载表情。外圈是稳定的识别结构，内部表情可以灵活变化。正式建模保持短弧约 20%、相同圆心半径和线宽，禁止在背面额外生成脸。

材质以哑光软硅胶为主，仅有轻微透光。可爱来自眨眼、停顿、歪头和小幅弹跳，避免持续晃动、强光晕和过度反光。

倾听：“嗯，我在听。” 完成：“搞定，空出一点时间给你。” 受阻：“这里需要你帮我选一下。” 休息不发送召回提示，不通过失落、哭泣或连续签到制造负担。

## 动作规范

| 状态 | 建议动作 | 节奏 |
| --- | --- | --- |
| 待机 | 上下浮动 4px，偶尔眨眼 | 4 秒呼吸 |
| 倾听 | 核心向用户倾斜 3°，外圈稳定 | 250ms 进入 |
| 专注 | 灰色弧内微光流动，脸保持正向 | 2.4 秒循环 |
| 好奇 | 歪头 5°，眼睛短暂放大 | 400ms 后停住 |
| 等你决定 | 蓝色短弧亮起，停止任务前进 | 持续等待真实输入 |
| 完成 | 小幅上跳、笑眼，然后恢复待机 | 700ms 一次 |
| 安慰 | 轻微前倾，降低动作幅度 | 500ms 进入 |
| 休息 | 闭眼，呼吸变慢 | 6 秒循环 |

## 官网与 Onboarding

官网循环：一天原本全由人处理 → AI 逐步接手 → 保留人的判断 → 空出生活时间 → 淡出重置，建议 12–16 秒。须标注是理念演示，不能映射成虚假进度。

Onboarding：介绍 → 帮忙推进 → 等你决定 → 用户明确点击 → 完成。等待阶段不能自动通过。样稿的按钮仅控制本地演示。

默认展示轻量动态；支持暂停、系统减少动态效果、键盘操作。32px 及以下继续用纯 Logo，48–96px 使用简化平面角色；大幅官网用 3D 角色。

## 评审边界与待修正

本阶段是视觉设计和动作原型，未接入正式官网或 App，也未输出 3D 模型、骨骼或 Lottie。
预览中的角色动作是透明 PNG 的整体位移/旋转，表情变化见表情板，尚未完成面部绑定。
造型板的正面与四分之三角度差异偏小；表情板 FOCUS 的眉眼需放松，避免像生气。
分镜 YOUR CALL 的勾号需移到用户确认之后；GO LIVE 应保留灰蓝角色，只让背景进入生活场景，避免把蓝色误读成 AI。
上述生成偏差是待修稿，正式制作以此说明与源 Logo 几何为准。

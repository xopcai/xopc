# Desktop pet

The desktop app can show a small animated companion that reflects broad Agent activity such as waiting, reading, working, succeeding, or needing attention.

## Enable or choose a pet

1. Open **Settings → Pet** in the desktop app.
2. Enable the desktop pet.
3. Choose an included or installed pet.
4. Adjust its visibility and behavior settings.

The pet is an ambient status display, not a separate Agent. Its animation does not change the current task or grant new capabilities.

## Create one in Chat

Choose **Create in chat** from Pet settings, describe the character and desired style, and follow the guided authoring flow. Review the preview before using it.

Custom pets are stored under `~/.xopc/pets/` by default. Use **Refine** to adjust a custom pet without starting over.

## Privacy

Pet bubbles should show short public-safe summaries, not raw messages, tool arguments, command output, or secrets. Disable the pet on shared screens or during sensitive work.

## Troubleshooting

- Pet does not appear: confirm you are using the desktop app and it is enabled.
- Custom pet is invalid: open Pet settings and review the validation message.
- Animation looks cropped: regenerate or correct the pet package dimensions.
- Status seems delayed: verify the desktop app is connected to the active Gateway.

## Start with a real result

1. [Download the desktop app](https://xopc.ai/en#download) or follow the [terminal quick start](./first-5-minutes.md).
2. [Connect one model](./how-to/configure-first-model.md).
3. Tell xopc: **“Turn this plan into a one-page file with three next actions and open questions. Save it so I can review it.”**

**Your context, carried forward.** xopc keeps context, the next action, evidence, and follow-up together so important work does not disappear when a chat ends. [See how the Task Loop works](./concepts/loops.md).

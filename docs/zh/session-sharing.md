# 会话分享

XOPC 可以通过现有 Share 系统发布不可变、只读的 Session 快照。在会话页顶部选择“分享会话”即可创建。

## 快照边界

默认快照只包含用户和助手的可见文本。系统提示、推理内容、工具参数与结果、Shell 命令与输出、上下文审计行、工作区路径、Session Key 和模型元数据始终不会进入公开快照。

发布前，所有者可以显式选择加入：

- 工具名称及成功/失败状态；
- 单个会话附件。

被选中的附件会复制到独立的分享快照目录，公开链接不会指向原始媒体存储。附件请求必须携带与快照 revision 绑定的短期票据。

预览指纹包含当前 `sessionId`、会话记录截止序号和 Session 元数据更新时间。如果所有者确认前会话发生变化，创建或更新请求会被拒绝。

## 链接生命周期

- 后续消息不会自动加入分享。
- “更新到当前会话”会保留原 URL，并替换快照内容。
- 更新会增加 snapshot revision，并让旧附件票据失效。
- 有效期、最大访问次数、撤销、限流、审计和分享管理全部复用统一 Share 基础设施。

公开页面地址为 `/s/:token`。元数据和社交卡片请求不会消耗访问次数；只有 `POST /s/:token/view` 会原子地计入一次访问。

## 可访问范围

只有 Gateway 已配置公共隧道或 `gateway.publicUrl` 时，分享链接才能从公网访问。监听回环地址时链接仅本机可用，监听局域网地址时仅局域网可用。XOPC 当前不会把会话快照上传到托管服务。

# 分享会话

XOPC 可以把当前会话生成一份只读快照，并通过链接分享给其他人。公开页面会保留会话中的 Markdown 排版，同时把运行时的私有上下文排除在快照之外。

## 创建分享

1. 在桌面应用或网页控制台中打开要分享的会话。
2. 点击会话顶部的“**分享会话**”。
3. 展开“**检查将要公开的内容**”，确认快照内容。
4. 选择分享方式：
   - “**XOPC 托管分享**”会发布到 `https://share.xopc.ai`；
   - “**本机 Gateway 分享**”由你自己的 Gateway 提供访问。
5. 按需加入工具活动或逐个选择附件。
6. 选择有效期和最大访问次数，也可以补充一段简短说明。
7. 点击“**创建分享**”，然后复制或打开生成的链接。

任何获得链接的人都可以在链接过期、达到访问上限或被撤销前查看快照。不要把链接发送给超出预期范围的人。

## 选择分享方式

| | XOPC 托管分享 | 本机 Gateway 分享 |
| --- | --- | --- |
| 公开地址 | `https://share.xopc.ai/s/...` | 你配置的 Gateway 地址 |
| 分享后设备需要保持在线 | 不需要 | 需要 |
| 首次使用 | 授权独立的 XOPC 托管分享连接 | 无需额外授权 |
| 适合场景 | 分享给公网中的其他人 | 本机、局域网或自托管分享 |

托管分享使用独立的 `xopc-share` OAuth 资源，只授予 `shares:read` 与 `shares:write` 业务权限，不会复用模型服务商密钥或隧道凭据。授权还会申请离线访问，以便 XOPC 刷新托管分享连接，而不必每次发布都重新登录。

本机分享链接的可访问范围取决于提供它的 Gateway：

- Gateway 只监听回环地址时，链接仅当前电脑可用；
- Gateway 监听局域网地址时，链接可在同一网络内使用；
- 配置公共隧道或 `gateway.publicUrl` 后，链接才可从公网访问。

分享对话框会显示检测到的可访问范围。如果希望从公网访问本机分享，请参考[远程访问](./remote-access.md)。XOPC 不会在后台把本机分享隐式上传到托管服务。

## 哪些内容会被分享

默认快照只包含用户和助手的可见文本。

| 内容 | 是否分享 |
| --- | --- |
| 用户和助手的可见消息 | 是 |
| Markdown 标题、列表、表格、引用、链接和代码块 | 是 |
| 工具名称及完成/失败状态 | 仅在启用“包含工具活动”后 |
| Session 附件 | 仅包含你逐个选中的文件 |
| 系统提示和隐藏推理 | 永不分享 |
| 工具参数、工具结果、命令及命令输出 | 永不分享 |
| 上下文/审计行、工作区路径、Session Key 和模型元数据 | 永不分享 |

公开页面会对渲染后的 Markdown 做安全清理。选择附件后，XOPC 发布的是经过确认的副本，公开链接不会暴露原始媒体存储。附件下载使用与当前快照版本绑定的短期票据。

如果分享对话框打开后会话发生变化，XOPC 会拒绝已经过期的发布请求。请重新查看最新快照后再创建分享。

## 有效期与访问次数

会话分享支持 **1 小时**、**24 小时**、**7 天**或 **30 天**有效期。访问次数可以设为不限，也可以限制为 **1**、**10**或 **50**次。

加载公开会话会计为一次访问；链接预览和社交卡片的元数据请求不会消耗访问次数。链接过期或达到访问上限后，公开会话将不可继续访问。

## 更新或撤销分享

在同一 Session 中再次打开“**分享会话**”，即可管理当前有效的分享：

- “**复制**”或“**打开分享页面**”会继续使用现有链接；
- “**更新到当前会话**”会用最新的可见会话替换快照，同时保留原 URL；之前的公开内容不会作为历史版本继续保留；
- “**撤销分享**”会立即让链接失效；
- “**新建分享**”会创建独立链接，并使用自己的有效期和访问上限。

后续消息永远不会自动加入分享。更新分享会生成新的快照版本，并使上一版本的附件票据失效。

## 分享敏感会话前

- 阅读快照预览，不要只根据会话标题判断内容；
- 除非接收者确实需要，否则不要加入工具活动；
- 逐个选择附件，并先检查每个文件；
- 使用够用的最短有效期和有限访问次数；
- 链接不再需要时及时撤销。

分享链接属于持有者即可访问的链接，接收者不需要登录。随机 token 让链接难以猜测，但任何收到或转发链接的人，都可以在链接有效期间查看快照。

## 故障排查

| 问题 | 检查内容 |
| --- | --- |
| 托管分享的“创建分享”不可点击 | 完成对话框中显示的 XOPC 托管分享授权 |
| 发布前提示快照已经变化 | 关闭并重新打开对话框，检查最新预览后再创建 |
| 本机分享链接只能在当前电脑打开 | 配置公共隧道或 `gateway.publicUrl`，参见[远程访问](./remote-access.md) |
| 本机分享链接后来无法打开 | 确认 Gateway 正在运行，公共地址或隧道仍然指向它 |
| 公开页面提示链接不可用 | 链接可能已过期、被撤销、达到访问上限或无效 |
| 新创建的链接返回 404 | 更新 XOPC、重启 Gateway，然后重新创建或打开分享 |
| 分享页中缺少附件 | 只有创建或更新快照时明确选中的附件才会发布 |

Session 的存储与生命周期说明见[聊天与会话](./session.md)。

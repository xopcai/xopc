# 会话分享

XOPC 可以发布不可变、只读的 Session 快照。在会话页顶部选择“分享会话”，再选择“XOPC 托管分享”或“本机 Gateway 分享”。

## 快照边界

默认快照只包含用户和助手的可见文本。系统提示、推理内容、工具参数与结果、Shell 命令与输出、上下文审计行、工作区路径、Session Key 和模型元数据始终不会进入公开快照。

发布前，所有者可以显式选择加入：

- 工具名称及成功/失败状态；
- 单个会话附件。

公开链接始终不会指向原始媒体存储。本机分享会把所选附件复制到私有快照目录；托管分享会按校验和把用户确认的附件上传到私有存储。公开附件请求必须携带与快照 revision 绑定的短期票据。

预览指纹包含当前 `sessionId`、会话记录截止序号和 Session 元数据更新时间。如果所有者确认前会话发生变化，创建或更新请求会被拒绝。

## 链接生命周期

- 后续消息不会自动加入分享。
- “更新到当前会话”会保留原 URL，并替换快照内容。
- 更新会增加 snapshot revision，并让旧附件票据失效。
- 有效期、最大访问次数、撤销和限流由所选择的分享服务强制执行。

公开页面地址为 `/s/:token`。元数据和社交卡片请求不会消耗访问次数；只有 `POST /s/:token/view` 会原子地计入一次访问。

## 可访问范围

托管链接使用 `https://share.xopc.ai`，所有者的 Gateway 和设备离线后仍可访问。首次发布会要求授权独立的 `xopc-share` OAuth 资源，只申请 `shares:read` 与 `shares:write`，不会复用模型或隧道凭据。仅在开发其他托管部署时设置 `XOPC_SHARE_URL`。

本机 Gateway 分享保留原有行为：只有配置公共隧道或 `gateway.publicUrl` 时才能从公网访问；监听回环地址时仅本机可用，监听局域网地址时仅局域网可用。XOPC 不会把本机链接隐式转换成托管分享。

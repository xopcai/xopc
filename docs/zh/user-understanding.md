# 个性化与用户上下文

xopc 可以保存可检查的工作偏好，例如姓名、时区、协作规则和已经确认的习惯。这些内容保存在本地，每次请求只使用相关的一小部分。

## 查看 xopc 了解的内容

在 Gateway 控制台打开 **你** 或 **用户上下文**。根据当前版本，你可以查看：

- 你直接填写的资料；
- 从对话中推断、等待确认的理解；
- 已启用的理解；
- 你明确设置的协作规则；
- 已连接来源及其权限；
- 后台复查与隐私设置。

## 修正或删除

只有内容准确且确实有帮助时才 **确认**。错误、范围过宽、过期或不应保留时，使用 **修正**、**拒绝** 或 **删除**。

明确的协作规则优先于推断偏好。规则应写成具体行为，例如：“向外部联系人发送消息前先询问我。”

## 不应记住的内容

不要让 xopc 保存密码、API Key、恢复码、支付信息、政府证件号、医疗记录或其它高度敏感秘密。此类信息应放在密码管理器或对应系统中。

工作区文件和 Agent Profile Markdown 与用户上下文是不同内容。把信息写在那里可能让 Agent 读取，但不会使其成为经过审查的用户理解。

## 模型服务商隐私

本地保存不代表每次模型请求都留在本地。所选上下文和对话内容可能发送给当前云端模型。任务不应向外部服务商发送个人上下文时，使用本地模型或调整个性化设置。

## 后台复查

启用后，后台复查可以识别过期或矛盾内容，并放入待检查队列。它不应把未经确认的推断静默变成权威资料。

请定期检查队列；不需要此处理时停用后台复查。

本地数据库的备份和删除见[数据和文件位置](./workspace.md)。

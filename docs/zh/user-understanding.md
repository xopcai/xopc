# 理解与记忆

xopc 分开维护可检查的用户模型与知识记忆。项目资料、短期活动和模型推断不会因此悄悄变成关于用户的永久事实。

在 Gateway 控制台打开 **你**，可以从三个视角查看智能体当前对你的理解：

- **你的画像**把称呼、角色、代词、语言和时区等明确资料作为可直接编辑的字段呈现，不再混入理解信息流。
- **共同理解**只组织偏好与节奏、重要关系、当前状态和智能体判断；每一条都可以确认、修正或停止使用。
- **工作记忆**只呈现提炼后的项目事实、决定、经验、承诺和待解问题。邮件、日历和文档原文保留在来源索引中供检索与溯源，不再显示成记忆卡片。

界面用自然语言说明内容来源、可信程度和时间范围；存储状态名与原始评分只作为实现细节保留。

## 五类上下文

| 领域 | 用途 | 常见有效期 |
| --- | --- | --- |
| 用户断言 | 身份、偏好、习惯、关系、能力和当前状态 | 稳定、缓慢变化、动态或事件级 |
| 目标 | 期望结果与成功标准 | 直到完成、暂停或放弃 |
| 优先级窗口 | 当前什么最重要，包含起止时间、紧迫度和复查时间 | 数小时到数周 |
| 协作规则 | 明确的沟通、执行、边界、例行和主动协作规则 | 直到停用或替换 |
| 知识记忆 | 项目事实、决策、任务经验、承诺、问题、事件和笔记 | 由范围和保留策略决定 |

每条断言都记录权威等级、可信度、重要性、可行动性、变化速度、敏感度、适用条件、有效时间和复查时间。可信度表示它有多可能为真；重要性表示遗漏它会带来多大影响，两者相互独立。

## 证据与纠正

用户直接陈述拥有最高权威。已授权观察可以提出候选项。系统推断始终与用户确认的事实分开；不可信外部内容不能成为权威用户事实。

纠正会创建一条替代旧断言的新断言，同时保留审计历史。当前事实发生冲突时进入复查；运行时无法可靠判断时会选择不注入。

## 时间与定时整理

整理功能默认开启，并由确定性的系统自动化注册：

- 每小时进行时间扫描，把已过有效期的断言和知识标记为过期，并结束到期的优先级窗口；
- 每天进行一次对账，检查复查时间、矛盾证据、证据阈值和搜索索引缺口；
- 每周进行一次知识维护，在保留期结束后归档过期知识。

默认每天 03:00 执行日对账，每周日 04:00 执行周维护；使用配置的维护时区，未配置时使用主机时区。任务幂等、有数量上限、结果写入 SQLite，而且不会调用模型做不可见的语义修改。

## Agent 实际获得的内容

每一轮都会从当前协作规则、相关用户断言、有效目标和优先级、任务相关知识中构建有预算上限的执行上下文。范围、有效期、敏感度、披露策略、权威等级、相关性、重要性、紧迫度和字符预算共同决定是否选入；不会把完整用户模型附在每次请求中。

系统按轮次记录选入内容，控制台可以解释哪些信息影响了回答。用户对回答给出的“有帮助”或“不相关”反馈会关联到对应执行上下文。

## 来源与隐私

对话、明确选择的工作目录和已配置连接器彼此独立授权。撤销某个来源后会停止未来读取。敏感写入有独立策略；标记为仅本地处理的来源内容不会发送给远程提取模型。

不要把密码、API Key、恢复码、支付信息或受监管记录保存为用户事实。本地存储也不代表本地处理：除非处理策略要求留在本机，为当前请求选中的上下文可能发送给所配置的模型服务商。

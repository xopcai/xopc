# 用户理解与记忆

xopc 自动维护用户理解与工作记忆，普通记忆无需逐条确认。打开 **关于你**，可以查看最近更新、来源依据，并随时修改或删除。

## 自动记住什么

- 明确表达的普通事实与偏好直接记录。
- 观察与推断始终保留来源区别。只有证据充分、普通敏感度、影响较低或中等的暂时理解参与个性化。
- 项目事实、决定、经验与待解问题保留原有作用范围，不自动扩展为全局用户特征。
- 近期状态有有效期或复查时间。证据不足或过时的理解暂缓使用，不变成用户的待确认任务。
- 自动记忆不会授予执行权限；推断出的协作规则保持关闭，敏感个人推断不写入用户模型。

普通记忆的 `writePolicy` 只支持 `allow`（默认）与 `deny`。升级时一次性将旧的普通 `confirm` 转为 `allow`，保留 `deny` 和敏感信息设置。运行时不再兼容旧的普通确认策略。

## 修改与删除

理解与工作记忆都可直接修改。用户修正优先于后续自动观察与来源刷新。也可以在对话里要求助理修正或忘记已有的用户理解。

删除理解会移除其修订链、关联证据关系、搜索索引、相关维护及上下文审计记录，并清理发现流程中的对应候选缓存。删除工作记忆还会清理关联的压缩派生记录。系统仅保留不包含原文的哈希标记，阻止相同槽位、规范键或规范化文本被自动重建。明确的新记忆指令可以重新记录已删除的用户理解。

删除范围是结构化记忆，不会删除原始对话、文件、连接器记录、备份或已经生成的回答。不同身份和措辞的语义改写不保证被哈希标记识别；不希望继续学习某类信息时，可以管理其来源或使用临时对话。

## 后台维护

沿用现有定时任务，不增加全量历史的大模型重写：

- 每小时处理到期理解、工作记忆和优先事项。
- 每天检查矛盾与独立证据，自动激活满足条件的候选。相同内容或相同来源项不重复计数，系统自己生成的内容不用于增强证据。
- 新的来源观察可更新推断的复查窗口；系统读取过某条记忆，不会提高它的可信度或刷新时间。
- 每周归档超过保留期的过时工作记忆。

每天默认 03:00、每周默认周日 04:00，使用配置的维护时区，否则使用设备时区。任务有工作量上限、幂等控制和审计记录。

## 每次回答如何使用

每次回答前，先检查范围、时间、敏感度与来源权威性，再按当前任务选择少量相关内容。自动激活的推断仍是暂时假设，不能标为用户确认。当前明确指令优先；到期内容无需等后台任务运行便停止使用。

对话、工作目录与连接器保留独立授权。临时对话和仅本地处理策略继续生效。数据位置与备份见[数据与文件位置](./workspace.md)。

## 更新 xopc

```bash
# npm 全局更新
npm update -g @xopcai/xopc

# 或重新运行安装脚本
curl -fsSL https://xopc.ai/install.sh | bash
```

详见 [更新](./update.md) 了解 gateway 更新说明和版本回退。

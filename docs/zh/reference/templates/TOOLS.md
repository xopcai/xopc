# TOOLS.md：本地工具提示

这里只记录 Agent 使用工具时需要知道、并且可以安全进入模型上下文的环境信息。

## 可以记录

- 工作区内常用目录及用途；
- 项目使用的构建、测试和格式化命令；
- 设备或服务的非敏感别名；
- 执行动作前必须遵守的本地约束。

## 不要记录

- 密码、API Key、Token、私钥或恢复码；
- 可以从标准命令或项目文档直接获得的冗长信息；
- 已经失效的主机名、账号或路径。

## 示例

```md
- 主代码仓库：`~/develop/example`
- 修改后运行：`pnpm test`
- 发布、发送消息和删除数据前必须向用户确认。
```

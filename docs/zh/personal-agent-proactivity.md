# Personal AI 持续跟进

Personal AI 可以关注你交代的主题，并在有值得交流的内容时，在个人聊天里留下更新。用户不活跃本身不会触发问候或催促。

## 交代一次跟进

在 Personal AI 的聊天中可以这样说：

```text
明天下午再检查一下这个方向。如果有值得补充的建议，在这里告诉我。
只使用我已经授权的来源。
```

等待助手确认跟进已保存，以及实际检查时间。“明天下午”按主动联系时区解释为 15:00。检查时间不等于消息送达时间：排队和准备可能增加延迟，没有有用的新内容时会保持安静。需要固定时间提醒时使用[自动化](./automations.md)。

## 控制联系时机

打开 Personal AI 偏好面板中的 **主动联系**：

| 方式 | 行为 |
| --- | --- |
| 关闭主动联系 | 停止主动联系；已有明确请求的结果仍可交付 |
| 仅明确跟进 | 只跟进你明确交代的主题 |
| 适度主动 | 也考虑有充分上下文的讨论 |

默认适度主动，静默时间为 22:00–08:00。请检查时区和静默时间，尤其是 Gateway 运行在另一台电脑时。

当前对话优先。正在语音交流、输入排队或明确请求的成果等待交付时，主动更新会让位。

## 查看与调整主题

点击主动消息下方的小提示，可以查看为什么关注、为什么现在联系和相关对话。推断关注会明确标记，不表示你已经委托工作或授权对外操作。

可以延后或停止主题、要求以后先准备完整或简短一点，并撤销最近的主题调整。这些选择只作用于当前主题，不会改变所有对话。停止的主题需要明确要求恢复；过期或失去来源的事项不能通过撤销重新启动。

也可以在聊天里说“不要再跟进这个主题”或“这个主题以后准备完整再告诉我”。多个主题同时存在时，请说明具体是哪一个。

## 运行条件与隐私

- 本地 Gateway 需要保持运行，并配置可用模型。约每分钟检查到期事项，不保证立即送达。
- 离线恢复后合并检查，不会集中补发过时消息。
- 用户理解、会话访问和写入策略仍然生效。当前版本在仅本地理解处理策略下暂停后台模型准备。
- 更新只发布到 Personal AI 个人聊天，这项功能不启用外部渠道通知。
- 可以问助手“你推断我有哪些长期兴趣”。兴趣候选保持静默，不会自动开始跟进。
- 删除或撤销来源后，不再披露该依据；已送达消息的正文不会因此自动删除。

没有收到更新时，先检查主动方式、静默时间、时区、模型和 Gateway 连接。请助手展示已经保存的主题，避免重复安排。

修改和删除见[用户理解与记忆](./user-understanding.md)；需要明确结果与验收的工作见[Project、Task 与笔记](./projects-tasks-notes.md)。

# 从聊天到数据飞轮

“把目标变成循环”不是让你一开始就搭一套复杂流程。

更自然的用法是：先把 xopc 当作一个本地 AI 聊天助手，用它讨论问题、整理想法、记录今天发生了什么。等你持续把项目进展、笔记、阻塞点和反馈放进来，它就开始从“一次对话”变成“能持续跟进的工作系统”。

## 一般会这样长出来

| 阶段 | 你做什么 | xopc 开始帮你什么 |
| --- | --- | --- |
| 简单聊天 | 问问题、做判断、整理思路。 | 先有一个跑在本地、使用你自己模型配置的 AI 助手。 |
| 持续项目 | 让它跟进一个真实目标。 | 记住目标、当前状态、阻塞点、决策和下一步。 |
| 笔记和想法 | 随手丢进展、想法、链接、反馈和复盘。 | 把零散输入沉淀成之后能继续使用的上下文。 |
| 外部入口 | 手机 App 扫码连接，也可以在桌面、终端、网页、IM 或 gateway API 里继续用同一个助手。 | 不在电脑前也能继续对话、记录 note/idea；Agent 和数据仍在你的 xopc 环境里。 |
| 自动化 | 设置定时复盘、提醒、摘要和工作流。 | 重要事项会自己回到视野里，不完全依赖你想起来再问。 |

## 一个循环长什么样

1. 你告诉 xopc 目标和当前状态。
2. xopc 帮你找出下一步。
3. 你去执行，或者继续让 xopc 协助完成。
4. 你把结果、阻塞点或新想法发回来。
5. xopc 更新上下文，再帮你判断下一步。
6. 自动化定期做复盘、提醒、摘要或触发工作流。

一次聊天能解决一个问题；循环的价值在于让项目一直可见、状态一直更新、下次恢复时不用重新解释。

## 手机是入口，不是另一个云端大脑

很多想法不是坐在电脑前出现的。xopc 的手机 App 适合用来随手记录 note、idea、进展和阻塞点，也可以在 iOS 或 Android 上继续和同一个 Agent 对话。

关键点是：手机 App 不是另一个云端助手。xopc 仍然运行在你的电脑或自托管环境里；手机通过二维码配对连接到你的 gateway，再和这个本地运行时通信。长期项目上下文和数据仍然留在你的 xopc 环境里，而不是迁移到某个云端聊天账号。

## 可以从这句开始

```text
帮我持续跟进这个项目。请记录目标、当前状态、阻塞点、关键决策和下一步行动。以后我每次更新进展时，请先总结变化，再建议下一步。
```

它可以用于个人项目、写作计划、产品想法、客户跟进、学习计划，也可以用于一人公司的日常运营。先在聊天里养成这个习惯，再按需要接入通道和自动化。

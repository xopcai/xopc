## 最短路径

1. [安装桌面应用](./desktop-app.md)，或按照[终端快速开始](./first-5-minutes.md)操作。
2. [连接一个模型](./how-to/configure-first-model.md)。
3. 在聊天中发送测试消息。
4. 第一次对话成功后，再按需要添加 Agent、消息通道、Workflow 或远程设备。

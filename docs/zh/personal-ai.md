# 认识 Ada，你的个人 Agent

Ada 是 xopc 中的个人 Agent。你可以先聊聊，理清目标，或交办一件事，同时继续对话；也可以直接进入工作空间处理文件和项目。两种方式都在同一个 xopc 中，无需额外安装。

## 开始前

安装[桌面应用](./desktop-app.md)或打开网关控制台，连接一个可用的[模型](./how-to/configure-first-model.md)，并保持网关运行。语音和外部服务需要单独配置；仅使用 Ada 不需要另一款应用或额外账号。

## 开始对话

1. 从侧栏打开个人 Agent（`#/personal`）。默认名称是 **Ada**，已有实例可能显示你设置过的名字。
2. 完成页面提示的设置；需要时选择可用模型。
3. 告诉它一点背景：“我独立工作，请简短回答，目标不清楚时先问我，一次帮我完成一件有用的事。”
4. 带入一个实际问题或小任务。如果只想讨论，可以直接说明。

先确认个人对话中出现了回复，且它理解了你的要求，再增加资料和访问权限。

## 按你的方式协作

点击页面顶部头像或 **回应偏好**。可以调整名字、形象、语气、回答长度，以及棘手时先听、帮你理清还是给办法。偏好面板中也可选择模型和声音。

**主动更新**决定 Ada 汇报任务进展的程度；**主动联系**决定对关注主题的联系方式和安静时段。这是两项不同设置，后者见[持续跟进](./personal-agent-proactivity.md)，以当前界面名称为准。

通过[用户理解](./user-understanding.md)查看、纠正或删除长期理解。调整语气不等于纠正一条记忆事实。

## 准备好后交办

试着说：“把刚才的计划整理成一页 Markdown 文件，包括目标、三个下一步和未决问题。文件准备好后告诉我。”

打开 **正在做的事** 查看派发任务。你可以继续讨论别的话题，再回来打开交付文件并要求修改。详见[交办任务与接收结果](./task-delegation.md)。

## 遇到问题

| 问题 | 下一步 |
| --- | --- |
| 无法完成个人 Agent 设置 | 检查模型凭据、可用模型和网关连接 |
| 显示的名字不是 Ada | 检查保存的个人资料；Ada 是默认名称 |
| 无法语音通话 | 配置并测试[语音](./voice.md)，文字聊天成功不代表语音已可用 |
| 收到不期待的跟进 | 查看主动联系模式及消息附带的主题缘由 |
| 它理解的背景不对 | 纠正用户理解，并澄清当前对话 |

核心状态保存在本地 xopc 实例中；选择云模型时，对应提供商会处理发送过去的上下文。详见[数据与文件位置](./workspace.md)和[产品理念](./product.md)。

# 认识 Ada，你的个人 Agent

Ada 是 xopc 中的个人 Agent。你可以先聊聊，理清目标，或交办一件事，同时继续对话；也可以直接进入工作空间处理文件和项目。两种方式都在同一个 xopc 中，无需额外安装。

## 开始前

安装[桌面应用](./desktop-app.md)或打开网关控制台，连接一个可用的[模型](./how-to/configure-first-model.md)，并保持网关运行。语音和外部服务需要单独配置；仅使用 Ada 不需要另一款应用或额外账号。

## 开始对话

1. 从侧栏打开个人 Agent（`#/personal`）。默认名称是 **Ada**，已有实例可能显示你设置过的名字。
2. 完成页面提示的设置；需要时选择可用模型。
3. 告诉它一点背景：“我独立工作，请简短回答，目标不清楚时先问我，一次帮我完成一件有用的事。”
4. 带入一个实际问题或小任务。如果只想讨论，可以直接说明。

先确认个人对话中出现了回复，且它理解了你的要求，再增加资料和访问权限。

## 按你的方式协作

点击页面顶部头像或 **回应偏好**。可以调整名字、形象、语气、回答长度，以及棘手时先听、帮你理清还是给办法。偏好面板中也可选择模型和声音。

**主动更新**决定 Ada 汇报任务进展的程度；**主动联系**决定对关注主题的联系方式和安静时段。这是两项不同设置，后者见[持续跟进](./personal-agent-proactivity.md)，以当前界面名称为准。

通过[用户理解](./user-understanding.md)查看、纠正或删除长期理解。调整语气不等于纠正一条记忆事实。

## 准备好后交办

试着说：“把刚才的计划整理成一页 Markdown 文件，包括目标、三个下一步和未决问题。文件准备好后告诉我。”

打开 **正在做的事** 查看派发任务。你可以继续讨论别的话题，再回来打开交付文件并要求修改。详见[交办任务与接收结果](./task-delegation.md)。

Ada 可以读取少量本地文本、找回历史对话细节，以及查看笔记、项目和自动化状态。工作返回后，你可以继续追问已保存成果中的章节、PDF 页、表格单元格或来源，无需重新制作。支持的文档文本在后台准备；首次读取需要解析时，准备好后会自动继续回答原问题。新的视觉理解、加工和完整批量审阅仍交给执行 Agent。连接应用请求先核对连接和账号；读取已保存结果仍检查账户权限，不会自动刷新外部数据。

在 Web 聊天中，点击返回成果或文件旁的 **询问**，可把准确的成果引用附到下一条消息。文本准备期间，原文件仍可预览和下载。提取文本可能不包含版式、图片或公式重算，回答应保留这些限制。

个人主对话使用固定的本地读取和协调工具。MCP、Codemode 和动态外部工具发现由执行 Agent 按自身配置使用；配置 MCP 不会直接开放个人主对话的工具权限。同一 Agent 的独立普通对话仍遵循其配置权限。

## 遇到问题

| 问题 | 下一步 |
| --- | --- |
| 无法完成个人 Agent 设置 | 检查模型凭据、可用模型和网关连接 |
| 显示的名字不是 Ada | 检查保存的个人资料；Ada 是默认名称 |
| 无法语音通话 | 配置并测试[语音](./voice.md)，文字聊天成功不代表语音已可用 |
| 收到不期待的跟进 | 查看主动联系模式及消息附带的主题缘由 |
| 它理解的背景不对 | 纠正用户理解，并澄清当前对话 |

核心状态保存在本地 xopc 实例中；选择云模型时，对应提供商会处理发送过去的上下文。详见[数据与文件位置](./workspace.md)和[产品理念](./product.md)。

任务交接会分别保存用户原话和主 Agent 的理解，固定所选输入版本，并允许执行者在获准范围内分页补读。沿用此前成果、笔记、Task 或文件时，可通过 `personal_task.sourceRefs` 交接稳定引用；提交后由后台完成归属和版本核验。后台分配检查必需操作、工具策略与注册、模型配置、Skill 和账户权限，真正启动执行前再次检查。详见[任务交接与能力校验](https://github.com/xopcai/xopc/blob/main/docs/design/technical/personal-task-handoff-stage-b-2026-10-15.md)。

已完成的普通 Task 可以在同一任务内继续修改，并保留原成果。`personal_task(get, section="revision")` 返回原子 `revise` 所需的准确基线与期望版本；执行仍在后台进行。成果卡会显示版本，`personal_result` 可继续读取历史版本。最终交付只使用明确选中的附件，不汇总运行期间出现过的所有文件；整理或前台繁忙时，已保存文字可独立投递。详见[后续修订与最终交付](https://github.com/xopcai/xopc/blob/main/docs/design/technical/personal-task-revision-stage-c-2026-10-15.md)。

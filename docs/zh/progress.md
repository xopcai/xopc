# 查看任务进度

xopc 会在 Agent 使用工具或处理长请求时显示实时状态，帮助你区分正在工作、等待输入和执行失败。

## 状态含义

| 状态 | 含义 |
| --- | --- |
| 思考 | 模型正在准备下一步 |
| 搜索或读取 | Agent 正在收集信息 |
| 写入或执行 | 工具正在修改文件或运行命令 |
| 等待 | Agent 需要你的决定、权限或缺失信息 |
| 完成 | 已返回请求结果 |
| 失败 | 当前动作因错误停止 |

不同客户端的显示方式不同。Gateway 控制台信息最完整；消息通道可能使用简短文字或更新中的草稿消息。

## 进度看起来卡住时

1. 检查是否有确认请求隐藏在当前可见区域之外。
2. 在 Gateway 控制台打开运行或工具详情。
3. 查看最新日志。
4. 只有确认没有有效进展或动作不安全时才取消。
5. 修复第一个错误后重试，不要只处理后续症状。

长任务可能定期报告仍在运行，但这不代表一定成功；最终仍要检查结果和验证证据。

## 通道流式显示

支持流式传输的通道可以在工作期间更新消息。如果局部更新干扰阅读或在该通道不稳定，可以在通道设置中选择整条消息模式。

进度摘要不应暴露原始密钥或完整工具参数。如果出现敏感信息，请停止运行、轮换相关凭据，并检查 Agent 和消息通道权限。

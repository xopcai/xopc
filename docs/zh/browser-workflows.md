# 浏览器自动化

浏览器自动化可以让 xopc 重复执行一次已经和助手成功完成过的网页任务。你只需要用日常语言说明想要的结果，xopc 会完成浏览器操作，并把可重复使用的步骤保存下来。

你不需要编写 YAML、选择器或自动化代码。

## 浏览器自动化和自动化有什么区别？

这两个功能可以配合使用，但解决的问题不同：

| 功能 | 负责什么 | 示例 |
| --- | --- | --- |
| 浏览器自动化 | 浏览器具体做什么 | 打开订单页面，输入订单号并返回当前状态 |
| [自动化](./automations.md) | 任务什么时候开始 | 每个工作日上午 9 点执行一次订单查询 |

如果你只是想重复一组网页操作，先创建浏览器自动化；如果还希望定时或通过其他事件触发，再把它添加到“自动化”中。

## 让助手帮你创建

1. 在网关控制台打开 **更多应用 → 浏览器自动化**。
2. 点击 **让助手创建**。
3. 告诉助手你想得到什么结果，以及需要使用哪个网站。
4. 和助手一起把任务成功完成一次。遇到登录或敏感确认时，由你自己操作。
5. 任务成功后，助手会保存已验证的操作步骤，并把以后每次运行需要填写的内容设为输入项。

例如：

> 打开我的订单管理页面，根据订单号查询当前状态。成功后保存为浏览器自动化，并把订单号设为每次运行时填写的内容。

第一次成功运行很重要，它让助手可以基于真实页面保存一条已经验证过的操作路径。如果网站或目标不够明确，助手可能会追问一个简短问题。

## 再次运行

打开 **更多应用 → 浏览器自动化**，选择一个已启用的浏览器自动化，在 **运行前填写** 中补全所需内容，然后点击 **立即运行**。

页面会显示当前状态、运行结果和最近记录。任务仍在执行时，可以随时停止。

你也可以直接在对话中说：

> 用“订单状态查询”帮我查一下订单 12345。

助手会找到对应的已启用浏览器自动化，填入参数，等待执行完成，然后把结果告诉你。

## 修改、暂停或删除

- 点击 **让助手修改**，用自然语言说明需要改变什么。助手会先测试新步骤，再保存修改。此前的运行记录会保留当次运行实际使用的版本。
- 点击 **暂停**，可以阻止新的运行，但不会删除它。暂停后，它也不会出现在“自动化”的可选列表中。
- 准备好再次使用时，点击 **启用**。
- 不再需要时，点击 **删除浏览器自动化**。删除后无法恢复；正在运行时不能删除。

## 设置定时执行

1. 确认浏览器自动化已经启用。
2. 打开 **自动化**，创建一个新的自动化。
3. 选择手动、定时或 webhook 触发方式。
4. 将动作选择为 **浏览器自动化**。
5. 选择已保存的浏览器自动化，并填写它需要的输入项。

定时任务开始时，xopc 网关和配置的浏览器必须处于可用状态。网站登录状态可能在两次运行之间过期，因此涉及账号的任务偶尔需要你重新登录。

## 登录和敏感操作

- 请在浏览器中自行登录。不要把密码、短信验证码、恢复码或支付信息保存为自动化输入项。
- 验证码、双重验证、授权确认等必须由你本人完成。浏览器自动化不会绕过这些验证。
- 运行前查看风险提示。xopc 会标明该任务只是读取信息、会修改账号数据，还是包含敏感操作。
- 网站改版后要谨慎检查。页面结构变化可能使原来保存的步骤失败，或产生不同的操作结果。

## 合规、安全地使用

只自动化你有权使用的网站、账号和数据，并遵守网站的服务条款、访问规则和合理的请求频率。

xopc 会把每个浏览器自动化限制在创建时声明的网站范围内，跳转后的地址同样受限制，并会拦截不安全的网址模式。不要用它绕过访问控制、验证码、频率限制、付费墙或反自动化机制。如果网站拒绝自动化，请停止任务，改用官方 API、数据导出或人工操作。

xopc 目前不会内置第三方浏览器自动化脚本库。这样可以确保保存的行为来自你在自己的环境中实际执行并确认过的任务。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 找不到功能入口 | 打开 **更多应用 → 浏览器自动化**，也可以直接访问 `#/browser-workflows`。 |
| 助手提示浏览器不可用 | 请让当前 xopc 实例的管理者为所选 Agent 开启浏览器权限，并安装浏览器运行环境。 |
| 运行时要求登录 | 打开浏览器自行登录，再重新运行。不要把密码放进可重复使用的输入项。 |
| 在“自动化”中找不到已保存的任务 | 先到“浏览器自动化”页面将它启用。 |
| 页面提示输入不正确 | 按页面显示的类型和格式填写所有必填项。 |
| 以前能运行，现在失败了 | 网站可能已经改版。点击 **让助手修改**，重新测试并保存。 |
| 定时任务没有开始 | 检查网关和浏览器是否运行、浏览器自动化是否启用，以及登录状态是否过期。 |

如需排查安装问题，实例管理者可以运行 `xopc browser doctor`。

# CLI 连接器

连接飞书、企业微信或 WPS 365，让 Agent 使用受支持的办公数据与动作。xopc 自动安装并校验所需 CLI，各账号分别隔离。这些连接器当前为 Beta。

## 使用

在连接器页面选择飞书、企业微信或 WPS 365并连接账号。飞书可能先初始化应用、再进行用户授权；企业微信显示二维码。关闭弹窗不会取消授权，重新打开可以继续查看；点击取消或 Gateway 重启后需要重新授权。

飞书登录成功但只授予部分权限时，继续验证账号并保留连接；每次操作仍检查所需权限。真正的登录失败会显示脱敏后的具体原因。

新连接默认只读。开启写入后，每次写入仍需确认。多账号时必须明确选择目标；账号不可用时不会自动替换为其他账号。重连保留账号标识，并使旧审批失效。本地断开会禁用执行，但不会撤销服务端授权；独立配置仍保留用于重新授权。

当前固定 `lark-cli 1.0.96` 、`wecom-cli 1.3.0` 和 `wps365-cli 0.3.6`。支持 macOS/Linux 的 x64、arm64，需要系统 `tar`。Windows 凭据隔离尚未验证，因此不开放。这些连接器保持 Beta，真实账号验收待完成。

## WPS 365 授权

首次连接分两步：先在浏览器绑定应用，再完成用户授权。每一步完成后返回 xopc，弹窗会刷新进度，验证当前用户成功后才显示已连接。企业可能要求应用发布、管理员审批和对应 API/数据权限；登录成功不代表所有能力都可用。企业套餐不包含能力时，应联系管理员处理，重新登录无法解决。

WPS 凭据存放在独立账号目录，使用固定 API spec 和明确的用户身份，不继承宿主 WPS Token，也不自动切换为应用身份。当前仅开放只读能力；CLI 内部重试语义和真实账号写入验收完成前，不开放写命令。

## 能力与边界

- 飞书：文档搜索/读取、日历与日程查询、日程创建、文件元数据和联系人查询。
- 企业微信：文档搜索/读取、联系人搜索、待办查询/创建。
- WPS 365：云文档、日历/日程、邮箱共 14 个只读动作；即使账号设置允许写入，也不会开放未上线的写命令。
- 分页游标通过动作参数和返回值显式传递，不自动无限翻页。
- `xopcAccountId` 指定稳定账号，批量读取必须传入。
- `xopcExportResult: true` 将成功结果导出为私有 JSON 文件，下载接口需要 Gateway 管理权限。不开放任意文件上传/下载或原始命令执行。
- 检查连接会验证身份与接口契约；最近执行记录可通过 `GET /api/connectors/:instanceId/executions` 查看。

写操作超时、被中断或响应格式无法确认时，结果记为 `unknown`，不会自动重试。应先通过只读动作检查远端资源，再判断是否需要重新写入。

运行文件位于 `<state>/connectors/cli/runtimes/`，账号配置、子进程主目录和产物位于 `<state>/connectors/cli/contexts/`。不同账号使用不同目录，CLI 自行维护其凭据格式；不继承宿主的无关密钥环境变量。

## 验证连接与排障

连接后先使用 **检查连接**，再让助手读取一条你熟悉的文档、日程或待办，核对账号和返回内容。普通登录成功不代表企业已开放所有权限。

- 找不到内容：核对选择的账号、文档共享范围和应用权限。
- 授权失败：检查弹窗中的具体原因；企业审批或套餐限制需管理员处理。
- 下载或启动失败：检查 Gateway 主机的网络、支持的平台和 `tar`。
- 写操作结果不确定：先读取远端状态，不要直接重试创建。
- 要撤销访问：在 xopc 断开后，再到服务商账号设置撤销授权。

飞书消息机器人与办公连接器是不同入口；消息接入见[飞书通道](../channels/feishu.md)。其它连接方式见[连接器](./index.md)。

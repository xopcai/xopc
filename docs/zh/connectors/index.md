# 连接器

连接器让 Agent 使用外部服务的数据或动作。它可能由内置集成、扩展、MCP 服务或已验证连接器目录提供。

## 选择连接方式

| 方式 | 适用场景 |
| --- | --- |
| 内置或已验证连接器 | 服务出现在 Gateway 连接器目录中 |
| 扩展 | 集成同时包含消息通道、服务商、界面或本地运行环境 |
| MCP 服务 | 服务提供 MCP 接口或本地服务 |
| Composio | 希望使用它托管的应用连接和动作目录 |

## 安全连接

1. 打开 **连接器** 并选择服务。
2. 登录前检查请求的权限范围。
3. 授予可选的最小权限。
4. 只把连接器分配给需要它的 Agent。
5. 先测试只读动作。
6. 确认交互行为后再启用写入或外部动作。

连接器可能把私人账号数据暴露给当前模型。需要同时检查外部服务的授权范围和 Agent 的模型服务商。

## 管理连接

在连接器页面查看健康状态、重新授权过期连接，并移除不再使用的连接。从 xopc 删除连接不一定会撤销外部服务的授权；必要时也要在外部服务的账号设置中撤销。

具体集成见 [Composio](./composio.md) 和 [GitHub](./github.md)，通用协议连接见 [MCP](../mcp.md)。

## 国内连接器

国内服务仍使用同一个连接器目录，不引入第二套“插件市场”或兼容层。办公数据与动作按服务使用受管理 CLI 或 MCP 运行时；消息入口继续由 Channel 管理。

| 连接器 | 运行方式 | 凭据 | 能力 |
| --- | --- | --- | --- |
| 飞书办公（Beta） | 官方受管理 CLI | 应用初始化和用户授权 | 文档搜索/读取、日历查询/创建、文件和联系人查询 |
| 企业微信（Beta） | 官方受管理 CLI | 扫码授权 | 文档搜索/读取、联系人搜索、待办查询/创建 |
| 钉钉办公 | 官方本地 MCP | Client ID、Client Secret | 通讯录、待办、日历、机器人、工作通知 |
| WPS 365 云文档 | 官方远程 MCP | 用户 Access Token | 搜索和读取文档、评论、分享权限 |
| WPS 365 日历 | 官方远程 MCP | 用户 Access Token | 查询和管理日程 |
| WPS 365 邮箱 | 官方远程 MCP | 用户 Access Token | 搜索和读取邮件、创建和发送草稿 |
| 腾讯会议 | 官方远程 MCP（灰度） | MCP Token | 查询、创建和管理个人会议 |

CLI 使用独立账号目录，固定版本并校验实际二进制。接入说明见 [CLI 连接器](./cli.md)。本地 MCP 包固定到经过验证的版本，避免启动时静默升级。远程 MCP Token 只写入 xopc 凭据存储；配置文件保存的是密钥引用，不保存明文。微信消息不作为连接器重复展示，统一在频道页扫码和管理账号。

未进入目录的国内服务表示当前没有可验证的官方 MCP、稳定开放 API 适配或完整消息运行时。目录不展示仅有名称、没有真实执行能力的占位连接器。

# 连接器

连接器让 Agent 使用外部服务的数据或动作。它可能由内置集成、扩展、MCP 服务或已验证连接器目录提供。

## 选择连接方式

| 方式 | 适用场景 |
| --- | --- |
| 内置或已验证连接器 | 服务出现在 Gateway 连接器目录中 |
| 扩展 | 集成同时包含消息通道、服务商、界面或本地运行环境 |
| MCP 服务 | 服务提供 MCP 接口或本地服务 |
| Composio | 希望使用它托管的应用连接和动作目录 |

## 安全连接

1. 打开 **连接器** 并选择服务。
2. 登录前检查请求的权限范围。
3. 授予可选的最小权限。
4. 只把连接器分配给需要它的 Agent。
5. 先测试只读动作。
6. 确认交互行为后再启用写入或外部动作。

连接器可能把私人账号数据暴露给当前模型。需要同时检查外部服务的授权范围和 Agent 的模型服务商。

## 管理连接

在连接器页面查看健康状态、重新授权过期连接，并移除不再使用的连接。从 xopc 删除连接不一定会撤销外部服务的授权；必要时也要在外部服务的账号设置中撤销。

具体集成见 [Composio](./composio.md) 和 [GitHub](./github.md)，通用协议连接见 [MCP](../mcp.md)。

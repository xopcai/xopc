# Composio

Composio 为外部应用提供托管连接和动作。需要的应用在 Composio 中可用，并且你接受 Composio 作为数据链路中的额外服务时，可以选择它。

## 连接

1. 创建或登录 Composio 账号。
2. 在 xopc 中打开 **连接器**，选择 **Composio**。
3. 添加页面要求的 Composio 凭据。
4. 选择应用并完成授权。
5. 检查外部应用授予的权限范围。
6. 只把连接分配给需要它的 Agent。

## 验证

让 Agent 执行一个只读动作，例如列出少量最近项目。确认它使用的是预期账号，并且没有要求更广权限。

只有读取正常且确认行为清晰后，才启用创建、更新、发送或删除动作。

## 隐私与移除

请求可能经过 xopc、所选模型服务商、Composio 和已连接应用。请分别查看各服务的数据政策。

移除连接时，从 xopc 和 Composio 中删除，并在需要时到外部服务中撤销应用授权。

## 故障排查

- 连接显示 Token 过期或撤销时重新授权。
- 确认当前目录中仍然存在目标应用动作。
- 确认 Agent 允许连接器工具。
- 从 Gateway 日志查找第一个 Composio 错误，但不要分享 Token。

# GitHub 连接器

当 Agent 需要读取代码仓库信息，或在明确授权下创建和更新 GitHub 内容时连接 GitHub。

## 连接

1. 打开 **连接器**，选择 **GitHub**。
2. 登录并检查请求的组织和仓库访问范围。
3. 优先选择特定仓库，不要直接授权全部仓库。
4. 从只读权限开始。
5. 把连接分配给目标 Agent。

## 验证

先请求只读动作，例如“列出仓库 X 最近更新的五个未关闭 Issue”。启用写入前确认仓库和账号正确。

## 写入动作

创建 Issue、评论、分支或 Pull Request 会修改共享外部状态。配置 Agent 在执行前显示拟执行动作和目标。日常仓库工作不应授予管理员或 Secrets 权限。

## 故障排查

- 确认授权账号能访问目标仓库。
- 检查组织审批和 SSO 要求。
- Token 或应用授权撤销后重新连接。
- 比较 GitHub Scope 与 Agent 尝试执行的动作。
- 查看日志时隐藏 Token、私有 URL 和仓库内容。

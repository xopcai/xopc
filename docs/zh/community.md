# 社区交流

xopc 通过公开、友善的协作持续成长。请选择与问题类型匹配的渠道，让有价值的答案可以被长期检索和复用。

| 渠道 | 适合内容 |
| --- | --- |
| [GitHub Discussions](https://github.com/xopcai/xopc/discussions) | 技术问答、想法、架构讨论和需要长期检索的知识 |
| [Discord](https://discord.gg/ZmK8FzZHG) | 实时交流、作品展示和贡献者协作 |
| [微信群](#wechat) | 中文交流、上手帮助和版本动态 |
| [GitHub Issues](https://github.com/xopcai/xopc/issues) | 可复现的 Bug 和可执行的功能建议 |

## 发言前

- 先搜索文档和已有 Discussions。
- 分享日志或截图前，移除 API Key、访问 Token、个人信息和私有配置。
- 在群聊中确认的 Bug，应整理复现步骤后提交到 Issue。
- Discord 或微信群产生的重要决定和可复用方案，应整理回 Discussion、Issue、Pull Request 或文档。
- 在所有 xopc 官方社区中遵守[行为准则](https://github.com/xopcai/xopc/blob/main/CODE_OF_CONDUCT.md)。

## Discord

Discord 适合快速、轻量的交流。新成员从 `#welcome-and-rules` 开始；安装与配置问题发到 `#help`；作品发到 `#showcase`；仓库协作发到 `#contributors`。重要技术结论仍应回写 GitHub。

[加入 xopc Discord 社区](https://discord.gg/ZmK8FzZHG)

## 微信群 {#wechat}

微信群用于中文社区交流。下方目前是占位二维码，后续会替换为有效的社区群二维码。它不是配置 xopc 产品 `channels.weixin` 消息通道时使用的登录二维码。

![xopc 微信社区群占位二维码](/community/wechat-qr-placeholder.svg)

如果二维码暂时不可用或群已满，请先使用 [GitHub Discussions](https://github.com/xopcai/xopc/discussions)，等待社区入口更新。

## 安全与私下报告

请勿在公开渠道发布漏洞、凭据或敏感个人信息。安全漏洞请通过 [GitHub Security Advisories](https://github.com/xopcai/xopc/security/advisories/new) 提交。需要私下报告违反行为准则的情况时，请发送邮件至 [lyxopc.ai@gmail.com](mailto:lyxopc.ai@gmail.com)。

社区渠道由维护者和志愿者共同维护，回复采用尽力而为原则，不承诺固定响应时间。

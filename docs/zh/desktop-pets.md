# 桌面宠物

桌面应用可以显示一个小型动画角色，用来反映 Agent 的大致状态，例如等待、读取、工作、成功或需要注意。

## 启用或选择

1. 在桌面应用打开 **设置 → 宠物**。
2. 启用桌面宠物。
3. 选择内置或已安装宠物。
4. 调整显示和行为设置。

宠物只是环境状态显示，不是独立 Agent；动画不会改变当前任务，也不会授予新能力。

## 在聊天中创建

从宠物设置选择 **在聊天中创建**，描述角色和风格，按照引导完成。使用前检查预览。

自定义宠物默认保存在 `~/.xopc/pets/`。需要调整时使用 **优化**，无需从头开始。

## 隐私

宠物气泡只应显示可公开的简短摘要，不应展示原始消息、工具参数、命令输出或密钥。在共享屏幕或敏感工作中请停用。

## 故障排查

- 宠物不显示：确认正在使用桌面应用并已启用。
- 自定义宠物无效：打开宠物设置查看验证信息。
- 动画被裁切：重新生成或修正宠物包尺寸。
- 状态明显延迟：确认桌面应用连接的是活动 Gateway。

# 手机端

在自己的电脑上运行 xopc，用手机继续同一份工作。电脑保存工作区和会话，手机负责查看、补充要求和处理工作。

## 下载与平台差异

| 平台 | 当前获取方式 |
| --- | --- |
| Android | [官网移动端下载](https://xopc.ai/zh#mobile-download)或 [Android Releases](https://github.com/xopcai/xopc/releases?q=mobile-android)中的 APK；发布页附有校验文件 |
| iOS | 以[官网当前分发渠道](https://xopc.ai/zh#mobile-download)为准，不代表已在 App Store 全面上架 |
| HarmonyOS | 官网目前标为内测，暂未开放公开下载 |

同时更新手机与电脑。各平台录音、通话、后台运行和媒体能力可能不同；配对成功不代表功能完全相同。手机是连接现有 xopc 实例的客户端，电脑休眠或网关退出会中断连接。

## 连接工作电脑

1. 在电脑上打开 xopc，点击侧栏的 **连接手机**。
2. 如尚未开启远程连接，按向导完成授权和开启；已有 HTTPS 或 Tailscale 连接可直接使用。
3. 在手机上选择 **扫描二维码**。
4. 比对两端数字，在电脑上选择 **允许连接**。
5. 手机自动进入工作首页。

二维码 10 分钟内有效。扫码后的电脑确认需在 2 分钟内完成；超时后刷新二维码。二维码不能代替电脑确认，也不包含长期访问凭据。无法扫码时，可使用向导中的临时配对链接。

## 离开电脑后

电脑需保持运行并联网。桌面应用可选择 **关闭窗口后继续运行**，之后从托盘返回；退出 xopc 或电脑休眠会中断连接。这个选项不会保证合盖后仍在线。

在手机的电脑设置中选择 **测试连接**。关闭 Wi-Fi 后再测，可检查当前移动网络；检测不到网络类型时，结果只显示“当前网络可用”。测试同时检查授权请求和实时工作连接，不代表以后始终可达。

## 断线与待发送内容

- 暂时断线时保留当前页面；手机上的待发送内容在恢复连接后重试。
- 待发送消息按电脑隔离，附件保存到应用持久目录。不要卸载应用或清除应用数据。
- 超过一天、会话重置、附件缺失或请求被拒绝时，内容保留并提示检查；可重试、复制或移出队列。
- 旧版未标记电脑的队列内容只供检查和复制，不自动投递。
- 移出队列只停止本机后续重试，已经提交的工作可能继续。

在 **设备** 中可撤销手机访问。撤销后，手机需重新扫码并获得电脑允许；原工作内容仍保存在电脑上。

## 故障排查

| 提示 | 操作 |
| --- | --- |
| 暂时连不上电脑 | 确认电脑运行、未休眠，远程连接可用 |
| 请更新电脑版 | 更新 xopc，再生成新二维码 |
| 在电脑上确认 | 检查数字并点击允许；超时后刷新二维码 |
| 有一条消息待检查 | 查看原内容；会话已重置时复制到目标会话重新发送 |
| 无法确认电脑身份 | 从目标电脑重新生成二维码，不更改证书或填写共享密钥 |

高级网络配置见[远程访问](./remote-access.md)。

## 日常入口

手机端采用助手、对话、进展、笔记、我的五个主要入口。先从助手交代工作，再到对话继续已有聊天；进展用于查看任务和需要你处理的事项，笔记用于保存资料，我的用于检查连接与偏好。

在支持资料引用的版本中，聊天加号菜单可以引用笔记、任务或添加文件。引用前核对当前工作电脑和资料范围。图片可打开预览；需要 Agent 理解图片时，还需配置兼容视觉模型。语音功能和权限见[语音指南](./voice.md)。

Android、iOS 与 HarmonyOS 的具体能力会随版本变化。更新客户端与工作电脑后，以当前界面为准；配对成功不代表所有录音、后台或媒体能力已经通过当前设备验证。

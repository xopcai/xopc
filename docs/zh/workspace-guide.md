# 在工作空间处理文件与项目

把资料和目标带入 xopc，检查成果，再把有用背景留在项目中。可以直接从聊天或 Project 开始，无需先和 Ada 讨论。

## 开始前

连接可用模型，并选择你有权处理的资料。工作空间属于运行网关的机器；本地路径指那台机器上的路径，从其他设备上传附件是另一种方式。

Office 文件和专业工作需要对应[技能](./skills.md)与[工具](./tools.md)。视觉、图像生成和语音各自需要兼容服务。

## 先完成一个小文件任务

1. 打开聊天，或从 Project 开始对话，把相关工作放在一起。
2. 添加附件，或提供授权工作空间路径，说明哪些文件允许修改。
3. 说明成果和检查方式：

```text
读取这些销售资料，在工作空间中生成汇总。
原始文件保持不变。按月列出总额、计算规则，
把缺失或冲突的数据放进异常项清单。
返回保存路径，并说明如何核对总额。
```

4. 打开交付文件，抽查关键数字与来源，检查异常项。
5. 针对已有成果提出修改，再打开修改后的结果。

预览正常或 Agent 执行成功，不代表内容一定正确。需要后续编辑时，明确要求可编辑的表格或演示文稿格式，并确认工具支持该格式。

## 下次从已有进展继续

Project 用于共享文件、对话和背景；结果、阻塞或下一步需要长期保留时创建 Task；参考资料可以保存为笔记。小请求无需同时创建这三类对象。

回来时可以说：“结合这个项目的笔记、任务和最新成果，告诉我哪些已完成、哪些被阻塞，以及下一件最有用的事。”确认来源和状态后再继续。

代码项目在界面提供选项时，可以选择本地环境或新本地 worktree。本地指网关所在机器；新 worktree 不会复制未提交修改。详见[聊天与会话](./session.md)。

## 常见问题

| 问题 | 检查项 |
| --- | --- |
| 无法读取路径 | 网关主机上的路径、资料权限、所选工作空间 |
| 无法生成所需格式 | 已安装技能、工具与格式要求 |
| 文件数字错误 | 原始输入、计算规则和异常项，并要求纠正 |
| 换设备后缺少项目背景 | 是否连接同一网关并打开同一 Project |

[实战教程](https://xopc.ai/zh/learn)包含销售表格、可编辑演示文稿、提案和研究。练习材料为虚构资料。继续阅读 [Project、Task 与笔记](./projects-tasks-notes.md)、[任务验收](./task-review.md)和[数据与文件位置](./workspace.md)。

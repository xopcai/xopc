# Web 笔记与录音体验验收（2026-10-16）

本轮验证新建笔记、录音、结束保存、查看原文、证据回听，以及窄屏离线后的同步重试。验收发现的问题已直接修复；未运行鸿蒙真机测试。

## 发现与修复

| 问题 | 调整 |
| --- | --- |
| 实际笔记首页的录音入口藏在 Agent 输入区 | 首页直接提供“新建空白笔记”和“开始录音”，Agent 输入降为次级入口 |
| 空笔记标题与预览重复，录音列表暴露自动生成的 Discussion 标题 | 空标题显示“未命名笔记”，自动录音标题显示本地化“语音笔记”，保留用户自定义标题 |
| 请求录音设置时短暂显示“已停止”，连续点击可能重复启动 | 增加准备态和启动互斥，确认按钮等待请求完成 |
| 正常离线录音同时显示离线状态和泛化错误 | 后台同步错误与采集、保存、重点操作错误分开，离线时保留明确的本机保存提示 |
| 录音笔记存在外层与内层两套工具栏 | 录音视图保留单套标题、搜索和更多菜单；分析、对话、分享、历史和删除收进更多菜单 |
| 打开已保存的录音笔记后，结束浮窗重复提示 | 原音确认后自动收起已打开结果的浮窗；尚待同步或重点保存失败时保留入口 |
| 概览证据入口使用技术化名称 | 改为“查看原话”，继续沿用版本化证据定位与区间播放 |
| 编辑器注册重复 trailingNode 扩展 | 关闭 StarterKit 默认扩展，保留项目现有的自定义实现 |

## 浏览器验收结果

以下 7 项通过，浏览器未捕获运行时错误：

1. 从生产 NotesPage 创建空笔记，通过实际 Notes 路由保存。
2. 修改标题和正文，确认自动保存结果已经写入独立 SQLite。
3. 使用浏览器 MediaRecorder 录制，完成标重点、暂停、续录、结束，确认本机保存屏障后才显示可离开提示。
4. 服务端确认原音后能实际播放；切换概览与原文时，播放器节点及播放位置保留。
5. 从概览“查看原话”请求实际证据接口，再播放对应原音区间。
6. 每次录音保持一个 Discussion 和一个 Note，重试不会重复创建。
7. 390px 窄屏下离线录制，完成缩小、拖动、标重点、暂停、续录和本机保存；联网重试后能搜索原文、回听重点，刷新仍沿用同一 Note。另检查 320px 详情布局无横向溢出。

两段原音时长分别为 7.02 秒和 7.68 秒，均已确认附件标识与 SHA-256。截图、请求记录和结果报告位于 `/tmp/xopc-notes-journey-final/`。

## 验收边界

脚本挂载生产 NotesPage、NoteDetailPanel 和全局录音面板，使用真实 Notes/Discussions Hono 处理器、独立 SQLite、文件存储、浏览器 MediaRecorder 和 IndexedDB；原音经过真实提交与解码确认。

外层应用壳为验收专用布局，认证使用仅限本地夹具的 HTTP-only cookie 注入身份，未启动完整 Gateway 的登录及懒加载链路。无关自动化接口未挂载，会返回 404。麦克风使用合成音频输入，AI 转写与整理结果由可控边界注入，因此本轮不代表硬件麦克风、真实供应商或数小时长录音专项验收。未修改或测试鸿蒙端。

# 浏览器录制与回放移除记录

日期：2026-11-03。

移除范围为固定网页流程的录制、参数化步骤保存、回放和独立管理页面。保留 Agent 临时操作网页的 `browser_use`、浏览器驱动、扩展聊天、页面与选区上下文、桌面内嵌浏览器以及浏览器连接和设置。

## 原有能力与取舍

原功能支持扩展录制点击、输入、选择、复选框、按键和导航；保存最多 100 步的线性 JSON 流程；参数化输入、语义目标定位、域名约束、结果断言、输出提取、版本和运行历史；通过对话、管理页面或通用自动化调度执行。

其独立价值是无需模型逐步决策即可复用固定路径，但页面变化、登录失效仍需维护，没有分支、循环或自动修复。录制默认不生成业务成功断言，保存后仍需补充验证才能接入定时任务。此次收缩产品范围，移除这套独立产品和执行链路。

## 清理内容

- 删除浏览器流程定义、执行器、服务和存储访问模块，移除 Agent `browser_automation` 工具及服务注入。
- 删除 `/api/browser/automations`、`/api/browser/automation-runs`、`/api/browser/recordings` 的处理器及专用 lazy matcher。
- 删除扩展录制面板、页面事件捕获、IndexedDB 录制代码、后台同步及 `browser.recording` 端点工具。
- 删除 `#/browser-automations` 页面、导航、预加载、通用自动化中的浏览器动作选项及关联文档入口。
- 保留基础控制使用的语义 DOM 定位方法，归入 `dom.ts`。

## 数据与兼容边界

不保留旧浏览器任务的数据类型、读取分支、启动迁移、自动停用、只读展示或扩展清理逻辑。旧动作不在当前自动化契约中，不再支持读取或执行；存在旧任务的数据库可能在读取这些记录时被当前校验拒绝。本次开发未操作用户本机数据库。

新建数据库不再创建该功能的表和索引。历史 SQL 升级链保持原样，避免破坏其他功能的数据升级路径；已有历史表不再有浏览器流程运行代码访问。扩展不再采集、同步或回放录制数据，也不再包含处理旧版本闹钟的分支。

## 替代路径

需要重复网页任务时，在通用自动化中创建 Agent 指令，由 `browser_use` 操作网页。该方式需要模型推理，成本和执行时间可能增加，也不具备固定步骤回放的确定性；有官方 API 的任务优先通过连接器或 MCP 完成。

# P3e 远端文件快照与显式回传

远端文件的标识始终是Gateway资源ID与版本，不能作为本机路径、PTY工作目录或本机工作区授权。首轮仅支持32 KiB UTF-8文本，与现有Gateway文件API复用；大文件由P4独立传输能力完成，不扩张Endpoint帧预算。

Main在当前profileId、Gateway身份公钥和连接epoch下读取元数据及内容；要求内容ETag与所选资源版本一致，拒绝下载过程中已变化、非文本、超限或无编辑权限的资源。Main生成随机快照UUID，缓存正文和元数据一起用OS安全存储加密。Renderer只能提交该UUID和文本，不提交本机路径。快照在当前连接中使用，切换不能污染新连接；重启后可显式打开同Gateway的草稿，不恢复任何上传动作。

编辑仅更新本机加密缓存。每次回传需用户显式操作和原生确认，显示Gateway、文件名、资源ID、原版本、内容摘要和变更大小。Main先持久记录上传中，再发送一次包含原版本的现有PUT请求。409保留草稿并显示冲突，不覆盖或自动重试；网络中断/超时、Main崩溃或无法持久化完成记录均保持结果未知，不能自动重发。上传中记录在读取恢复时转为未知，不转为失败或成功。用户需重新读取服务器副本并核实效果，再创建新的编辑意图。

本机缓存不执行下载内容，不自动调用openExternal，不自动清理脏草稿或未知回传记录。每个Gateway最多20份有界文本快照；达到上限要求显式管理，不能静默删除恢复证据。正式开放前覆盖真实认证API、版本冲突、丢回执、切换、加密与安装包本地回归。现有本地文件和PTY路径不改。

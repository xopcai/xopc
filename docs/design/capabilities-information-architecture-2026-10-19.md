# 能力管理的信息架构与交互

## 页面职责

- 插件与扩展：整套能力的安装、准备、授权、更新、停用与卸载；默认全 Agent 可用。已有安装时优先显示已安装列表。
- 连接：按账号与所属插件展示状态，一个插件一个入口。本地无授权工具不计入连接，不猜测凭据字段。
- 技能：展示具体使用方法、可用状态与来源。独立技能可单独管理，插件技能由插件统一更新和卸载。

## 连贯的使用路径

技能卡片与详情标明所属插件，使用可读名称，运行时仍保留唯一命名空间。尚未完成准备或已停用的插件技能可查看，不向运行时加载。缺授权时主操作进入所属插件的声明式账号表单。

从技能进入插件保留筛选和搜索，从连接进入插件返回账号列表。返回目标仅允许能力中心已知的内部列表路由。插件详情提供开始使用、账号管理与可点击的技能清单。直达授权只打开表单，不自动扩权或提交凭据。暂时跳过后仍保持待授权，可从列表重新进入。

## 参考与取舍

实际查看 Accio 的 Plugins / Skills 页面，参考其插件聚合能力、技能展示与状态入口。XOPC 不引入 Agent 绑定安装步骤，账号授权由插件统一管理，不让插件技能独立卸载。

## 验证

自动测试覆盖目录与运行时隔离、只读预览、来源和状态、受控返回路径及直达 Token 表单不自动授权。真实 Gateway 验证插件技能可预览且单独卸载被拒绝。浏览器验证技能到所属插件及返回原筛选、连接到授权及跳过后的恢复路径。

本轮仅更新 XOPC 客户端与 Gateway，不修改 Store 资源或账号授权数据。

# 设置复杂度审查与分层建议

审查日期：2026-10-12。状态：源码审查与建议；2026-10-12 已实施显示层优化，见末尾实施记录。

范围：Gateway Web 设置导航、普通/高级模式、智能体全局设置及单独覆盖、模型/图片/语音/搜索、浏览器与电脑控制、远程访问、运行环境、会话、追踪，以及能力中心的渠道配置。依据当前源码；未对运行中的界面做交互验收，也没有读取或修改用户本机凭据。

## 结论

应当把更多低频部署和执行调优选项放进高级模式。保留用户能理解其结果的设置：选择模型、授权工具、控制费用、连接设备、远程访问、通知、隐私与数据管理。

当前的复杂度来自三处：导航入口多；一个页面同时提供功能选择与底层调参；“高级”既用于全局显示模式，又用于页面内折叠，边界不一致。只移动导航不足以解决问题。

## 已核实的现状

| 层级 | 源码现状 | 影响 |
|---|---|---|
| 设置导航 | `web/src/navigation/index.ts` 定义 19 个固定入口，Electron 另加 3 个；实际数量还受平台能力影响。简洁模式仅隐藏固定入口中的日志 | 普通/高级两种模式的导航差异很小 |
| 路由限制 | `settings-nav-visibility.ts` 仅限制日志、扩展 debug 与扩展自定义设置路径 | 运行环境、追踪等部署诊断页面仍可见 |
| 网关页 | 普通模式显示网络、访问；高级模式增加更新、安全、高级 | 技术参数已有部分分层，但更新开关也随整页签一起隐藏 |
| 全局智能体 | 模型、技能、工具、运行四分区均可访问，没有接入高级模式 | 任务模型路由、回退链、缓存、Codemode 和执行限制全部可见 |
| 单独智能体 | `agents/agent-editor.tsx` 也提供图片超时、运行限制及缓存覆盖 | 仅改全局设置会留下另一个复杂入口 |
| 浏览器 | 页面理解、执行限制和访问策略整体由高级模式控制 | 技术参数分层较好，但文件上传及高影响动作权限也被藏起来 |
| 语音 | 普通模式只隐藏诊断分区；服务中的技术项、自然对话高级设置仍能展开 | “高级”文案与全局显示开关不一致；必需凭据和调优项需要分别处理 |
| 运行环境 | 下载来源、离线包、代理已经高级化；版本、来源优先级、预装策略仍直接展示 | 普通用户仍需理解 Node/Python/uv 的管理策略 |
| 会话 | 同时提供会话管理、压缩策略与存储/路由配置 | 压缩已有预设，但阈值、Token 数、摘要模型、质量保护及缺口审计仍在普通模式 |
| 远程访问 | 指南、Tailscale、公网、反向代理、SSH、局域网六个页签均显示 | 产品需求与部署方式平铺，用户要先理解多种技术路线 |
| 渠道 | Schema 分出基础字段和高级字段，但高级字段通过普通 `details` 展开 | 能力中心有自己的渐进展开机制，未统一到设置模式 |
| 搜索 | 字段索引直接导航到页面；路由索引另行按模式过滤 | 下沉后需要防止“搜索命中，但跳转被拦截/找不到字段” |

## 分层标准

普通设置回答“我想要什么结果”；高级设置回答“系统具体怎样执行”。

- 普通：首次使用所需、经常修改、关系授权/隐私/费用、直接影响用户体验。
- 高级：有可靠默认值、低频修改、需要了解协议/路径/Token/毫秒/队列等技术概念。
- 按需：选择某个服务或连接方式后必填的凭据与地址。这些字段即使技术性强，也不能因高级模式而阻断连接流程。
- 状态与配置分开：已启用、出错、使用自定义策略的状态可以普通可见；具体调参入口放高级。

## 页面级建议

| 页面 | 建议 | 普通模式保留的入口或内容 |
|---|---|---|
| 运行环境 | 整页放高级，优先实施 | 总览中显示依赖状态；缺失依赖时提供安装/修复入口 |
| 运行追踪 | 整页放高级，优先实施 | 普通任务页面保留执行结果、失败原因；启用详细采集或远端导出时提供隐私状态摘要 |
| 日志 | 维持高级 | 错误页面可以定向进入排障 |
| 本机服务 | 先拆出连接状态、重新连接与更新操作，再把部署编辑放高级 | 服务运行状态、认证异常恢复、检查更新与自动更新开关 |
| 会话 | 保留普通入口，内部字段分层 | 查看、搜索、归档、导出、删除、数据保留规则、压缩预设 |
| 设备、远程访问、分享 | 保留普通入口 | 配对、撤销访问、连接状态、分享范围与有效期 |
| 浏览器、电脑控制 | 保留普通入口 | 启用、连接、授权范围、查看/撤销授权 |
| 模型、语音、搜索、智能体设置 | 保留普通入口，缩减默认表单 | 完成配置和选择能力所需字段 |
| 外观、快捷键、桌面系统、桌面宠物、桌面应用、导入、用量 | 保留普通入口 | 用户偏好、数据迁移和费用查看；低频本身不足以判定为高级 |

本机服务不能直接整体隐藏：连接恢复仍依赖它，且普通更新开关当前已经被藏在高级页签中。应先提供替代普通入口。

## 字段级建议

| 区域 | 普通保留 | 放入高级或进一步收起 |
|---|---|---|
| 智能体模型 | 默认对话模型、图片理解/生成选择、有效配置摘要 | 六类任务意图路由、回退链编辑、图片生成超时及自动服务商回退 |
| 工具 | 允许/询问/禁用，先按用户任务分组展示 | 每轮调用次数、单次超时、逐工具技术标识的细节列表 |
| 技能 | 选择默认可用技能与继承状态 | 完整目录自动纳入等策略说明可按需展开；不要整页隐藏 |
| 单独智能体 | 身份、模型、能力选择、权限、费用限制、继承摘要 | 与全局一致的模型路由、回退、缓存和运行参数覆盖 |
| 压缩 | 启用、平衡/保留/提前预设、自定义状态 | 触发阈值、预留 Token、保留轮数/Token、摘要模型、质量保护/缺口审计调参、当前高级区域 |
| 会话存储/路由 | 自动清理时间及清理结果说明 | 最大条目数、DM scope 路由规则；已有自定义时显示摘要 |
| 浏览器 | 推荐连接方式、启用、文件上传及高影响动作权限 | Chromium 路径、CDP/远程自定义连接的配置入口、节点/字符上限、超时/步骤上限、精确私网主机列表 |
| 浏览器特殊连接 | 选择或已使用 CDP/远程方式后，必要地址及凭据仍可编辑 | 将“选择特殊连接方式”放高级；普通模式显示当前连接及更改入口，不能显示成空值 |
| 语音 | 服务选择、必需凭据、语言、音色、设备、字幕、节奏预设、测试 | 自定义 endpoint、独立凭据覆盖、自然对话指令覆盖、STT fallback 与技术参数 |
| 语音 TTS | 必需的模型/音色/凭据等连接字段 | 先拆解现有“高级”字段组，再隐藏真正的技术字段；不能把整个 `VoiceProviderConfigFields` 一起隐藏 |
| 搜索 | 开关、服务商/凭据、地区；被屏蔽站点状态及管理入口 | 结果条数等调参；域名黑名单编辑可按需展开，不宜因技术配置一并失去可见性 |
| 模型服务商 | 登录/API Key、服务状态、可用模型 | 请求覆盖、手工模型参数等；自定义服务的必填地址按需显示 |
| 远程访问 | 连接向导、局域网/推荐连接、公网开关及访问控制、当前地址 | 反向代理、SSH 命令、自定义部署参数；Tailscale 安装可按需引导 |
| 运行环境 | 总览只显示就绪/缺失及修复 | 版本固定、system/managed 来源优先级、eager/on-demand 预装策略、下载源/代理/离线包 |
| 网关 | 当前连接状态、重新连接、更换凭据、安全状态 | 监听端口、绑定接口、自定义 host、CORS、可信代理、限流细节、跳过/延迟连接渠道、安全逃生开关 |
| 更新 | 检查更新、启动时检查、自动更新开关 | beta/dev 渠道、稳定版延迟/随机延迟、beta 检查周期 |
| 渠道 | 连接凭据、收发开关、私聊/群聊访问控制、路由到哪个智能体 | 其他 Schema 高级字段；先检查插件 basic/advanced 标注，防止把必要连接字段隐藏 |

## 交互与实现约束

1. 复用现有 `settings-mode-store` 与 `SettingsAdvancedGate`；页面折叠和高级模式各司其职。一个高级字段组不应只靠写“高级”两个字。
2. 普通模式显示“已使用自定义配置”摘要和明确的“查看高级设置”入口。切换显示模式不会关闭功能、恢复默认值或改变运行行为。
3. 隐藏字段仍保留在 draft 与保存 payload 中。现有全局设置按完整 snapshot 保存，字段下沉不能引入隐藏字段被省略、重置或覆盖的行为。
4. 高级页面深链接不能无说明跳回总览。建议展示该页用途和“显示高级设置并继续”；设置搜索可保留带“高级”标记的结果，选择后再切换并定位。
5. 同步普通/高级模式的 tab、URL query 与当前已选值。当前绑定方式或认证模式若属于高级选项，普通界面仍应显示真实配置。
6. 全局设置和单独智能体覆盖遵循同一字段分层。能力中心中的编辑器应使用一致的显式展开入口，不应依赖一个不可见的全局开关而让配置无法发现。
7. 授权、费用、数据保留、采集/外发隐私状态保持可发现。危险技术开关可以高级化；授权管理和撤销入口保持普通可见。
8. 不改配置 Schema、默认值、存储位置及 API 行为。先做显示层与入口整理，避免将界面简化和配置迁移混在同一变更。

## 建议实施顺序

- 第一批：运行环境/追踪导航下沉；全局与单独智能体的路由、回退、缓存、超时高级化；压缩数值调参下沉。先实现深链接与搜索兜底。
- 第二批：语音必需连接字段与技术项拆分；远程访问向导和高级部署方式分层；浏览器权限从技术调参中分离；渠道高级区域统一入口。
- 第三批：本机服务拆分，把连接恢复和更新放回普通路径，再下沉部署页；按真实使用反馈收敛导航分组。

验收重点：普通模式可完成首次配置和日常工作；高级模式能编辑全部既有字段；切换模式无配置写入；普通编辑后隐藏的自定义值仍保持；搜索、收藏深链接、前进/后退和已选高级值可正确恢复；安全与费用控制容易找到。

## 实施记录（2026-10-12）

已按普通页面独立完成操作的约束实施：

- 普通导航隐藏运行环境与运行追踪；高级深链接保留目标并提供继续入口，切换模式保留页面草稿。
- 总览增加执行环境状态和安装/修复操作，使用现有版本策略，不写入配置。
- 会话保留压缩预设、数据保留时间和管理操作，数值压缩策略、路由与条目上限进入高级。
- 浏览器保留全部连接方式及必要字段，普通可编辑上传、高影响动作和跨域权限；自定义路径及观察/执行限制进入高级。
- 远程访问收起反向代理和 SSH 选项；已选方式及状态入口仍能直接访问，其他连接流程保持完整。
- 本机服务保留连接恢复、凭据、重启及更新；监听参数进入高级，安全审计普通可见，现有特殊认证/更新渠道仍显示真实值。
- 语音保留服务、必需凭据、音色和测试，收起非必需的次数/超时、STT 回退、自然对话地址及指令覆盖；搜索保留域名屏蔽管理。
- 渠道高级 Schema 接入高级显示模式；必需字段、故障字段及私聊/群聊授权字段保持基础可见。
- 设置字段搜索定位具体分区，选择高级字段后再展开；模式切换本身不写后端配置。

验证：设置、导航与命令搜索相关组件测试；Web TypeScript、ESLint 与生产构建。未修改配置 Schema 或运行时默认值；此次未进行真实账号和设备的人工交互验收。

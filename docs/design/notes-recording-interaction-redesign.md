# 笔记与录音界面交互优化

2026-10-16

## 设计依据

参考 Apple HIG 的 [Disclosure controls](https://developer.apple.com/design/human-interface-guidelines/disclosure-controls)、[Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars) 和 [Layout](https://developer.apple.com/design/human-interface-guidelines/layout)：内容优先，工具栏保留常用入口，相关详情按需展开。视觉继续使用仓库现有语义色、字体和组件。

## 已落地的信息层级

| 场景 | 默认呈现 | 按需展开 |
| --- | --- | --- |
| Web 笔记列表 | 搜索、创建、直接开始录音；列表与详情分栏 | 原有采集菜单与列表收起入口 |
| 鸿蒙笔记列表 | 笔记列表、搜索与新建；有待恢复录音时显示单行数量入口 | 待恢复列表、恢复、导出、丢弃 |
| 录音笔记详情 | 标题、时长；概览／原文／标记；正文；固定播放器 | 搜索框、笔记工具、章节与处理范围 |
| 概览 | 已完成摘要、重点结论、行动；未完成时先展示已有录音摘录 | 编辑、证据、后续处理详情 |
| 录音结束 | 本机保存结论和简短处理状态；失败重试直接可见 | 保存、同步、转写、笔记的详细说明与可用范围 |

Web 移除外层“会议／我的笔记”切换。个人补充移到更多工具中，返回录音笔记有明确入口；切换到补充后聚焦标题，沿用同一 Note。

Web 更多工具分为整理、导出与分享。模板和重新生成不再常驻标题栏；MD/TXT/SRT、下载原音与带到新对话集中在同一个入口。鸿蒙用现有单一底部面板承载整理工具与证据，避免叠加多个模态。

## 内容与状态

- 处理状态收敛为一行，可展开查看保存证明、已可用内容与失败原因。录音结束后的“本机保存完成、可以离开”保持直接可见；首屏不再重复多段相同进度说明。
- 失败后的同步、转写与笔记重试保持在状态行附近，无需先寻找工具菜单。
- 概览先呈现内容，章节和处理范围随后出现。未生成章节时不再展示空目录、重复的待处理说明和大块占位。
- 搜索按需展开，Web 支持当前笔记中的 Command/Ctrl+F；关闭搜索清除筛选。三个内容入口切换时保留同一播放器和播放位置。
- 默认不展示“显示已忽略项”，仅在实际存在已忽略内容时出现。旧笔记的普通重点结论恢复展示，不虚构对应证据。
- 未整理前的系统时间戳标题呈现为“语音笔记”；用户自定义标题与存储值保持原样。

## 鸿蒙统一录音浮窗

### 信息层级

笔记页全屏录音界面与其他页的简略状态条统一为 Home Navigation 上层的一份应用内浮窗，页面切换不重建录音会话。

展开：真实采集状态、时长及声音输入优先；连续本机保存范围显示一行；云端备份、文字与笔记进度按需展开，实时原文单独折叠。中断、存储失败、重点保存失败与仅前台录音的提示仍保持可见。停止后仅在原有本机保存屏障完成时显示已保存成功。

缩小：时长、真实录音状态、保存提示及标重点、暂停/继续、结束按钮保留。无真实输入时禁用标重点；暂停仍保留按钮但禁用标重点，恢复后等待采集确认再开放。保存中禁用重复操作；恢复场景的结束位置改为重试保存。

### 移动与尺寸

拖动仅绑定在 44vp 的六点移动手柄，正文滚动与核心按钮不参与拖动。轻触手柄可选择四个角落，提供不依赖拖动的操作方式。结束/取消手势后抑制随后误触，取消时回到起点。

浮窗位置限制在 Home 的可用布局范围内，四周保留 12vp。沿用应用系统安全区及 KeyboardAvoidMode.RESIZE，窗口、旋转、键盘改变可用尺寸时重新限制边界；尺寸变化会废弃旧拖动偏移。窄屏缩小模式将操作放到独立一行，保持 44vp 点击范围。展开面板的文字区域内部滚动；矮窗口仍能展开。位置菜单临时替换正文，避免被底部控件裁切。

浮窗状态由 Home 持有，缩小/展开与导航保留位置；新录音默认展开。它不拥有麦克风、不停止录音、不清理本地音频。三个动作调用现有 DiscussionCapture，会话、原音落盘、持续上传和恢复沿用原实现。结束操作额外防重入，只在同一会话完成后导航到原 Note；失败时保留恢复入口。

### 验证

- 控制器主机测试：两种模式的动作一致性、无输入/暂停/停止状态禁用、重复结束与失败重试、手势偏移/取消、点击替代操作、窄屏/横屏/键盘尺寸变化与边界、矮屏展开和位置菜单。
- 真实 SQLite 故障测试：录制过程中移动/缩小/展开/标记/暂停/继续后仍写入同一会话；重复结束只提交一次；磁盘写失败后的连续原音前缀保留并可恢复到同一 Note；标记写失败不停止原音。
- ArkUI 接入、原有录音恢复与主机回归、Release 未签名 HAP 编译、配置的 CodeLinter 静态检查。
- 不运行鸿蒙真机、不执行安装或设备操作。本批没有真机触控、字体缩放或长录音的视觉/性能验收结论；这些仍是后续设备验收项。

## 当前 S4 修订

远端入口直接定位打包契约要求的 `app.asar.unpacked/out/preload`，避免通过共享资源解析器改变原本地 main 的打包依赖图。本地 `main.js` 重建后与原 main 对照字节相同；这只证明构建耦合已消除，性能结果仍以完整采样为准。

本批140项回归和新版安装包本地/远端fixture E2E通过。串行性能对照中候选6/8、原main8/8，候选两项就绪P95仍超原预算；原生恢复实际点击仍被CUA绑定/超时阻断。未进入S5或开放Host。完整结果及失败见[继续开发证据](./evidence/electron-gateway-s4/continuation-20261031/README.md)。

历史 S4 报告中的“不推进 S5/Host”描述原阶段的实施边界。后续范围以本文和[完整方案](./electron-local-remote-gateway-plan.md)为准；历史测试结果不追溯修改。

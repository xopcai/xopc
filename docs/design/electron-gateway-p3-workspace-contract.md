# P3 本机工作区契约与实施边界

本批按已批准的完整方案继续实施。P2b 的故障恢复验收与 P3 开发可并行，未通过的原生验收仍保留为未完成项。本文件不表示 P3 已实现或通过验收。

## 目标与授权

服务器上的默认 read/write/exec 继续作用于服务器。访问本机必须使用显式设备来源及 `deviceId + workspaceId + relativePath`；工作区的绝对目录仅保留在 Electron Main 与本机执行器，不加入工具参数、Gateway 配置或远端响应。

工作区首次由本机原生目录选择器选定，随后给出绑定 Gateway、设备、目录、工具集合与有效期的原生授权。目录选择不自动授权命令、浏览器或文件写入；每次产生副作用的操作仍须独立批准。切换、锁屏、暂停、退出、撤销、授权到期均停止执行并销毁工作区句柄。重新连接不能恢复失效授权。

## 文件执行器

文件工具使用受控的目录句柄逐级解析路径。只进行字符串前缀或 realpath 检查不足以防止检查之后替换符号链接，因此不能作为执行边界。路径拒绝绝对路径、空组件、点目录、上级目录、NUL、反斜线；中间组件和最终文件均不跟随符号链接。拒绝特殊文件和多硬链接文件；不跨越已授权目录句柄访问其他路径。

macOS 使用同一 Electron 进程内的独立 Worker 与 N-API 文件适配器，授权期间持有目录 FD。同步系统调用只在 Worker 中执行，不阻塞 UI。执行器不接受 shell、任意 URL 或新的绝对路径。避免使用在 Main 崩溃后可能继续运行的独立文件子进程；Worker 与 Main 共享进程退出及 OS 执行锁的生命周期。其他平台在具备相同保证的适配器和测试之前明确禁用此能力，不能退回不安全的路径访问。

首轮普通文件传输保持有界文本（32 KiB UTF-8）和目录结果数量；大文件通过 P4 独立传输能力扩展，不改变现有 Endpoint 消息或截图上传限制。读取返回内容和内容版本；写入必须提交已读版本，创建必须明确预期不存在。发生冲突返回冲突状态，不覆盖或自动重试。外部编辑器不参与本机锁，不能宣称这些版本检查构成操作系统级全局 CAS；写入策略必须在接口与测试说明中准确说明并发边界，并保留恢复所需证据。

所有文件副作用继续使用 P2b 的稳定 operationId、持久意图、回执、未知结果和执行器监督。取消或关闭执行器必须等待 Worker 实际退出，不能把调用 terminate 当成停止证明；阻塞的原生系统调用导致等待超时，则保持停止未确认，不交出执行锁。旧操作永不因为重新授权而被重放。

## 后续子阶段

1. P3a：目录句柄执行器、严格参数契约、路径/链接/特殊文件/版本冲突/限额测试；尚不暴露远端工具。
2. P3b：本机原生目录与能力授权、设备工具登记、读写接线、真实 Gateway/Agent 与安装包 E2E；本地默认入口回归。
3. P3c：结构化命令和进程树监督。采用独立能力与原生批准，不能从文件授权推导；命令退出不直接证明所有后代停止。
4. P3d：复用现有 Browser/Computer Broker 的专用控制协议，设备/会话/执行权显式绑定；不能开放通用 Electron IPC。
5. P3e：远端文件快照下载、显式编辑回传及版本冲突。远端绝对路径不得直接交给本机文件 API 或 PTY。

## 验收

每个子阶段保留首次失败与修复后结果，不调整旧预算。必须证明路径越界、符号链接替换、设备/工作区串用、版本冲突和过期授权被拒绝；断网、取消、崩溃与结果丢失不会自动重复副作用。原生授权和真实本机效果单独验收，注入批准与合成执行器的测试不能替代。每轮安装包验证本地新启动、复用、聊天、IPC、退出/重启及远端恢复。

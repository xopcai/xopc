# 模型与能力 P1 交付与验收

日期：2026-10-16。P1 已实现并完成复审；本页集中维护能力总览、同页设置、入口收敛与体验走查的交付记录。完整调用验证记录、验证失效规则及更细参数编辑仍属 [P2 设计范围](./model-capabilities-experience-proposal.md)。下列测试结果属于当时批次，不是本次文档整理重新执行的结果。

## 最终交互与配置边界

- 模型首页按文本、图片、语音、后台四组呈现七个用途。已连接能力直接显示模型选择器，切换只应用当前用途；未连接时提供“连接服务以启用”，进入当前用途的服务页签。
- “设置”和“管理服务”打开同页固定尺寸弹窗，分为“模型与参数”“管理服务”；从入口定位相应页签，切换页签保留编辑状态。同一能力关闭重开保留服务草稿，换能力开始新表单；关闭恢复焦点、页面操作与滚动。
- 已连接服务优先展示，“添加服务”按需展开。默认复用已有连接，选择具体模型后应用；更换 Key 单独展开，并说明同服务其他模型也会使用新 Key。连接成功但应用失败回到已保存连接摘要，保留具体模型选择与草稿。
- 通过“连接并用于…”显式保存连接并应用当前用途；单独连接服务不启用能力、不改派模型、不发送生成测试。“已选择”“已配置待验证”不冒充供应商调用已通过；失败显示重试，技术原因收进详情。
- 语音设置区分录音与听写、文字转语音、实时语音对话，复用已有参数和测试控件。听写报错及聊天中的语音设置同页打开，关闭保留聊天路由与未发送草稿；高级快捷键打开原链接的行为保留。
- 服务列表提供七种能力入口。录音识别与 TTS 依据注册元数据和后台用途目录过滤，区分共用模型凭据与原生独立凭据，不按品牌猜能力。已有百炼凭据可复用，音色、语言等参数仍属于能力详情。
- 全局模型只在“模型与能力”选择；Agent 默认设置保留摘要与跳转入口，单个 Agent 保留“继承全局 / 单独设置”。任务路由、对话/视觉回退、图片超时及自动回退集中到对应能力，已有配置不迁移、不清空。
- 模型名和服务名分开展示，支持中英文多关键词搜索；隐式 `provider/default` 显示“默认模型”，不擅自替换为推荐项。页签采用 tab/tabpanel、方向键导航；保留语义颜色、减少动态效果和入口焦点恢复。
- 旧用途详情、图片 URL、语音高级入口、设备和搜索设置仍可达，保留目标用途及返回位置。自定义图片连接窗口嵌入当前弹窗，保存期间禁用字段和关闭；不叠加重复编辑器或重置背景滚动。

## 保存、并发与兼容

- 保存期间锁定模型切换、参数编辑和竞争入口，重复点击不重复应用。失败后不因失焦自动重提，允许原地重新加载并保留草稿。
- 语音保存携带按能力划分的不透明版本，网关在写锁内校验；过期请求返回 409。高级模型设置原子校验预期模型快照；Agent 默认页保存技能、工具或运行参数时保留最新全局模型，避免旧页面快照写回。
- `PATCH /api/config` 的局部语音保存显式使用 `voicePatchMode: "merge"`，只合并语音根节点；实时语音发送完整快照。该标记只用于请求，不写入配置。未标记保存范围/版本的旧客户端沿用原接口语义，删除的流式路由不能被合并复活。
- 沿用 SQLite Agent catalog、现有模型默认值、STT/TTS/实时语音、models.json、setup preview/apply 和原生媒体凭据，不新增配置存储。Agent/会话覆盖语义和计费回退保持不变。
- 传统 STT/TTS 凭据独立，本地 TTS 无需 Key，自定义图片沿用原来源接口；未创建连接的 models.json 预设不提前请求目录。后台继续由服务端校验使用范围，交互 Token Plan 不进入后台候选。
- 重新启用相同百炼语音模型保留音色与参数；原生语音换模型选该模型默认音色。图片尺寸、格式遵循当前模型/来源能力，不新增未实现的全局参数。

## 录音与听写

- 开始采集前选择识别方式；已有显式流式配置继续使用。没有流式能力的服务（包括当时百炼订阅）使用录音转文字接口，点击“完成”后回填输入框。
- 鉴权、网络或显式流式配置失败不能自动切换其他服务；识别失败保留音频供重试，取消或关闭后忽略迟到结果。实时语音仍单独配置。
- 采集后固定所选服务，提交前配置变成另一服务时返回 409，不把音频发给新服务。未携带此约束的旧客户端保留原接口行为。

### 模拟与组件验证

初版使用实际 React 组件及隔离 API 数据，setup HTTP 用鉴权 Gateway 路由；未使用真实 Key 或付费调用。同页设置夹具覆盖未连接服务只应用识别用途、保存锁、后台排除交互套餐和旧入口。390px 宽度下弹窗为 366px，窄屏/深色无横向溢出；键盘页签、焦点、滚动、普通关闭和保存动作分别检查。

### 真实网关与供应商验证

- 使用当时本机已认证 Gateway 和保存的 Cloud/百炼凭据，验证仅应用当前用途、语音参数保存/恢复、后台保持 Cloud、看图单独切换、409 不覆盖、旧入口与草稿保留。
- 百炼订阅实际聊天返回指定文本，看图识别红色；TTS 生成音频，页面听写与笔记录音识别数字 4729，笔记原音实际播放；聊天图片工具生成附件，附件可读并展示。
- Cloud 与百炼分别生成语音，再交给同服务识别，数字 4729 正确；标签朗读使用 `[[tts]]`。Cloud 可切换音色，百炼当时单音色保留。
- 服务切换期间固定采集服务的请求返回 409；参数与模型保存分别验证，未隐式回退到 Cloud。测试临时切换值恢复，原有 Key 未替换；不同批次的初始默认值分别保留，不合并解释为同一配置快照。
- 最后的服务页面检查只操作配置，不产生供应商调用；真实媒体证据来自上述独立调用批次。

浏览器麦克风输入使用百炼真实 TTS 音频作为模拟采集源；识别与生成调用真实服务。未新增物理麦克风、实时语音供应商会话或其他厂商真实流式验收。走查不等同于用户研究或品牌质量认证。

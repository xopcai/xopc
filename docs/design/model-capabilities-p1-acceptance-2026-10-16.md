# 模型与能力 P1 交付与验收

日期：2026-10-16。状态：P1 已实现并完成复审。

## 已实现

- 模型首页采用能力总览：文本、图片、语音、后台四组，七个用途。保留直接选择模型，并提供逐项设置入口。
- 能力详情通过 `models?use=...` 定位；服务页通过 `view=services` 保留目标用途。接入成功返回原能力，连接本身不调用模型分配接口；明确选择模型时才应用单个用途。
- 总览、详情、服务页分别保存页面滚动位置。图片旧 URL 映射至生成图片详情；原语音、设备、搜索及高级配置入口继续可达。
- 录音转文字、文字转语音、实时对话分别复用现有语音控件；按用途提交参数，避免其他语音用途被覆盖。参数保存过程中暂停总览模型切换，避免旧表单覆盖新模型；仅查看详情不补写缺省模型或音色。
- 传统 STT/TTS 服务使用原注册表及独立凭据路径；本地 TTS 无需 Key。自定义图片来源继续使用原来源配置与凭据接口。服务连接不启用能力、不改变默认模型、不发送生成测试。
- setup 候选覆盖现有语言、图片及语音注册表；语音凭据就绪不代表聊天凭据就绪。后台沿用服务端使用范围校验，Token Plan 不进入后台候选；单用途切换沿用显式回退规则。
- 状态区分未启用、已配置待验证、已保存但需检查连接或模型；保存连接不等于真实调用成功。

## 兼容边界

沿用现有全局默认模型、STT/TTS/实时语音配置、原生媒体凭据、models.json 和 setup preview/apply，没有新增平行配置存储。Agent 和会话覆盖语义保持不变。保留传统语音完整设置及独立 Omni 覆盖参数作为高级兼容入口。

图片尺寸与格式继续遵循现有模型及自定义来源能力，不新增运行时尚不支持的全局参数。完整的调用验证记录、验证失效规则及更细的参数编辑属于 P2。

## 验证

- 13 个相关测试文件，97 个测试通过：setup 引擎、语音绑定、原生语音凭据隔离、鉴权 HTTP/lazy 路由、语音局部配置合并及现有语音组件兼容性。
- `scripts/verify-model-use-switching.mts`：百炼、XOPC Cloud、其他 Token Plan 的七类用途切换；后台排除交互套餐；冲突保留原选择；键盘操作；390px 窄屏与深色显示。
- `scripts/verify-model-capabilities-p1.mts`：总览到能力详情、连接服务再返回原能力；连接时零模型分配；之后仅分配所选用途；后台范围与旧图片 URL；切换过程锁定语音参数；经旧语音高级设置返回原能力；窄屏无横向溢出。
- 浏览器使用真实 React 组件及隔离 API 数据；setup HTTP 测试启动鉴权 Gateway 路由并通过真实 HTTP 请求。未修改用户实际配置，未使用真实 Key，未发送付费模型调用。
- 根项目类型检查、Web 类型检查、相关 ESLint 和生产构建均验证。构建保留现有分包体积提示。

## 复审修正

- 新能力详情仅使用统一模型选择器；移除重复的语音 Provider/模型选择入口，避免绕过服务端 preview/apply 和保留旧录音模型链。
- 模型切换与参数保存互斥，切换期间暂停详情编辑和页内跳转，避免旧表单覆盖新模型。
- 服务页进入旧语音高级设置时保留目标用途，并可直接返回该能力；连接成功、取消和旧图片 URL 的返回路径均检查。
- `PATCH /api/config` 的新局部语音保存显式使用 `voicePatchMode: "merge"`，只合并语音根节点；实时语音仍发送完整快照。旧客户端不带该标记，保持完整替换语义，删除的流式识别/输出路由不会被重新合入。该标记仅用于请求，不写入持久配置。
- 补测本地 TTS、原生语音凭据隔离、仅提供图片能力的自定义来源，以及旧稀疏快照的兼容保存。同一个百炼语音模型重新启用时保留已保存的音色与参数，原生语音切换不同模型时选择该模型的默认音色。

验收脚本输出报告和桌面、窄屏、深色截图至临时目录，可重复执行。本次提交仅包含模型设置相关实现、设计说明和验收文件。

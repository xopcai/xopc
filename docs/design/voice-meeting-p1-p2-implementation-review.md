## P1-A 第一批：异步封存与恢复

### 改动

- 用 `POST /api/discussions/:id/capture/seal` 提交持久任务，立即返回 202；`GET /api/discussions/:id/recording/job` 查询处理结果。结束录音的 sequence 与任务在同一事务保存，服务端随后独立进入转写与整理。删除原 `recording/complete`、`stop` HTTP 入口和前端调用，内部只有一个封存提交路径。
- SQLite v171 新增封存任务，记录内容清单哈希、状态与租约；重复提交返回同一任务，过期租约允许重启后接管，失败保留分块供显式重试。当前仅实现 finalize 职责，未声称已实现设计中的全部 Discussion job 类型或自动重试预算。
- 复用现有 DiscussionSealer 生命周期调度，不新增后台定时循环或队列依赖。每轮先处理一个封存任务，再继续现有转写封存。
- 取消会立即撤销任务写入资格并中止本进程解码；发布结果前再次验证租约。临时拼接文件按执行实例区分，避免过期 worker 覆盖新 worker 的临时文件。
- 前端断线/重载后查询既有任务；已完成的录音不重复上传。轮询超时保留草稿，后台任务仍可完成；录音详情显示后台校验及失败状态。
- 录音有效时长改用单调时钟，主动暂停不计入；墙钟仅用于日期元数据。本项尚不等于多音轨采样时钟对齐。
- 本地待写入数据设 32 MiB 上限；存储跟不上或写入失败时停止采集，不把不完整写入当作成功结束。此上限限制应用队列保留量，不承诺浏览器 MediaRecorder 内部内存上限。
- 解码器仅接受 WAV/WebM/Ogg/MP3/MP4 对应容器与本地输入协议，拒绝播放列表。取消时等子进程退出再清理临时文件，已解码片段消费也检查取消信号。

### 自查发现与修复

| 问题 | 修复 |
|---|---|
| HTTP 请求承担整场解码，超时和重启状态不明确 | 提交与执行分离，任务持久化 |
| 客户端在保存附件后关闭，尚未发送 stop，会议一直停留在录音态 | seal 原子记录结束状态，删除第二次 stop 提交 |
| 通用重试只重置会议状态，失败的封存任务没有重新入队 | 复用原 manifest 重排同一任务，并立即显示失败阶段 |
| 附件已保存、任务完成状态未提交时崩溃 | 即使会议已进入整理，仍可接管并补齐任务完成状态 |
| 恢复上传与后台清理分块发生竞争 | 有在途任务时直接继续查询；已有附件不再传块 |
| 同一块数但内容不同仍可能重用任务 | 内容哈希进入持久清单校验 |
| 租约失效或取消被当作文件损坏，误删有效块 | 仅真实缺失/完整性失败可移除回执，且先检查租约 |
| 取消与附件持久化交错，旧 worker 发布结果 | 取消撤销租约资格，最终写入前再次检查 |
| 系统校时改变录音时长 | 单调时钟累计有效时间 |
| 慢磁盘使 Blob 写入队列无限增长 | 队列上限、明确停止与恢复状态 |
| 解码取消后继续消费/临时目录清理早于进程退出 | 消费检查信号，等待 close 后完成取消 |

### 验证

已覆盖真实运行的 Hono Gateway HTTP 鉴权与 lazy 路由、只读 scope 拒绝封存/允许查询、任务重复提交、失效租约接管、过期 owner 写入拒绝、取消竞态、前端恢复上传、时钟暂停恢复及 SQLite 迁移。

两小时合成 WAV 已验证分块上传、后台解码、实际时长与清理结果。它只证明容器/容量路径，不能代替真实多人、系统声音或跨设备对齐测试。

验证结果：

- 完整相关回归：13 个测试文件、98 项通过，覆盖 Discussion、路由、迁移、前端录音工具和解码器。
- 最后的重试与原子发布修复后，单独重跑服务/解码器：25 项通过，包含两小时录音。
- `pnpm run typecheck`、`pnpm -C web run build`、针对性 ESLint 和 `git diff --check` 通过。Web 构建仍有既有大 chunk 和动态/静态导入混用提示。
- 文档相对链接检查通过。

最终定向命令：

```bash
XOPC_LOG_LEVEL=fatal XOPC_MEETING_LONG_SMOKE=1 pnpm exec vitest run src/discussions/__tests__/service.test.ts src/voice/audio/__tests__/normalize.test.ts --hookTimeout=60000 --testTimeout=30000
```

并行编译时，一次定向运行有 3 项在临时数据库初始化钩子超过默认 10 秒，尚未进入业务断言。停止与编译并行后，以以上命令重跑通过；没有修改仓库的测试断言或全局超时设置。

本批录音可靠性改动已完成自查和相应自动验证；P1-A 其余部分仍未完成。未部署生产，未升级用户运行中的数据库。

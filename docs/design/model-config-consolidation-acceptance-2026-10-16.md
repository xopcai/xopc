# 模型配置入口与听写收敛验收

日期：2026-10-16。实现与验收记录。

## 配置入口

- 全局模型选择统一在「模型与能力」。智能体默认设置保留共用模型摘要、对应能力的跳转入口，不再提供另一套模型选择器。
- 任务模型路由、对话与视觉回退、图片超时及自动回退设置迁入对应能力详情；已有配置不迁移、不清空。
- 单个智能体保留模型覆盖能力，入口明确为「继承全局 / 单独设置」。
- 智能体默认设置保存技能、工具或运行参数时，重新读取当前全局模型，避免将旧页面快照中的模型写回。
- 能力详情保存高级模型参数前检查已有模型是否变化，同时保留最新的非模型设置。

## 录音与听写

- 「录音与听写」统一解释和管理录音识别能力，显示聊天听写当前实际使用的方式与服务。
- 聊天听写在开始采集前选择识别方式。旧的显式流式配置继续沿用；没有流式能力的录音识别服务（包括当前百炼订阅）直接使用既有录音转文字接口，点击「完成」后回填输入框。
- 不因鉴权失败、网络失败或显式流式配置不可用而自动切换其他服务。录音识别失败后保留音频供重试；取消或关闭后忽略迟到结果。
- 录音采集后固定所选识别服务；若提交前配置已切换为另一服务，网关返回 409，不向新服务发送音频。旧客户端未提供该约束时继续使用原有接口行为。
- 实时语音对话仍单独配置，不受录音听写复用逻辑影响。

- 根项目类型检查、Web 类型检查及生产构建、变更范围 ESLint、diff 检查通过。
- 使用本机网关及已保存的百炼订阅 Key，真实验证默认 TTS、页面听写、笔记录音转写及原音播放、聊天生图及图片展示。识别测试数字 `4729` 正确，未隐式回退到 Cloud。
- 真实网关验证录音服务切换约束返回 409；验证摘要跳转、当前听写服务提示以及窄屏页面无横向溢出。
- 测试未修改默认用途：聊天、看图、生图、录音识别、TTS 保持百炼，后台保持 `xopc-cloud/auto`。

## 连接的服务与最终复核

- 全部服务页先提供七种能力入口，保留统一模型服务管理，不再叠放语音和图片接入表单。
- 录音识别与 TTS 接入页只展示相应用途；依据语音注册元数据区分共用模型服务凭据与原有独立语音凭据，避免误入文字模型接入。模型服务再按后台用途目录校验，不以品牌名称判断能力。
- 已保存百炼凭据可直接复用，连接窗口只呈现当前用途；连接成功返回原能力，保留来自语音或对话的返回位置。音色、识别语言等仍归能力详情。
- 网关在写入高级模型配置时原子校验预期模型快照；智能体默认参数保存保留最新模型。旧客户端未标记保存范围时保留原接口语义。
- 真实已认证网关验证旧快照冲突返回 409、模型与智能体保存范围、旧接口兼容以及服务往返；所有默认用途保持原值。
- 本轮服务页面验证不产生供应商模型调用；此前真实 TTS、录音识别、听写和生图调用证据见上文记录。

# 鸿蒙录音浮窗统一（2026-10-16）

## 信息层级

笔记页全屏录音界面与其他页的简略状态条统一为 Home Navigation 上层的一份应用内浮窗，页面切换不重建录音会话。

展开：真实采集状态、时长及声音输入优先；连续本机保存范围显示一行；云端备份、文字与笔记进度按需展开，实时原文单独折叠。中断、存储失败、重点保存失败与仅前台录音的提示仍保持可见。停止后仅在原有本机保存屏障完成时显示已保存成功。

缩小：时长、真实录音状态、保存提示及标重点、暂停/继续、结束按钮保留。无真实输入时禁用标重点；暂停仍保留按钮但禁用标重点，恢复后等待采集确认再开放。保存中禁用重复操作；恢复场景的结束位置改为重试保存。

## 移动与尺寸

拖动仅绑定在 44vp 的六点移动手柄，正文滚动与核心按钮不参与拖动。轻触手柄可选择四个角落，提供不依赖拖动的操作方式。结束/取消手势后抑制随后误触，取消时回到起点。

浮窗位置限制在 Home 的可用布局范围内，四周保留 12vp。沿用应用系统安全区及 KeyboardAvoidMode.RESIZE，窗口、旋转、键盘改变可用尺寸时重新限制边界；尺寸变化会废弃旧拖动偏移。窄屏缩小模式将操作放到独立一行，保持 44vp 点击范围。展开面板的文字区域内部滚动；矮窗口仍能展开。位置菜单临时替换正文，避免被底部控件裁切。

浮窗状态由 Home 持有，缩小/展开与导航保留位置；新录音默认展开。它不拥有麦克风、不停止录音、不清理本地音频。三个动作调用现有 DiscussionCapture，会话、原音落盘、持续上传和恢复沿用原实现。结束操作额外防重入，只在同一会话完成后导航到原 Note；失败时保留恢复入口。

## 验证

- 控制器主机测试：两种模式的动作一致性、无输入/暂停/停止状态禁用、重复结束与失败重试、手势偏移/取消、点击替代操作、窄屏/横屏/键盘尺寸变化与边界、矮屏展开和位置菜单。
- 真实 SQLite 故障测试：录制过程中移动/缩小/展开/标记/暂停/继续后仍写入同一会话；重复结束只提交一次；磁盘写失败后的连续原音前缀保留并可恢复到同一 Note；标记写失败不停止原音。
- ArkUI 接入、原有录音恢复与主机回归、Release 未签名 HAP 编译、配置的 CodeLinter 静态检查。
- 不运行鸿蒙真机、不执行安装或设备操作。本批没有真机触控、字体缩放或长录音的视觉/性能验收结论；这些仍是后续设备验收项。

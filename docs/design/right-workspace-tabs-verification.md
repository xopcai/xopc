# 右侧混合标签工作区：实现与验证

补充：[2026-10-18 完整浏览器 E2E、Codex 对齐与动效复核](./right-workspace-codex-parity-e2e.md)。下文保留首版验证记录，最新结果以补充报告为准。

日期：2026-10-18。范围：Gateway Web 与 Electron 共用的 renderer；内置浏览器原生引擎仍处于 [方案设计阶段](./unified-workspace-and-embedded-browser.md)。

## 已实现

- 主聊天保持挂载，右侧工作区统一管理文件、Sidechat、文件浏览和工具起始页标签。
- ＋打开工具起始页；文件与侧聊卡片使用真实功能。侧聊创建成功可原位替换起始页，晚到结果不抢占新选择。
- 标签列表、轻量活动标签、数量、工作区放大/还原、独立收起和文件树开关。
- 右侧文件树与内容分栏；空间不足时自动折叠，显式打开使用临时辅助层，保留当前文件。
- 文件与附件共用预览插件；保留分享、下载、系统打开和新会话编辑能力。独立分享及项目文件页保留原有组合。
- 文件、侧聊和父会话状态隔离；资源解析后的文件别名合并，未保存文件不会被合并移除。
- 文本编辑逐文件保留，串行自动保存，提交读取时 revision；失败阻止关闭并保留草稿，可重试或明确放弃。
- 轻量文件阅读状态、有限的干净文本 controller 保留；非活动二进制预览卸载以释放重型实例。
- 明确目标的文件附件引用，加入主聊天/来源侧聊草稿，不自动发送。
- Sidechat 使用原有会话逻辑和服务端 API；非活动、跨父会话、收起状态下继续维护心跳、运行、过期及恢复，重型消息列表只在可见时渲染。
- 现有模型设置、附件、澄清/审批、停止、延长、结束阅读态、草稿重建、保存笔记、转为正式会话和选区带回主聊天继续复用。
- 侧聊关闭在服务端成功后移除标签；失败保留草稿。主聊天填充事件不再覆盖常驻侧聊输入框。
- URL 同步只管理界面选择，浏览器返回不调用侧聊删除或创建；收起不会被自身 URL 更新重新展开。
- 会话存储按 Gateway 与公开浏览器会话命名空间校验；本地附件正文、文件二进制及未保存编辑不写入持久标签记录。
- 新聊天创建时显式迁移临时工作区；任务详情文件入口接入统一右侧区域。

## 验证边界

- 未把 23 项设计验收全部标成真实设备端到端通过。运行、审批、过期、保存冲突等主要依赖自动化测试与已有服务端回归；本次未调用真实模型制造这些状态。
- 本次没有构建和启动 Electron 原生安装包；原生窗口多 DPI、系统文件选择器与平台打开应用仍需打包后专项验收。
- 内置网页浏览、地址栏、浏览 profile、浏览器自动化目标后端路由和原生视图覆盖层尚未实现。后续按 B0–B2 推进，不在当前工具起始页展示假浏览器入口。
- 首版不承诺未发送侧聊草稿、未保存文件编辑及本地附件的崩溃/刷新恢复；正常 Tab 切换受保护，离开时对未保存编辑提供浏览器保护。

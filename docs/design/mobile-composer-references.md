# 移动端对话资料引用

## 入口与交互

加号菜单提供「引用笔记」「引用任务」「添加文件」。三个入口共用底部选择面板，直接打开对应分类；在面板内可以切换分类。

- 笔记与任务默认展示最近更新的 50 条，输入关键词后查询服务端，不在最近列表上做本地过滤。
- 文件支持本机选择和当前对话工作区；支持文件名/路径搜索、进入目录和返回上级。
- 输入搜索词后等待 200 ms 发起查询；加载使用骨架，错误支持重试，无结果明确提示。
- 点击资料加入草稿并关闭面板，不自动发送。选择面板是专用选择界面，行点击执行选择或进入目录，不提供管理页面的删除、滑动操作。
- 已选资料标记为已选；笔记与任务合计最多 5 条。文件沿用附件上限。
- 草稿中的笔记、任务可点开查看或移除；工作区文件沿用文件预览和移除操作。
- 返回通话维持原有外部入口。

## 技术实现

`ComposerReferenceSheet` 复用 `BottomSheetModal`，固定响应式内容高度，列表内部滚动并避让键盘。通过 React Query 读取 `query/composer-references.ts`，查询键包含 Gateway、会话、分类、搜索词、目录，避免异步结果混入其他分类。

笔记和任务通过 `contextRefs` 提交来源 ID 与选择时版本。任务支持扩展现有 `GET /api/tasks?search=`，参数化 SQL 在限制条数前搜索标题和正文。Gateway 将任务解析为只读上下文快照，包含目标、正文、阶段、优先级、截止时间和任务约定；先验证版本，再裁剪内容并应用统一上下文预算。来源已删除或已改变时拒绝提交，由已有发送失败恢复逻辑保留草稿。

工作区文件在草稿中显示附件卡，发送时转换为既有 `@file:` 引用，路径统一转义；不将无上传数据的工作区文件提交到媒体上传链路。本机文件继续使用既有上传逻辑。

任务引用同时接入实时消息、持久化历史、移动端解析和重发。笔记、任务及工作区文件引用可恢复草稿；不新增持久会话绑定，也不因引用而执行任务状态修改。

## 验证范围

自动化覆盖任务搜索、版本变化与来源缺失、内容上限、引用类型验证、实时/历史元数据、草稿恢复和工作区路径编码。原生键盘、底部面板切换、文件预览及系统文件选择需要在 iOS/Android 真机验收。

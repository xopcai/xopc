# 模型配置同页完成验收

日期：2026-10-16。实现与验收记录。

## 交互

- 能力总览直接显示模型选择器，点击后只切换当前用途；“设置”和“管理服务”并列显示，打开固定尺寸弹窗，不切换路由。
- 弹窗分为“模型与参数”和“管理服务”两个页签，从对应入口直接定位；切换页签保留编辑状态。同一能力关闭再打开保留未保存的服务表单，切换到其他能力开始新表单，关闭后恢复页面操作与滚动。
- 语音入口提供录音与听写、文字转语音、实时语音对话三项原地设置，沿用已有语音参数与测试能力。
- 当前能力内可以选择服务、复用凭据或填写 Key、选择具体模型，并通过“连接并用于…”一次应用当前能力。原生 STT/TTS 的独立凭据域保持独立；保存后仍留在当前能力。
- 服务设置保存后明确反馈结果；保存期间禁用竞争操作，重复点击不会发起多次应用。
- 听写报错与语音对话中的设置入口打开当前页面上的设置面板，关闭后保留聊天路由与未发送草稿；高级快捷键打开原链接的行为保留。
- 服务账户仍提供集中维护；旧用途详情、图片设置重定向和原有语音服务链接继续可用。

## 验证

- 27 个测试文件、183 项测试通过，涵盖弹窗入口、具体模型选择、并发冲突、重复点击、设置面板保存锁定、旧链接、后台使用范围与语音工厂回退约束。
- 夹具 E2E：未连接服务保存凭据并仅应用识别用途，模型切换期间锁定语音设置，后台排除交互套餐，旧入口和移动布局通过。
- 真实已认证本机网关：语音参数原地保存与恢复、百炼凭据复用、看图模型切换与恢复、后台与对话不被改派、面板内模型选择、聊天草稿保留、窄屏深色展开设置通过。
- 已保存百炼订阅真实调用：聊天返回指定文本；看图识别红色；TTS 返回可播放音频；页面听写和笔记录音识别数字 4729；笔记原音实际播放；聊天调用图片工具生成图片，附件可读且页面成功展示。
- 测试临时切换的模型与朗读参数已恢复，后台仍使用 XOPC Cloud。配置连接、保存和真实调用分开验证。
- Web 类型检查、生产构建、相关 Web 源码 ESLint 与差异空白检查通过。现有 ESLint 配置未覆盖 `.mts` 验收脚本。

## Review 修复

- 旧语音详情进入服务连接时只挂载一个编辑器，嵌入弹窗不重置背景页面滚动。
- 语音保存附带按能力划分的不透明版本；网关在写锁内校验，过期请求返回 409，保留草稿并提供原地重新加载。兼容不发送版本的旧客户端，配置文件结构不变。
- 保存失败后不因按钮失焦再次自动提交，避免打断重新加载操作。
- 图片自定义连接窗口位于当前弹窗内，保存期间禁用字段和关闭操作。
- 尚未在模型注册表创建连接的 models.json 预设不参与当前模型目录请求，避免把未创建的百炼按量服务误报为加载失败。

## 边界

录音输入通过 Chrome 模拟麦克风播放百炼真实 TTS 音频；识别与生成请求均调用真实服务。未新增物理麦克风、实时语音供应商会话或其他厂商的真实调用验收。

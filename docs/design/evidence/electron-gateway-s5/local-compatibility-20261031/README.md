# 本地旧Gateway复用兼容

两个失败安装包样本保留：新版Electron在复用探测前通过initWorkspaceCore执行数据库bootstrap；v262数据库仍由旧Gateway持有时，新schema263升级触发所有权保护，主窗口未创建。失败状态目录保留，未删除数据库，也未停止用户服务。

修复仅在磁盘为受支持的较旧schema且现有Gateway接受配置凭据时使用Gateway的Agent目录API读取文件边界；不由Electron初始化、改写或升级该服务的数据库。原启动监督器继续执行协议检查、原本地直连和进程所有权判断。空数据库、当前schema、无运行Gateway等情况仍走原初始化路径；只读预检失败交回原校验器，最低支持版本不变。

最终包 `0aee597f3798b6453944cec78bd767fa96446ab6bee21c988eaf866a543108a3`：

- `s5-final-local-1.json`：本地新启动与复用当前Gateway通过，复用数据库保持v263。
- `s5-final-old-server-1.json`：新客户端复用旧包Gateway通过，数据库保持v262；聊天、Cookie/WS、文件边界、PTY、浏览器、拒绝重启非拥有进程、退出后旧服务仍在线均通过。
- 单测覆盖通过HTTP目录取得自定义工作区而不改写旧DB/配置，以及已有空DB继续正常冷初始化。最终相关Electron回归100项通过；只读预检的性能成本留待原预算专项评估，不宣称性能验收通过。

中间候选预验证另存，不代替最终包结果。新schema263自身的升级需要离线所有权/备份/完整性检查；旧schema262程序不能直接读取升级后的数据库，降级需演练正式备份恢复流程。

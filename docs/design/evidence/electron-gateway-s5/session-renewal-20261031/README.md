# S5会话到期失败与受控续期

首轮真实长测 `s5-100-cycles-24h-1.json` 完成100次连接循环和15轮输入后失败：Shell的15分钟短期会话绝对到期，界面进入“需恢复连接”。该结果不是24小时通过，原包/报告/失败状态保留，清理已确认。

修复保持单次Cookie有效期15分钟：主进程在到期前触发固定Gateway身份和管理认证复核；worker准备新随机Cookie，主进程用同一HttpOnly/SameSite/受限分区策略安装，随后只有内部IPC可提交轮换。交接最多15秒，未确认则失效；旧Cookie提交后立即拒绝，已到期会话不能复活。原生Cookie写入仍在执行时，关闭Shell等待其结束后再清理分区，不能先宣称清理成功。

没有新增Renderer续期IPC，没有改为无限Cookie或放宽原恢复/清理时限。短期网络错误只在原Cookie未接近到期时有限重试；身份/凭据/不确定交接失败会关闭并保留恢复入口。

单元测试检查身份复核、受控提交、旧Cookie失效、原期限后新Cookie有效、新Cookie到期拒绝和清理竞态。单元测试的时钟替身只验证逻辑，不冒充真实长测。首轮新增测试误预期身份错误码，实际正确返回更具体的IDENTITY_CHANGED，失败日志保留并修正断言。

` s5-compatibility-tls-1.json `记录原生安全熔丝下私有自签证书正向fixture未被信任；没有禁用验证或修改熔丝。`s5-untrusted-tls-rejection-1.json`明确验证未信任证书在发送HTTP/管理凭据前被拒绝。有效公有HTTPS正向证据继续使用S4独立服务器记录，不把自签失败伪记为成功TLS兼容。

续期和后续清理修复使用不同包摘要分别记录。运行中的新长测只归属实际包，不用于未接入的Host或后续写能力。原预算和全部性能失败保留。完整S5的24小时、真实休眠唤醒、版本/回退和平台矩阵仍须逐项确认。

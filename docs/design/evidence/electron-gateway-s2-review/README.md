# S2 review 与修复验证（2026-10-31）

范围：基于 `ab82be00f` 的 S2 分支，审查认证/身份绑定、HTTP/WS 白名单与配额、窗口 IPC、生命周期和默认本地入口隔离。不推进 S3、远端 Host 或本机能力。

## 发现与修复

ticket 请求体尚未发送完时，15 秒计时器只 abort 内部 controller，没有关闭 `IncomingMessage`；`for await` 仍可能等待后续数据，占用代理并发槽位。本轮将合并后的取消 signal 绑定到请求销毁，并在读取结束后释放监听器；会话失效也能立即中止请求体。原 15 秒预算、16 活跃/16 排队等限额保持不变。

[修复前回归失败](./xopc-s2-review-body-before.log)：25 项中 1 项失败；触发实际注册的 15 秒计时器回调后，未完成请求仍未关闭。新增测试通过原始 HTTP 分块写入、不结束请求，确认超时关闭、控制请求继续可用且没有上游 ticket 调用。测试主动触发已注册的原期限回调，避免依赖 15 秒墙钟等待，不改变产品计时器或验收预算。

本轮本地功能首次复测还发现测试脚本漏处理恢复到“选择来源”页的首次引导：回复已显示，但引导对话框令主内容区不可访问，导致原 30 秒可见性断言失败。见[失败 JSON](./s2-review-local-functional-failed.json)和[日志](./xopc-s2-review-local-functional-failed.log)。修复测试脚本分别识别模型选择与来源选择两步；不修改产品 UI、不跳过聊天断言、不提高超时。原性能采样脚本与预算不变，functional=false 时不执行该逻辑。

## 审查范围与限制

- 显式远端入口独立于默认本地 main；原本地入口、Gateway 子进程监督、S0 采样脚本及旧证据文件与 main 相同。
- 已绑定身份先进行无 owner token 的 nonce 证明，再认证 discovery；TLS 仍验证证书/主机名。
- Shell 只接受当前内存会话、窗口 proof、受控路径和 Realtime topic；Endpoint、本机 IPC 与写入能力拒绝。
- 切换/恢复先确认旧 worker 退出；清理失败隔离，旧 epoch 不可关闭新会话。
- 相关测试和开发 Electron E2E 不能替代安装包、物理远端服务器、跨平台、长期运行或完整 P2a-1 发布验收。

最终结果和可复现命令见同目录 `validation.json`。本轮失败日志独立保存，旧 S2、S0/S1 及性能失败证据未覆盖。

最终 **886 项 / 110 文件通过**，8 组 E2E 通过；两轮完整原 S0 预算均 **8/8**，各 60 次启动。参见[汇总及全部命令](./validation.json)、[预算 1](./s2-review-budget-1.json)、[预算 2](./s2-review-budget-2.json)。所有采集入口要求新输出路径，复测时须更换文件名，不能覆盖本轮证据。

功能优先继续开发，未等待S5的24小时长测。原预算摘要仍为 `e752bb4b97f54e4713d8ecc8b6f8cd302d3e80d044099b0397dfe113d0f45746`；没有性能验收结论。

## 交付与验证

- 连接页增加登记、检查、停用、重新登记和同目标登录凭据更新。设备私钥/刷新凭据只由主进程通过OS安全存储保管，Renderer只有状态和设备id。登记不创建Endpoint，不启动屏幕、文件、命令执行器。
- 原生确认绑定可见的可信主frame、profile和epoch；选择/修改连接、退出、返回本地会取消旧操作，人工确认不占用连接切换队列。被撤销身份不自动重新配对。
- 离线停用先持久写入本机停用，在线撤销确认单列。丢完成回执后通过签名status找回已建立的设备再撤销；没有提交成功的孤立邀请由owner取消并重新读取确认，不能将任意404当作撤销成功。
- 独立desktop SSH邀请只允许规范loopback origin，旧mobile/browser路由验证不放宽。
- 77项服务端/路由测试、93项Electron连接相关测试、148项契约测试、10项新增SSH边界测试及根/Electron类型检查通过。真实Node和正式包内Gateway的认证E2E验证最小scope、重放拒绝、撤销、离线停用、刷新/完成回执丢失恢复、重新登记必须再次同意。
- 正式DMG安装副本 `ef24440e4daccb283f9afbc5b22be82d12c0f4e82fcaf89a3664dc971ff75f83`：Developer ID严格签名验证、368项必需资源、659项运行文件对应构建产物、58.25MiB运行依赖通过。本地spawn/reuse、聊天/Cookie/WS、文件边界、PTY、浏览器、拥有进程重启与复用进程退出隔离通过。远端fixture聊天、故障/进程恢复、半开连接、未知输入不重发、版本/身份/认证拒绝和显式返回本地通过；短场景不冒充24小时结果。
- 原生UI闭环见 `p2a2-d2-native-enrollment-8.json`：CUA实际点击取消/确认/取消重新登记/确认重新登记；OS safeStorage重启后读取同一设备；owner登录失效时独立设备仍可检查；离线停用、在线确认、外部撤销后不自动重建；无客户端Gateway数据库和工作区。

## 原生副本差异与失败保留

本机已有运行的同名xopc，原生自动化按相同bundle id可能选中现有窗口。原生交互使用独立标识 `ai.xopc.desktop-enrollment.acceptance` 的测试副本，使用相同Developer ID和原有entitlements重新签名。文件比较仅 `Contents/Info.plist` 和签名所在 `Contents/MacOS/xopc` 不同，所有asar、preload、主进程代码、Gateway与原生资源字节相同，详见 `native-bundle-differences.json`。该结果证明相同运行代码的OS安全存储和原生交互，**不声称独立标识副本就是正式发布包**；正式包单独执行上述本地/远端/认证E2E。macOS公证、其他架构/操作系统和物理WAN不包含在本批验收。

保留全部8轮原生结果：1/2/5在预期取消阶段得到确认；3/4因临时修改CFBundleName造成Electron找不到helper而启动失败，保留并恢复名称；6/7因监督器没有在重启/更新凭据后重新选择配置导致按钮禁用。修复监督器恢复实际选择步骤后8通过，没有修改产品选择规则或放宽预算。错误Vitest项目/过滤器的1–3轮无效命令也保留，正式测试结果为第5轮。失败状态目录在各JSON中，未删除。

S5原安装包和长测进程保持独立，本批未把其运行时间借作D2/Host长测。完整P2a-2还需D3逐项只读授权、独立Host与D4持续运行验证。

## 首次失败和修复

保留本目录中所有编号报告/日志，不覆盖失败。初次包构建lipo参数顺序错误已修正；接线测试发现已核实无副作用的版本拒绝被上层包装成未知，改为仅在签名失败回执、输出契约和结果摘要均核实后传播明确错误。无有效回执仍为未知。

原生第1至4轮暴露Worker在Endpoint握手尚未完成时被Main清理的问题：以origin尚未就绪判断资源未接管不正确。现改为连接协调器成功接受资源即拥有停止责任，同时资源停止仍须等待真实Worker退出，停止超时保留执行锁。首次取消并非超时即通过，必须有本次USER_DENIED审计。

第5轮CUA旧应用绑定导致目录超时；第6轮合成模型后台标题请求误识别为工具调用；第7轮人工操作累计超过两分钟导致授权正常过期。修正夹具请求识别并分三次显式授权验证，未增加任何产品时限。第9轮完整通过。

目录FD逐级no-follow、版本校验与并发边界延续[P3契约](../../../electron-gateway-p3-workspace-contract.md)。文件版本检查不构成与不参与锁的外部编辑器全局CAS，中断可能留下部分效果，不承诺exactly-once。

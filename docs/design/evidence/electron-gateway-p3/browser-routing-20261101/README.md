# Browser device routing and reviewed admission recovery

Public `browser_use` now selects the explicitly addressed independent Desktop endpoint before historical bindings. Offline/revoked Desktop identities remain a device route; missing authority cannot launch a server browser. Default/local and legacy Browser routes continue through the existing factory. Device runtimes are bounded and retained when stopping cannot be confirmed. Cleanup attempts every independent resource even when another fails.

The adapter binds conversation, endpoint, connection instance, Gateway, device, grant, authorization revision and descriptor revision. It accepts only bounded typed results, rejects inline images/session substitution, consumes frames by invocation identity and clears transient bytes. Server-path uploads remain unavailable.

After a lost control result, old session admission can be released only when the exact old execution authority is inactive and every unknown operation in that scope has a native manual review confirming executor stop. Revocation or reconnect alone is insufficient. Original outcomes remain unknown and are never replayed. Computer capability checks now precede session admission, preventing an unavailable capability from leaving a busy slot.

Validation: 140 tests across six routing, transport, operation-review, Computer and factory files passed (`/tmp/xopc-p3d-browser-routing-regression-1.log`); the public Agent factory integration passed (`/tmp/xopc-p3d-browser-factory-routing-1.log`). Full TypeScript/Electron checking passed (`/tmp/xopc-p3d-browser-routing-typecheck-5.log`). Sets overlap earlier evidence. Actual authenticated HTTP/WSS covers lost result, revocation without stop proof, signed manual review and release without replay; the Browser/approval backend is injected, so this is not native DOM acceptance.

Original budgets and failed fixture evidence are retained. This does not resolve idle-disconnect admission recovery when no unknown operation exists. Native Browser backend, idle resource stop proof, full fault acceptance, disk constraints, P4 and final main build remain outstanding.

# Dedicated Browser native execution

The independent device grant now exposes an optional `remoteBrowserVersion: 1` capability and a trusted connection-window action. Existing local Browser entry and drivers remain unchanged. Main creates only an inert session until the durable operation journal; encrypted preparing metadata precedes worker startup, and ready process-group metadata is fsynced before browser dispatch. No new authenticated route or database schema was added.

The private Electron worker uses a detached owned process group, ephemeral partition and OS IPC without a debugging port, Node/preload bridge, personal browser cookies or server-path uploads. Page evaluation executes bundled typed operations in an isolated world, never Gateway script/selector input. Observations are bounded; password/file controls are excluded; mutation, URL and revision changes reject stale input. Window popups, downloads, webviews and browser permissions are denied. Supported single-key input is restricted. Each non-stop request requires native consent showing the complete typed request and locally obtained tab metadata. Parent loss, IPC disconnect or the original two-minute deadline terminates the worker group. Recovery observes the old parent and complete group; it never kills persisted PIDs.

# 模型配好后，Ada 先找一件值得做的事

## 首用体验

模型配置成功后，用一张卡完成首次工作发现。

> **要看看最近有什么可以接着做吗？**
>
> Ada 会查看近期工作线索，帮你找一件可以继续的事。
>
> **帮我找找** · 直接进入

「帮我找找」下方用一句话显示本次会查看的位置，以及是否会用云端模型处理少量内容。点击后，Ada 从可用线索里选出一件最有把握的事，卡片直接换成建议。用户还可以点「换一件」或直接进入。

> **整理这轮供应商评估的待跟进项**
>
> 最近更新了《报价对比表》和《10 月 28 日评审纪要》，两份资料都在讨论本轮报价。
>
> **生成待跟进清单** · 换一件 · 直接进入

点击主操作后，打开正常对话并用相关资料生成第一份只读结果。用户可以在对话里校正和继续。需要长期跟进时，再提供保存项目或创建任务的入口。

## Ada 怎么找

- **先找候选。** 在用户确认的范围内查看文件名、更新时间和目录线索。首期本机发现覆盖桌面、文稿、下载及已知的项目目录。Codex 和 Claude Code 的已知项目目录也可以提供线索，已有权限的 xopc 项目优先复用。远程 Web 只展示已授权且实际可访问的来源。
- **让模型判断哪件事值得做。** 利用已有的只读调查能力，从候选里挑少量相关文件片段，合并属于同一件事的线索，判断当前进度和可交付的下一步。每条建议带一两处来源。比如识别出表格和纪要讨论的是同一批供应商，进而起草一份包含依据的待跟进清单。
- **证据不足就收口。** 只显示有充分依据的建议。找不到时，保留「直接进入」，可提供一个明确标为通用起点的动作，例如「帮我准备一场会议」。用户点选后即可生成通用提纲。

## 首期范围

复用[工作目录发现](../../src/work-discovery/candidate-discovery.ts#L258)、[近期文件发现与提取](../../electron/understanding-sources/recent-files.ts#L52)、[AI 工具中的已知目录](../../src/imports/scanner.ts#L62)和[有界只读调查](../../src/work-discovery/investigator.ts#L30)。将候选发现和按需读取拆开，正文读取以本次明确展示的范围为限。首期用一张卡承接现有工作发现向导的默认入口。项目和 Skill 导入沿用设置入口，连接沿用能力中心的授权流程。

验收看三条路径：找到旧 Agent 的工作目录并建议一个具体动作，从两份散落的办公文件识别同一件事，以及无可用线索时直接进入。用真实资料检查建议是否有出处，以及用户从模型就绪到拿到首份结果的耗时。

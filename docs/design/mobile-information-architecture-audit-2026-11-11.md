# xopc 移动端信息架构盘点与优化方案

2026-11-11 · 源码基线 8c8966463 · HarmonyOS、Android、iOS 原生客户端

本次从三端入口追到一级页、子页、操作面板和系统入口。同一业务页面的筛选、宽屏布局和弹层变体合并记录。依据为静态源码、竞品公开资料和仓库已有研究。真机布局、发布版本以及不同账号和 Gateway 条件下的运行行为留待验收。

## 1. 当前导航

~~~text
启动 → Gateway 配对 → 扫码／手动连接 → 主界面
主界面
├─ 助手 → 当前会话、输入工具、会话上下文、执行与成果、语音、手机工作区
├─ 对话 → 个人助理入口、搜索、历史列表、任务子对话、会话管理
├─ 进展 → 待处理、进行中、接下来、近期结果、工作入口
│         ├─ 任务 → 详情、状态、创建／编辑、任务对话
│         ├─ 项目 → 概览、对话、任务、笔记、自动化
│         └─ 自动化 → 详情、创建／编辑、运行记录 → 单次运行
├─ 笔记 → 搜索与筛选、详情／编辑、录音、文件入口或文件结果
└─ 我的 → 助理档案、个人资料、目标、关于你／记忆、设置
          └─ 设置 → Gateway、通知（按端）、分享中心、语言、外观、关于
~~~

三端的五个一级入口语义一致，二级 Tab 根页都提供快捷输入。展开输入工具、打开详情或键盘出现时，底栏显隐和回跳由各端实现。主要差异集中在文件入口、会话管理、项目内创建、通知设置与跳转。9 月的 [Tab 评审](mobile-tabs-information-architecture-review-2026-09-17.md)基于已退役客户端，当时的四入口与部分缺口已经变化。

入口依据见 [HarmonyOS 首页](../../apps/mobile-harmony/entry/src/main/ets/view/HomeView.ets)、[Android 主界面](../../apps/mobile-android/app/src/main/java/ai/xopc/mobile/ui/main/MainScreen.kt)、[iOS 应用根页](../../apps/mobile-ios/XopcMobile/App/AppRootView.swift)。

## 2. 逐页盘点

H = HarmonyOS，A = Android，I = iOS。「三端」指有对应入口或界面，同一行里的功能和深度可能有差异。优先级对应第 5 节。

### 助手与对话

| 页面或面板 | 当前内容与去向 | 建议 |
|---|---|---|
| 助手首页／普通会话 | 三端。欢迎态或会话时间线、输入栏、会话操作、流式状态、附件和成果。 | **P0** 恢复最近活跃会话，提供明确的主助理入口。标题显示助理名或会话主题，次行显示项目／任务归属与真实状态。 |
| 对话列表 | 三端。主助理入口、新建、搜索、日期分组，父会话可展开关联任务。 | **P0** 固定主助理入口；列表以置顶、最近、归档组织。对话搜索区分标题与正文命中，直接定位到结果。 |
| 会话管理 | 三端可见重命名、置顶等操作；H 还有多选、批量归档、分享结果面板。 | **P0** 统一重命名、置顶、归档、删除语义。批量操作进入编辑态；分享前预览公开范围。 |
| 对话内查找／消息详情 | 三端有对应搜索实现；I 使用全屏查找和消息详情弹层。 | **P0** 命中结果定位原消息，返回保留查询和滚动位置。复制、朗读、引用等在消息附近完成。 |
| 输入工具／附件／引用选择 | 三端。照片、相机、本地文件、录音、笔记／任务／文件引用、新对话。快捷输入可用动作因端而异。 | **P0** 加号面板按「添加内容」「引用资料」分组；实时通话与录音附件各有名称。附件行显示来源、上传和待发送状态。 |
| 会话选项／上下文／会话文件 | 三端有模型、思考或会话选项，以及工作、环境、项目、来源或会话文件界面。 | **P0** 会话信息先显示归属和关联对象，模型等放会话选项。会话文件保留会话来源和返回路径。 |
| 澄清／连接等待／输入队列 | 三端有澄清、连接等待、执行和排队相关实现，触发路径各异。 | **P0** 明确「需要回答／等待连接／已排队／已接收」和各自可执行动作；重新进入按服务端已确认状态恢复。 |
| 执行步骤／活动／成果 | 三端可从聊天打开执行详情，另有结果入口与媒体预览。 | **P1** 时间线里给简短的最新进展，完整步骤进入详情。成果卡优先展示摘要和「打开」，详情提供引用、修改、分享。 |
| 图片／文档／媒体预览 | 三端有聊天附件与媒体呈现，格式支持随端和来源变化。 | **P1** 统一标题、来源、可用状态与操作名称，预览和播放采用各端原生方式。 |
| 实时语音 | 三端从助手进入通话；I 有根级全屏通话和缩小后的通话条。 | **P1** 最小化、挂断分别呈现；前后台恢复可查看通话状态并回到来源会话。 |
| 手机工作区／接管 | 三端都有与聊天关联的 Phone 界面，受设备连接状态控制。 | **P1** 从当前执行卡进入「查看设备」，显示所属任务，明确观看、接管、交还、断线四种状态。 |

| 自动化列表 | 三端有规则列表和创建入口。 | **P1** 每条显示启停、下次运行、最近结果；提供启用、暂停、需处理筛选。 |
| 自动化创建／编辑 | 三端有规则编辑。I 有基本信息和定时规则表单；H 有对话创建路径。 | **P1** 按「做什么、何时、交付到哪」组织，保存前预览下次运行、时区和交付去向。 |
| 自动化详情／运行历史 | 三端有规则详情、规则状态和近期运行入口。 | **P1** 规则详情优先显示下次运行与最新结果。手动运行完成操作后定位到本次记录。 |
| 单次运行详情 | 三端有运行详情；I 有时间线与重跑，A 有取消确认，H 有独立运行路由。 | **P1** 先展示结果、失败原因或等待条件，再放时间线。重试打开新运行，并可回看旧运行。 |

### 我的、设置和系统入口

| 页面或面板 | 当前内容与去向 | 建议 |

| 我的首页 | 三端。个人身份、助理入口、目标、理解摘要和设置入口。 | **P0** 区分「我的助理」「关于我」「目标」「应用设置」。多个入口打开同一助理档案。 |
| 助理档案／个性设置 | 三端有助理头像或档案编辑入口，部分模型入口会回到聊天。 | **P1** 档案集中姓名、头像、协作方式，模型配置注明影响助理默认值还是当前会话。 |
| 我的资料／编辑 | 三端。个人资料与关于你关联，编辑表面各异。 | **P1** 用户填入的资料与助理推断的记忆各自可编辑；说明时区等字段影响哪些功能。 |
| 目标／新增／编辑 | 三端在我的首页展示和编辑目标，可表达期望结果、日期、状态。 | **P1** 目标在我的管理，在进展展示发生变化的相关工作，点击回目标或事项详情。 |
| 关于你／理解列表／条目详情 | 三端有个人理解或记忆页。A 有概览、筛选、详情及删除；I 按基本信息、最近关注、协作和记忆组织；H 有独立路由。 | **P1** 用「我提供的／助理记住的」组织入口，条目展示来源、更新时间和纠正或删除动作。 |
| 应用设置首页 | 三端有 Gateway、分享、语言、外观、关于。H、I 有通知行；A 根页无同类独立行。I 同时由设置进入文件。 | **P0** 统一为连接与通知、数据与分享、偏好、关于。资料可稳定找到文件后，再评估设置里的重复入口。 |
| Gateway 列表／连接详情 | 三端有 Gateway 档案与管理，I 有连接详情页。 | **P0** 首行显示当前 Gateway、连接状态及恢复动作。切换时说明对待发送内容和设备绑定的影响。 |
| 首次配对／新增 Gateway／扫码 | 三端有扫码及手动配对；I 由根视图按令牌进入，H 由 Index 管理，A 在主界面进入配对。 | **P0** 扫码为主，手动连接为辅；分别提示码失效、Gateway 不可达、授权失败，配对后恢复原目标。 |
| 通知设置／系统权限 | H 有应用内注册状态；I 有系统通知入口；A 本轮只核实根页差异。 | **P1** 在支持的平台分开显示系统授权和 Gateway 推送状态，并给对应恢复入口。 |
| 语言／外观／关于 | 三端有语言和外观。关于可能是版本行或独立页。 | **P2** 语言和外观即时预览；关于集中版本、构建与诊断。 |
| 系统分享导入 | H 有 ShareIntake 与导入弹层，A 有 ExternalIntakeHost，I 有 Share Extension 和导入选择。 | **P0** 预览对象后选择当前、指定或新建对话。退出后可恢复未完成上传，分别反馈「已添加」与「已发送」。 |
| 通知／消息内链接／跨页跳转 | H 有校验 Gateway 的通知路由；三端有各自的消息链接和跨页跳转。 | **P0** 直接打开对象详情，保留来源与返回路径；对象失效时回可达上级。首次连接成功后重新解析原目标。 |

## 4. 建议的一级架构

首期继续使用五个位置，将「笔记」在覆盖文件、成果与录音后扩为「资料」。

| 入口 | 用户来这里做什么 | 首屏优先内容 |
|---|---|---|
| 助手 | 交代、追问、调整 | 当前会话、输入、当前工作状态 |
| 对话 | 找一段历史并继续 | 搜索、主助理入口、置顶和最近 |
| 进展 | 查看需要决定的事，接收交付 | 待我处理、已交付、进行中、接下来 |
| 资料 | 记录、找回、引用 | 搜索、最近使用、可恢复的录音、新建 |
| 我的 | 管理助理、个人信息和连接 | 助理档案、关于我、目标、设置 |

**共享底栏。** 助手保留完整输入栏；对话、进展、资料根页可用一个轻量「问助手」入口，带当前项目、任务或资料引用进入会话。我的根页默认仅保留导航。阅读、编辑和接管详情使用各端原生返回与键盘行为，减少底栏占用。先用小屏验证「直接打字」与「点一次进入输入」的完成率，再决定是否进一步收敛快捷输入。

**同一对象跨页复用。** 一次委托产生对话、任务、运行和成果。进展引用任务或待决事项，资料引用成果或原始资料，项目呈现同一对象的集合。通知和站内入口共享对象标识、权限校验与当前状态。用户读完成果后可回到原对话续改，退出后回到进入前的列表位置。

**典型链路。** 在助手说「帮我整理客户会」→ 进展提示需要确认的行动项 → 确认后打开对应任务 → 会议纪要从进展的交付卡和资料检索都能打开 → 在纪要点「继续修改」，带上对象引用和版本回会话。

## 5. 交付顺序与验收

| 阶段 | 工作 | 验收 |
|---|---|---|
| P0 · 导航和任务路径 | 保留五入口，优先统一会话身份、底栏去向、任务回跳、进展首屏、文件入口、配对与外部分享。进展先展示当前接口明确返回的待处理、运行和结果信息。 | 三端从任务详情、项目和对话列表打开任务对话，都能返回各自来源。外部文件进入所选会话，配对或上传中断可恢复；对话切换后回到原草稿。 |
| P1 · 成果、资料和持续工作 | 交付物、笔记、文件形成可索引的资料入口；统一项目详情、自动化和单次运行结构；补会议行动项、助理档案、记忆与设备接管路径。 | 同一成果从进展、资料与项目打开同一对象；可见范围一致。录音后可找回纪要和关联任务。接管再交还后回到原工作。 |
| P2 · 信息发现 | 基于使用数据扩展跨对象检索、长周期目标视图和入口个性化。 | 记录找历史、找结果、查某次运行的成功率与耗时，按端比较。对话是否并入助手内的历史入口，先用原型测重访效率，再决定。 |

实现依赖包括跨入口可解析的对象 ID、可分页的成果查询、真实最近访问记录，以及跨入口同步的待处理状态。优先复用 Gateway 的任务、运行、交付物和会话标识。成果索引尚未覆盖的内容保留明确入口和搜索范围说明；「最近使用」以打开、编辑或引用记录为依据。资料改名放在文件、录音和成果都有稳定入口之后。

真机验收用同一套业务用例覆盖三端。至少走一遍未配对进入、对话草稿恢复、通知待处理、项目内继续任务、录音中断后恢复、查找旧成果、接管和交还。每条同时记录入口、实际点击数、返回位置、异常恢复和是否出现重复操作。结合当前基线设定点击数和耗时目标。

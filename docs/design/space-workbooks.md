# Space 工作簿

## 用户工作

用户拿到一份预算、订单明细或任务产出的表格后，可以在 xopc 里改几处数据、确认公式结果、把需要讨论的单元格放进对话，再交付一份 Excel 文件。Space 的工作簿是这段工作的资料对象，版本可以在后续对话和任务中复用。

## 首版交互

1. 在资料库新建空白表格，或导入本地 `.xlsx`、`.csv`、`.tsv`。点开已有表格资料时，先预览并从指定版本创建可编辑副本。原始文件继续作为资料存在，副本可以沿用来源对话和项目。
2. 打开工作簿时进入铺满内容区的编辑器。顶部始终显示名称、保存状态和操作，公式栏、网格、工作表标签使用同一套编辑器状态。键盘可以切换单元格、输入公式，并用 `⌘S` 或 `Ctrl+S` 保存。返回资料库后可用原来的入口继续编辑。
3. 「在对话中使用选区」先显示工作簿名、工作表名和范围，再让用户选择近期对话、搜索已有对话，或指定助手开新对话。来自原资料的对话在列表中优先展示。选区以可检查、可移除的附件加入草稿，保留已有草稿内容。个人助手是一个可选目的地。提交仍由用户在目标对话中决定。
4. 显式保存产生可重开的版本。历史版本以只读方式打开，可以单独导出或使用选区。保存冲突时保留本次编辑，并提供「保存副本」。从编辑器切换到对话时，同一浏览器进程内保留已提交的单元格编辑。关闭或刷新时使用浏览器的未保存提醒。
5. 「下载此版本为 Excel」导出当前查看的已保存版本。导出范围覆盖表格数据、受支持公式、数字格式、合并单元格和基础列布局。

## 可支持的工作簿

采用开源 Univer Sheets 和现有 SheetJS，文件在本机转换。导入适用于日常分析表和可移植的多工作表计算。XLSX 编辑副本保留基础表格信息，图表、透视表、宏、批注和完整 Excel 样式不在复制范围内。现阶段对数组公式、引用其他工作簿或依赖表结构及自定义命名区域的公式给出无法转换的反馈。文件大小、表数和工作表尺寸超限时保留原资料，导入失败可重试。

## 验收

- 导入用户自己的预算表，编辑实际支出，确认跨表公式刷新。保存并下载 XLSX，用独立解析器核验公式、值及工作表。
- 把不同选区分别放入已有对话和由所选助手开启的新对话。检查加入前后原有草稿、实际模型输入和选区范围。
- 从 Space 重新进入同一工作簿，切换新旧版本并验证历史版本只读。模拟两次编辑使用同一个基准版本，验证后提交者能够保存副本。
- 用真实 Web 与 macOS Electron 窗口走查中文、英文、浅色、深色、键盘操作和窄屏。用多工作表真实样本记录首次打开时延、保存开销和格式保真；在这些数据齐备后决定是否扩大格式支持。

## 后续验证

工作重点是确认用户能完成一份真实工作簿的调整和交付。首批试用看三件事：导入后是否能在 xopc 内完成修改，选区能否顺利进入正在工作的对话，导出的文件能否直接交给接收方使用。需要高保真回写原始 Excel 模板的用户流程，使用单独的样本集验证复杂公式和版式后再决定转换实现。

# Accio 插件迁移到 XOPC Store

2026-10-19 完成 20 个源包的一对一用途迁移及发布，现有目录保留四个专项包、清理四个重复包装包。线上目前 24 个正式插件与三个明确标注的测试插件，另保留原生 Extension Lab。

完整映射、授权方式、证据和生产验收步骤见 [迁移报告](/Users/micjoyce/develop/github/xopc-plugins/reports/accio-migration-2026-10-19/README.md)。

本轮补充安装器的两个能力：

- 同一资源 ID 可声明六个系统/架构变体，客户端只下载当前平台唯一匹配的版本。Store 扫描所有变体的地址、摘要和大小；客户端完成 SHA 校验后使用固定资源路径，不要求用户手工安装 CLI。
- CLI 授权方法可声明自己的凭据字段，使用与 Token 表单相同的本地秘密引用机制。提交后先保存、再启动登录，适用于飞书手动 App ID/Secret 与 Google 桌面 OAuth。字段不再进入重复的全局配置步骤。

安装与账号授权保持分离：准备完成后可跳过账号并全局启用插件；缺失账号的执行服务不会投影到 Agent；详情页继续授权后才按实际连接检查结果加载工具。

真实 Store/Gateway 逐包验证 24 个包，实际浏览器验证五个账号插件，官方 CLI 与 OpenBoost 原生 OAuth 均取得真实挑战且随后取消；真实业务账号的同意和业务调用留给用户生产验收。原有授权 Lab 的 17 场景也重新通过。

语雀使用公开 API，钉钉与飞书使用固定官方 CLI，Gmail 使用用户自己的 Google Desktop OAuth 应用，OpenBoost 使用公开 MCP。其余 15 个是独立工作流版本，不能将安装成功理解为复制了 Accio 私有商家后台、CRM、知识库或云端部署服务。

插件与资源已上线；客户端改动在当前本地 Gateway 中运行，尚未发布 npm/桌面客户端版本。

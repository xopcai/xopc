## 主要诊断

- **路由**。R05 两种认证用同类自然语言任务触发。Token 隔离运行发起了工具搜索，但没有进入 MCP 发现，随后要求用户提供地址或先连接设备。该运行的模型请求均返回 200。OAuth 普通查询在初始运行和固定空目录复跑中都通过，说明现有模型能触发发现，但目前结果不足以证明该路径稳定。认证类型只是夹具变体，不能从单次运行推断失败与认证类型存在因果关系。
- **授权**。显式 Token 对照走过来源审核，最终配置目标选择了自动认证。夹具返回 403 后进入 `auth_unknown`，未自动出现密码框。该对照在卡片认证阶段停止，恢复阶段未执行。安全 Token 保存和原生 OAuth 回调的集成测试仍通过。
- **续跑**。OAuth 实测在原会话读到了后端记录的唯一标记，日志与会话均未出现测试凭据。连接等待已有重启、重复回调和失效保护。R13 目前证据止于宿主检查点与消费边界。
- **运行异常**。未隔离目录的首次 Token 普通查询中，Gateway 因 `UND_ERR_INFO` 的 HTTP/2 空闲错误退出。该次记为运行异常。后续使用固定本地空目录重跑，得到上面的路由结果。

# CLI Connector 实施与自检记录

日期：2026-09-20。依据 [技术方案](./cli-connector-runtime.md) 实施。用户确认现有飞书连接器无人使用，因此直接替换，不实现迁移、双轨或旧凭据兼容。后续用户要求继续开发、暂缓扫码，真实账号验收单独保留。

## 阶段 A：固定版本与协议

- 固定飞书 1.0.96、企业微信 1.3.0，声明 macOS/Linux x64/arm64 发行物及完整性摘要。
- 实际通过管理安装器下载并验证 macOS arm64 二进制。12 个动态动作 Schema 实际解析通过；另有 2 个飞书文档快捷动作使用与版本绑定的静态契约。
- 实际启动两家授权流程，取得飞书初始化链接与企业微信二维码；用户暂不扫码后取消了两项授权，清除了此次临时授权目录。
- Review 修复：飞书实际资源命名不同于原始 OpenAPI；企业微信使用裸类型 `$ref`，需要转换为本地 JSON Schema 引用；飞书用户授权必须提取 `verification_uri_complete`，不能误取不含验证码的基础地址。

## 阶段 B：运行与授权基础

- 新增受管理安装、私有上下文、环境白名单、无 shell 参数执行、超时/取消/输出限制、结果归一化。
- SQLite v187 添加 CLI 账号归属、授权状态和执行记录。运行实例复用现有 config 记录，没有新增重复的实例注册表。
- 授权先在独立目录完成身份验证，再事务提交稳定账号；重连复用原应用配置，取消、过期或身份不符不能覆盖旧连接。
- Review 修复：tar 二进制输出按 Buffer 捕获；重连不复制旧结果文件；不同存活进程不被误判为已重启；取消与停用终止相关子进程。
- 测试覆盖真实子进程参数隔离、超时、输出截断、产物越界/符号链接、完整性破坏、并发安装和新版本安装失败保留旧版本。

## 阶段 C：发现、权限和恢复

- 新增 `CliToolProvider`，接入现有外部工具 search/describe/execute、账号权限、审批、目标绑定、审计和 Workflow 预检。
- 审批绑定参数、账号、连接、目标、身份范围、适配器版本、二进制版本和动作修订；在实际启动前重新读取权限，审批消费与执行记录创建使用同一事务。
- 同账号执行串行化，写入不确定结果持久化为 `unknown`，禁止自动重试与审批复用。失去执行进程的记录也恢复为 `unknown`。
- 未授权时可以通过统一 connection candidates 发现 CLI 服务；授权入口和原任务恢复接入已有连接等待机制。批量读取必须明确指定账号。
- Review 修复：审批哈希在创建等待目标之后计算；重连、参数变更、重复审批、执行前收紧权限均会拒绝；CLI 账号不被 Composio 后端初始化收编。

## 阶段 D：适配、API 和界面

- 飞书 MCP 定义与专属旧测试已删除。飞书、企业微信共享授权/账号弹窗，支持恢复待授权状态、取消、重连、本地断开、停用、连接检查和移除。
- 管理 API 使用 Gateway 管理鉴权与 lazy dispatch；授权状态和产物禁止缓存。JSON 结果产物通过执行记录和账号归属校验后下载。
- 真实本地 HTTP 测试覆盖鉴权、路由、权限设置、授权恢复/取消、产物下载和跨 principal 拒绝；浏览器测试覆盖英文宽屏、中文窄屏深色、权限选择、链接/二维码、取消和 Escape 关闭。
- Review 修复：补齐 CLI 健康检查、连接状态展示、健康记录以及连接恢复流程中的非 Composio 分支。

## 阶段 E：分发与扩展验收

- 商店 CLI manifest 只能引用已注册的固定版本适配器，拒绝任意命令、可执行路径、代码与环境覆盖。
- 第三个确定性 CLI 适配器通过同一 runtime/provider 执行真实子进程，覆盖发现、描述、审批、重连失效、权限收紧、并发重复审批、未知写入和 JSON 产物；不添加厂商分支。
- 二进制版本目录互相独立；新版本验证失败不破坏旧版本。支持新供应商版本需随适配器代码和 fixtures 一起交付，不提供任意版本覆写入口。
- 使用和扩展文档：[CLI 连接器](../../connectors/cli.md)。可重复浏览器检查：`pnpm exec tsx scripts/cli-connectors-browser-smoke.mts`。

## 验收范围

代码、离线协议验证、HTTP 与浏览器测试已实现。完整构建、root/Web 类型检查、修改范围 lint 均通过。Connector 与相关网关/外部工具回归共 37 个文件、224 项用例通过；中英文浏览器冒烟测试通过。构建仍有项目现有的 chunk 大小、动态导入和插件耗时提示，无构建错误。

以下项目仍需真实账号验收，不计为通过：登录完成后的读写、令牌刷新、同一系统用户下多账号/keyring 隔离、企业微信机器人与实际授权人的身份关系。两项服务保持 Beta；Windows 尚不开放。当前文件能力是结果 JSON 导出，不开放任意厂商上传下载命令。撤销上游授权需在供应商侧操作，本地断开只禁用 xopc 访问并保留隔离配置用于重连。

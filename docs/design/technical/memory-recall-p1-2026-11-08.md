# 按需深度召回与评测 P1

日期：2026-11-08。建立在已完成的 [聊天记忆 P0](./chat-memory-p0-implementation-2026-11-08.md) 上。

## 实现

复用 SQLite 转录与 FTS、现有知识检索、逐轮上下文 coordinator、主人身份和遗忘边界、模型凭据／用量记录、上下文预算和审计。没有新数据库、向量服务或 schema 升级。

先执行已有检索。普通问候、代码生成、明确记忆修改不增加查询模型调用；直接命中较强的当前事实继续走普通路径。历史／修订问题，或匹配不足的记忆问题才升级：

1. 使用当前会话模型，结合最多两条近期用户问题，把问法改写为最多三条短查询。不给改写模型整份历史或记忆库。遵循已有 local_only 处理政策。
2. 用改写结果重搜允许的当前事实，并在同一助手、规范化工作区和项目内发现匹配会话。候选会话先按查询过滤，再施加数量上限，避免旧来源被无关的新会话挤掉。
3. 通过已有 `recallSession` 读取原始用户语句，并有界追读相邻用户解释。排除当前问题、纯历史提问、临时／未授权来源，以及被遗忘或限定其他会话的来源；检查证据关联的更窄 scope。
4. 既有 `session_search` 的降级读取同样执行范围检查，不能通过工具绕过自动召回的边界。混有更窄 scope 的原始会话保守地整段屏蔽，以覆盖没有字段血缘的标题和助手复述；已独立保存且当前可用的事实仍可由原有记忆工具读取。要检索其他项目的原始会话，需切换对应项目上下文。
5. 把原话、记录时间、会话及条目身份作为背景证据交给回答模型，明确区分记录时间和文本陈述的生效时间。先前决定只作为历史事实；当前回答使用最新明确修订。
6. 继续通过既有整体上下文字符预算裁剪，并把实际纳入的来源记入 `execution_context_items`。没有另建一份记忆正文。

默认一次查询改写、8 秒超时、最多 60 个匹配会话、6 条原话，每条最多 850 字符。引用与其他记忆共同受默认 6,000 字符总预算限制。超时、无效模型 JSON 或本地查询失败时降级，不阻断正常回答，也不把查询失败解释成“没有历史”。

近期查询缓存同样经过遗忘投影，防止已忘内容通过后续查询改写、任务上下文或外部检索重新发送。

## 回答中的来源

历史原话使用当前轮次的 H 编号，审计记录对应的 conversationId 和 entryId。宿主检查引用身份，以及紧邻引用、被标为原话的内容是否确实来自该来源；支持普通、分组及内联引用格式。

历史事实回答缺少引用，或出现伪造编号／改写后冒充原话时，复用已有隐藏消息续答机制修正一次；仍失败则返回执行失败，不宣称验收成功。普通当前事实不强制额外引用，明确无依据的回答可以直接说明不足。

这个校验验证来源身份和原话匹配，不证明模型推理的每个因果判断。正在流式输出的草稿可能在修正前已显示；最终结果、修正状态和转录仍保留，不能把它描述为发布前拦截。

## 评测

固定语料：[recall-cases.json](../../../evals/memory/recall-cases.json)。包含中文转述、按当时时点查询、当前修订、跨会话原因链、连续追问，以及无证据问题。

确定性测试使用参考改写查询，验证存储、权限、检索、裁剪及审计，不把参考查询成绩当成真实模型改写能力。真实端到端则由模型自己生成查询：五条来源通过鉴权 Gateway 的真实对话建立；额外 25 条无关知识通过既有领域仓库写入，明确标为合成噪声。

真实报告逐项记录原检索路径的参考词项覆盖、预期原话的实际纳入、来源身份、模型回答、真实改写次数及耗时。词项覆盖是诊断指标，不能代表答案正确率或历史原因链完整性。保存操作必须有真实提交回执；回答正确但缺少应纳入的原始证据仍判失败。

## 发现的问题

- 持久化工作区在内存会话尚未加载时未被读取；补上既有配置仓库回退。
- macOS 工作区路径 `/var` 与 `/private/var` 指向同一位置，字符串相等过滤漏掉来源；复用现有 canonicalWorkspacePath，同时保留项目／助手边界。
- 网页设备信息和时间包装混入检索与原话；复用既有用户文本投影清理。
- 后续提问占据证据预算，挤掉较早的批准人记录；排除不包含实际陈述的纯提问。
- 最后一个项目外负例发现模型通过既有 `session_search` 取回受限项目原话。增加共享的历史源范围政策，并把本地摘录和摘要路径一起接入；不依赖模型自觉遵守范围。
- 模型有时重排原话、漏引或采用另一种引用格式；增加宿主校验及一次有界修正，评测解析与宿主共享实现。

最新综合复测中，召回 16 项和 P0 27 项均通过；报告在验收完成时为 `success=true`、`errors=[]`，源码指纹无漂移。普通问候没有触发改写。原始运行报告仅保存在本地 `reports/memory/`，不进入版本控制；后续综合回归见 [P1 自动学习记录](./memory-learning-p1-2026-11-08.md)。

在固定语料上，最新复测中原检索上下文覆盖 15 个参考词项中的 10 个，补充的原话覆盖全部参考词项，真实回答通过相应事实检查。这个小样本诊断展示了中文转述、历史批准人和跟进日期的补足，不能作为通用召回率或多模型性能提升比例。

本轮最终真实运行没有触发引用修正；伪造引用、重排原话、修正成功／仍失败及有界续答分支由确定性测试验证。早期真实尝试暴露的原话重排和漏引促成了该校验。

Node/Electron 类型检查、验收脚本类型检查、受影响源文件 lint、Node 构建及 `git diff --check` 通过。构建也完成了浏览器扩展验证。两个隔离状态目录的临时配置和模型文件均已清理；没有修改个人记忆数据库。

本轮针对单一已配置模型、固定合成语料和少量噪声；未声称达到长期大规模、多模型稳定性统计。自动历史追读目前使用活动转录，不自动遍历 reset 后的归档转录。未做视觉 UI 验收。

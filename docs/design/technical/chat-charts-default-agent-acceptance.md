## 数据与行为检查

1. **缺失值与真实零值分开处理。** 五个月、两个设备，甲序列为 `[12, null, 18, 0, 21]`，乙序列为 `[9, 11, null, 14, 17]`。所有模型都保留月份顺序和缺口，没有补零、插值或丢弃月份。截图复核确认折线断开，真实零值落在零线上。
2. **负号、零值与分类映射保留。** 部门甲至丁分别为 `[-1250, 0, 875, -420]`。所有模型都保留四个分类、正负号和数值；真实图表的负柱在零线下方，零值分类仍在横轴。
3. **多序列及小数精度保留。** 三组、四周的数据分别为 `[10.5, 11.75, 9.25, 12]`、`[8.5, 9, 10.25, 11.5]`、`[7, 7.5, 8, 8.75]`。所有模型都保留组别对应、四周顺序及小数，呈现分组柱状图，没有合并、取整或堆叠。
4. **数据全缺失时不伪造图表。** 四个模型均说明没有足够数据作图，没有输出图表、编造读数或补零。该场景均未读取图表 Skill，避免无意义的工具调用。
5. **Skill 按需加载。** 12 个作图用例均自行调用 `skill_view` 读取 `chat-charts` 正文及 `references/chart-spec.md`；检查实际返回内容，不仅检查调用名称。MiniMax 的负数用例还读取了正确路径的柱状图示例。没有使用其他工具来生成或发布替代网页/文件。
6. **真实渲染与历史恢复。** 12 份生成配置均通过生产 `parseChartSpec` 校验与数据对应校验，在完整聊天界面产生非零 Canvas，刷新后继续显示。用例内未捕获浏览器异常。
7. **单位及模型身份复核。** 对保存的原始回答再次运行校验，允许 `CNY`/`元`、`h`/`小时` 等同义单位，拒绝改变计量维度。16 个用例的实际模型均与所选模型一致。

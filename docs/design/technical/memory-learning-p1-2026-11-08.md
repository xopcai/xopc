# P1 自动学习准确性（2026-11-08）

## 行为与实现

复用现有持久化学习任务、用户理解解释器、断言准入、证据链接、删除抑制和执行上下文。没有增加另一套记忆存储或常驻提取器。

- 用户没有说“记住”，但明确陈述长期偏好时，可以自动学习。多次一致的独立选择只作为 `user_observed` / `system_inferred`，置信度不超过 0.85；不能借模型的 `user_explicit` 标签升级为用户声明。
- `capture/evidence-policy.ts` 校验实际来源及所在完整语句。模型不能通过截去“今天”“这次”等限定词，把临时状态提升为长期偏好；临时状态必须具有有效截止时间。
- 引用、代码块、转述、假设角色和助手输出不构成用户事实。用户自己的偏好值即使带引号仍可接受；同条消息中的真实自述与第三方引用分别校验。“好的，谢谢”不能给助手猜测补证。
- 新建或替换观察性断言需要两份独立用户表达及不同支持片段；重复复制同句话不算两份证据。既有断言可以补充一次新观察。
- 解析与提交阶段均校验来源、引用片段和权威级别。目标、协作规则以及工作记忆入口也增加归属检查，个人画像不能用工作知识候选绕过个人断言准入。
- “记住、纠错、忘记、确认”必须来自用户自己的实际指令。普通自述即使被模型标成“记住”，也不能恢复已删除的偏好；继续复用原有作用范围和敏感信息策略。
- 前台可按用户当下偏好回答，但没有真实写入回执时不能声称已经永久保存。自动学习仍由后台流程处理。

真实验收还遇到过前台没有写入工具调用却回答“已写进用户偏好”。新增 `memory-claim-grounding.ts`，对隐式偏好场景的最终保存声明核对本轮成功且可用的 `personal_memory` 回执。复用已有回答校验的单次续答机制，要求明确撤回不准确的保存声明，不能为了补证而临时执行写入；仍不合格时返回失败。验收器同时核对最终回复，不再只检查数据库与工具调用。

## 真实模型验收发现与修复

使用当前配置的 `deepseek/deepseek-flash`，通过鉴权 Gateway 输入及签名浏览器端点发送真实对话，再调用现有 rebuild 接口驱动实际持久化学习工作器。每个场景重放一次并核对数据库、证据归属、执行上下文和新会话回答。没有复制生产记忆。

实际模型曾漏掉“我长期偏好先给结论再列证据”，将同条消息里的“只回复收到”错误解释成整条信息都是临时要求；另一次忽略两次一致的版式选择。解释器现在复用既有最多两次的响应/格式修复预算，在有独立来源证据时最多复核一次；模型仍可弃权，后续仍经过全部准入校验。已被断言证据覆盖的消息不再触发该复核。临时状态、引用和确认语不触发偏好补提取。

实际重放还出现过弃权说明超过长度限制导致整份合法结果被判无效。仅对不参与事实准入的 `abstentionReason` 截断至 500 字符，事实字段、证据及结构约束继续严格校验。

另一轮实际响应正确理解了带引号的本人偏好，但抄错原始消息 UUID，宿主按 `owner_quote_not_grounded` 拒绝写入。现在只在解释器输入边界把消息引用投影为 `source_1` 等短编号，并将输出中的已知编号精确映射回原始证据；数据库仍保存真实消息标识。未知、近似或杜撰编号不做模糊匹配，继续拒绝。测试验证短编号不会写进证据表。

混合内容验收还发现：真实长期习惯已经正确存储，但模型生成 `applicability.operation=report`，而已有执行上下文仅支持 `response`，造成“学到却不可用”。现有提取 schema 现在拒绝不支持的 operation，复用格式修复预算让模型纠正；提交阶段同样拒绝绕过解析的无效值。保留原有执行上下文过滤和作用范围，语义上的“写周报时”继续体现在断言内容中，不通过放宽消费者过滤来修复。

另一次模型复用了已有的 `preference.response.structure`，把“结论和证据的顺序”与“是否使用简短标题”误当成同一单值维度，新观察因此被既有冲突保护标记为 `conflicted`。提取和复核提示现在要求比较现有断言的实际含义，为兼容的独立维度使用精确谓词；不放宽冲突保护，不自动重命名已有断言或覆盖显式偏好。

选择模式的复核使用已有检索词法相似度函数筛选不同消息，避免给重复原文补证；相似度本身不授权写入，语义是否一致仍由解释器判断并通过宿主准入。`user_explicit` 表示用户直接自述了事实，不代表用户明确要求保存；后者必须另外验证真实记忆指令。

验收按来源绑定、实际语义和顺序判断偏好，而非要求模型保留测试标签。明确自述的长期表达习惯可合理分类为 `preference` 或 `routine`；观察性版式选择仍要求 `preference`，不能混入身份或临时状态。数据集见 [learning-cases.json](../../../evals/memory/learning-cases.json)，运行器见 [memory-learning-live-cases.mts](../../../scripts/memory-learning-live-cases.mts)。

## 范围

这是中文和英文证据规则与有限真实语料的验收，不能当成任意语言或任意模型的整体准确率。观察性学习沿用已有批次证据窗口，不新增跨任意历史窗口的观察累积器。当前没有视觉界面验收。

回执校验沿用已有流式回答纠正流程，校验最终回答；若不准确草稿已流式展示，会续答明确撤回，未新增前置输出缓冲。

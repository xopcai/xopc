# Phone Use 执行效率优化：第一轮实现与验证

第二阶段实现与最终质量、速度对比见[常驻观察与字段短事务报告](phone-use-efficiency-phase2-2026-10-27.md)。

日期：2026-10-27。起始基线：`0e9c738200df2448c2cf6c0c7bd80136634612df`。

本轮落实分段计时、AutoGLM 单项消融和设备初始化优化。默认模型协议、采样参数、动作预算、语义/分层开关不变；没有修改用户实际配置，没有发布。

## 已实现

- `PhoneRuntime` 为 open/run/step/observe 分配 operationId，报告与 `phase=execution_timing` 日志记录 UI 树、截图、模型请求、派发、输入确认等耗时。阶段可能嵌套或并行，不能相加作为墙钟占比。
- 模型记录请求/图像/响应字节、HTTP 状态、usage、结束原因与错误码。JSON 首字节不冒充首 token；SSE 可记录首 token。诊断不包含屏幕文字、提示词、原始推理或凭据，不进入主 Agent 规划文本。
- 云端 helper 按内容哈希校验复用，缺失或损坏时重新部署；修复 Android 15 缺少主 Looper 导致的崩溃并重新生成 DEX。仍为 one-shot UI 读取，并非常驻观察服务。
- Unicode 输入在一次操作内复用专用 scrcpy 通道，结束、接管、交还、取消和失联时清理；不重放未知输入。取消后迟到的预测不能派发，也不能保留执行历史。
- 增加独立的上游提示、消息轮次、采样参数对照，以及 SSE 和重复输出检测。上游历史最多保留八轮已确认派发的响应，只存在内存中。保留 xopc 权限和独立完成验证，并非原样运行上游 Python agent。
- 多字段视觉合并读取提供实验入口；真实验证失败，默认关闭。未放宽解析器，也不将截图读数升级为已验证完成。

高级配置及默认值见 [Phone Use 文档](../../phone-use.md#execution-diagnostics-and-controlled-model-experiments)。上游提示固定于 Open-AutoGLM `86f55382982fb054e8fc98ca80609dff8a2cdc3c`；Node/Electron 包均携带 Apache-2.0 许可证。

## 验证结果

仅操作专用 `XOPC_Android_Test_API_35`，使用真实 AutoGLM API。完成率要求两次独立终态检查，不以模型 finish 计成功；检查系统设置与测试文件不变，初始化不匹配整对排除。

### 七任务配对回归

28 条记录中排除一对 Clock 起点不一致，保留 13 对；实际共 94 次模型请求。

| 有效配对口径 | 基线 | 优化候选 |
| --- | ---: | ---: |
| 独立完成 | 8/13 | 9/13 |
| 模型请求 | 50 | 43 |
| 错误已验证完成 | 0 | 0 |
| trial 时间合计 | 450.685 s | 378.460 s |
| trial 时间中位数 | 23.975 s | 19.145 s |

这是小样本可靠性回归，**不能证明普遍提速或统计非劣**。本地 ASCII 任务没有直接触发云 DEX、Unicode 或合并读取优化，耗时差异也受模型路径与长输出影响。计时器配置与 Files 搜索仍有失败。

计分使用冻结的中间候选；之后增加了计时细节、helper 兼容性、实验合并开关与取消/接管清理修复。最终版本经独立机制检查和自动化回归，不将该面板冒充逐字节最终版本的完整真实验收。

### 设备与长尾机制

- 实际云 Driver 经本地 ADB 桥完成 UI 树、截图、方向和前台包关联检查，读取 21 个节点、1080×2400 图像。缓存臂首次上传一次，后续两次零上传；本地耗时区间与 one-shot 重叠，不宣称公网云手机提速。
- 连续三次中文/emoji 替换均通过原生字段检查。包含观察与收尾的整组时间为 15.413 → 14.975 秒；有预热和顺序影响，只证明复用路径可用与小幅节省。
- 两次合并字段读取均失败：一次格式校验未通过，一次达到 3000 tokens 截断。`batchReadings` 保持默认关闭。
- 计时器流式配对因起点失配不能用于速度比较。另一次独立流式诊断在 4.889、8.681 秒中止两段重复输出；任务最终仍失败。不能将快速失败计作完成提速，也不能把取消后的缺失 usage 计为零费用。流式与重复检测保持默认关闭。
- helper 与 Android CLI 会争用 UiAutomation。测试仅在专用 AVD 分阶段停止 CLI 仪器服务；生产没有自动停止其他自动化服务的逻辑。后续常驻观察方案必须管理唯一所有者。

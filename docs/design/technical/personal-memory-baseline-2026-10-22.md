# XOPC Memory 首轮基线与失败归因

日期：2026-10-22。**已完成：184 条冻结基线、120 条 LongMemEval 原生评分、全部证据诊断，以及独立 3 条补充诊断。产品逻辑未修改。**

本轮最值得优先处理的是检索契约与中文词块、时间锚点返回、证据链接写入，以及历史导入路径的遗忘状态。偏好应用也明显偏弱，但不能只靠扩大记忆注入或复述背景来提高分数。

## 2. 已确认的实现问题与归因边界

| 问题 | 实测证据 | 结论与下一步 |
| --- | --- | --- |
| 搜到会话却读不到正文 | `zh-multi-hop-0-q2`：多词 OR 搜索命中 History0003，摘要读取却按整句短语匹配而为空；同一数据库副本改搜 SQLite 即找回答案 | 已复现的契约不一致。统一关键词匹配语义，保留明确的短语检索模式与权限过滤 |
| 中文词块漏候选 | 同一源历史搜“青禾”无候选，已知会话 ID 后原文子串能读到；完整词块“青禾选择”又能命中；FTS 为 unicode61 | 已复现的候选检索缺口。不能用增加 top-k 代替中文检索修复；该探针不是原多词请求的唯一根因证明 |
| 找回“今天”，未找回日期 | `lme-bcbe585f` 搜到观鸟工作坊原文，摘要却没有 createdAt；源日期 2023-04-01，查询 2023-05-01，相距约 30.16 天，回答猜成两周 | 返回事实时需同时给出源消息时间、身份和可追溯入口；缺锚点时不能编时间差，不能只称算术差 |
| 同源多引用写入崩溃 | 隔离库中，生产 `applyWorkCandidates` 对同一来源的两段合法引用，新增、更新均触发 knowledge_evidence_links 唯一约束；单引用、不同来源对照成功 | 已复现可达缺陷。验证引用后按证据 ID 幂等写链接；保留原始引用信息，不改事实权限 |
| 库存有事实，但不等于有权自动注入 | 绘画挑战和花卉技巧 active/supported，却归在旧会话 session 级知识；新问题实际注入冥想。中文“移动端”处于 needs_review，补查又漏关键词 | 分别检查抽取类型／作用域、适用条件和合法历史补查。不能直接取消 session 限制或把待复核事实改 active |
| 时间／事件绑定不完整 | 中文交接只取回 15 日计划、遗漏 20 日延期，回答将计划说成已接任；岗位题把已知 Senior Engineer 五人团队转给未确立的 Manager 入职事件 | 要求证据链覆盖主体、岗位／事件及时间；不从近似相关事实补出缺失关系 |
| 未找回最新值 | 旧鞋位置题只找回旧助手提及，回答床下；漏掉后来的鞋架记录，库存没有鞋子位置 | 是最新证据遗漏，不能当作“已存新值被覆盖”的证明；需带来源时间与作者身份核查 |

本轮 **5,931 个学习任务中有 219 次错误**：153 次证据链接唯一约束、66 次通用 invalid-output。104 条病例至少有一项学习错误。13 条病例的标注证据批次发生错误，其中 7 条最终仍答对；**同题出现错误不证明它造成该题答错**。通用 invalid-output 还混合模型／结构化输出／服务失败，不能都归为模型理解错误。

全部统计基于冷重放：每个问题独立学习一次历史，未做同一快照下的重复方差实验。多跳四条失败均缺少必要关联的一环；目前不能由 4/8 推出需要图数据库，或证明模型拿到完整合法证据后仍不会多跳推理。

## 3. 遗忘状态与三条补充诊断

原中文遗忘后五个检查点，**5/5 仍有 active 的日期衍生知识**。以 q4 为例，三段学习均成功，遗忘指令的抽取任务完成但无输出；旧日期与更正日期都保留，抑制记录为零。口头说“不复述”不等于真正删除或抑制。

边界：这里测的是**历史导入／后台学习路径**，没有执行历史来源当时的前台工具动作。因此不能据此断言实时聊天忘记命令或 UI 删除也失败；后续必须补实时闭环控制。原始 transcript 仍有权访问，也不等于允许未经请求复活衍生记忆。

另行预先冻结的三条开发诊断均失败，未混入 184 条：

| 补充题 | 结果 | 归因 |
| --- | --- | --- |
| 明确问“上次记录里继续哪个项目” | 选远帆，正确应为青禾 | 修去跨日歧义后仍有真实焦点遗漏 |
| 明确接着上次最后讨论的项目问下一步 | 先答青禾补测试正确，又安排之后做远帆结算页 | 未开始不代表已决定随后执行；出现无依据跨项目顺序 |
| 不提醒遗忘，只要求回顾青禾 | 复述 27 日和 25 日两个日期 | 确认历史导入路径会在普通回顾时再次带出日期；不能仅靠提示里提醒遗忘 |

补充题的学习任务 9/9 成功，但遗忘探针仍有 active 日期。它们是问题定位用开发集，不是独立泛化验证，也不是对原失败的替换或产品优化收益。

## 4. Benchmark 与裁判自身的问题

- 原项目 q3/q7：10 月 12 日说“今天只讨论青禾”，10 月 22 日的新会话却问“今天／刚才”。原分数保留，补充题改问上次讨论。未来中文 v2 修正措辞；v1 仍可逐字节复现。
- 遗忘恢复 q8：日期 27 日答对，新授权允许读取；裁判因来源／先前遗忘表述判失败。不能报告成日期错误或未经授权披露。未来 gold 允许如实承认此前遗忘未完成，不能要求虚称已删除。
- 上游示例：洗发水原文只说购于 Trader Joe's，未明确品牌；调酒经历不必然意味着不喜欢基础配方；自行车源文是决定升级及索取步骤，不充分证明已完成维修。原生分数保留，不能为命中 gold 将推断或计划改成事实。
- 裁判把按 10 月 22 日推得的“明天 23 日”误称无依据；该题确因遗漏忌口失败，但不能把正确日期算作确认幻觉。诊断输入数字时间将来可加可读时区，若改变提示须重新评同份旧回答。
- 自动分桶有 19 条 benchmarkConcern，包含答对题；这是待审标记，不等于 19 条已确认坏题。来源链接覆盖是可追溯性 proxy，不能当语义 Recall@k；缺完整来源 ID 不证明没有找回正文。

评分记录保持可核对：原队列有 3 项错误——候选 502、裁判 overload 空输出、工具文本转义校验异常。v3 对全部同一份原始输出重新校验，恢复转义误拒；overload 只对同一份回答补判一次即成功，评分提示和模型不变。最终只保留候选 502 一项不可用回答。**没有重新生成候选，没有重试有效低分，没有覆盖原始记录。**

## 5. 后续优化顺序（尚未实施）

| 优先级 | 动作 | 验证要求 |

| P0 | 统一会话候选／摘要查询语义，补中文关键词检索，返回源时间与 entry 身份 | 固定同预算与权限；复现探针、已知源时间题、完整回归；不以更大上下文掩盖漏查 |

| P0 | 验证并修正历史导入对遗忘的处理；补真实前台控制 | 状态断言＋不含遗忘提示的回顾；保留负责人；新授权读取与常驻重存分开；不推断 UI 删除结果 |
| P1 | 偏好抽取分类、合法作用域路由与相关性选择；补岗位／事件／有效时间绑定 | 先跑可用合法证据 oracle 和 no-memory，对照固定快照；保护计划／事实、第三方身份及待复核条款 |
| P1 | 扩独立验收场景与真实到达模式 | 新人物之外还需新事件结构；目前预留集仅模板变体。已分析的诊断题不可再当未见验收集 |

先用小规模消融定位，独立验证通过后再完整回归。收益看有用事实是否正确应用、错误使用是否减少，保留风格与克制保护；不要用增加记忆条数、引用私人背景或减少合理弃答来替代收益。

## 6. 运行成本、实现与可复现性

原捕获耗时约 **3 小时 55 分**。QA 轮次租约耗时 p50 **13.3 秒**、p95 **87.8 秒**；它包含模型及工具往返，不是首字延迟。每题含历史摄入的冷重放 p50 **392.2 秒**、p95 **530.5 秒**，不代表生产一次摄入、多次查询的摊销成本。

原基线及其评分／一次裁判服务补判的用量：gpt5.6sol **7,150 次调用、45,074,926 tokens**；gpt6.1sol **303 次调用、2,167,392 tokens**。失败调用亦保留；账单费用未知记 null，不能解释成免费。三条补充诊断另有自己的用量，不混入此表。实际并发峰值为生成 4、裁判 4；没有串行控制实验，不宣称相对提速倍数。

隔离 SQLite、配置与工作区，保留源角色／时间，通过生产学习入口与带认证 Personal Gateway/realtime 提问。每次只接纳一段来源并处理全部批次，查询阶段禁止新记忆写入。未复制个人历史、记忆或连接器业务数据；模型授权共享标准凭据刷新锁，临时配置清理，输出日志按产品规则脱敏。

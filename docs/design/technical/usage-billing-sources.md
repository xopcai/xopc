# 用量页面：Cloud Credit 与外部供应商费用

## 展示规则

- Cloud 采用平台扣费凭证的整数 microcredits，1 Credit = 10,000 microcredits。
- BYOK / 外部供应商显示 USD 估算；订阅或价格未知的调用保留“费用未知”。该分类不声称所有外部凭据都是 API Key。
- 本地调用标明不扣 Cloud Credits；本地算力费用不在此页面估算。
- 两种单位不合并。按场景、按模型、最近调用和顶部汇总遵循同一规则。
- 调用成功/失败与扣费状态独立。只有凭证确认结算才能显示实际扣费；预留显示结算中，凭证确认释放才显示零扣费。
- 统计范围为当前设备保留的调用记录；账号跨设备全量账单通过 Cloud 明细入口查看。历史调用没有平台请求 ID 时显示“费用未确认”。

## 数据与关联

SQLite v242 添加 `cloud_request_id` 与 `cloud_billing_json`，保留原始历史记录。平台请求 ID 唯一索引防止同一凭证被多个 observer 重复计入。

LLM 的 `onResponse` 回调读取 `x-xopc-request-id`，保留调用方原有回调。Cloud 图片生成、文件 STT、HTTP TTS 也各自建立调用记录，因此 BYOK 聊天中的 Cloud 工具费用不会归到外部供应商。

调用结束后通过既有 OAuth `account:usage` 接口同步对应凭证。用量页刷新时最多并发同步四条未完成凭证，优先轮换最久未尝试的记录；网络超时、缺少授权和不存在的凭证不会制造零金额。实时语音仍以平台全量账单为准，未在此处新增实时会话记录。

`/api/usage/*` 添加 `billing` 投影：每次调用声明计费来源；汇总分别返回 Cloud 确认金额、当前预留、未确认数量和外部供应商估算。Cloud 历史美元估算从所有美元汇总及展示中排除，不转换为 Credits。

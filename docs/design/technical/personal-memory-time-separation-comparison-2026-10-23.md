## 新失败归因：初始准入与来源覆盖相互作用

失败世界：`episode-time-validation-04`（云浦／苇岸两份拍摄合同，同一供应商）。QA 最终没有复述目标价格，裁判判正确；输入级 P0 检查却发现真实越界，不能用最终答案掩盖。

1. **遗忘前已经漏学**：原历史包含云浦原报价 6520 元、联系人林沐、会面地点清泉会客室，以及苇岸报价 7350 元。四个工作事实候选被准入拒绝；初始活跃记忆只有同一供应商关系和后续更正价 6940 元。联系人／地点在执行遗忘前就缺失，不能归为遗忘误删。这是抽取／准入质量问题；存储只记录 `rejected`，未保存具体分支原因，不能武断断言是证据引用、scope 或敏感度哪项导致。
2. **遗忘来源覆盖缺口**：删除更正价时，边界依据已准入目标的 evidence／revision 链建立，覆盖更正对话与执行遗忘的会话；初次被拒绝事实所在的原始对话没有进入该链。SQLite 的规则条件实际只包含更正源，原价源 conversation ID 缺失。
3. **混合源工具出口泄漏**：新 QA 只有供应商关系可自动注入，模型为查询两份合同及联系人／地点调用普通 `knowledge_read`、`session_search`。后者返回原始混合片段，其中同时包含目标原价 6520 元与允许的另一合同报价 7350 元。该回合没有显式原文读取授权，却有一个实际 answer 请求收到目标原价。最终未输出该价，仍是输入级披露失败。
4. **不是时间包装或误判**：时间分离审计通过，planner hash 匹配未包装问题；目标价格不是时间戳、UUID 或非目标合同价格的碰撞。初始保留字段缺失也有独立快照证据。门禁四个检查点均失败（28/32 是其他七个世界全通过），不把一个世界的多个检查点当作独立失败用户。

证据：正式根目录的 `validation-04-forensic.json`，以及该 case 的 `initial-learning.json`、`learning.json`、`model-inputs`、`time-separation-audit.json` 和已关闭 SQLite。分析与重验证均零模型请求，无修改原记录或有效裁判结果。

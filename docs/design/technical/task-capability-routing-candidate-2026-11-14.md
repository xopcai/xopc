# 任务内连接与续跑验收

2026-11-14 · Owner Web Chat 纵切

## 交付范围

- 普通业务请求缺少匹配工具时，Agent 可走现有连接器与插件、再发现远程 MCP。工具搜索结果和系统指令使用一致的规则。
- Web 和桌面宿主端从当前会话状态提供连接入口。来源审核、密钥输入和登录按当前状态给出主动作，安全弹窗承接后续步骤。纯文本渠道保留安全入口链接。
- 有同一接入文档支持的端点、Bearer 请求头和手工取密钥步骤时，配置草稿可识别 Token 路线。发现来源仍需审核和连接诊断。只有拒绝响应或 OAuth access token 示例时，保持认证不确定或走已验证的 OAuth。
- 复用原会话续跑和版本隔离。连接通过验证后恢复原任务，结果由真实工具调用决定。

真实聊天使用 XOPC Cloud GPT‑5.6 Sol、独立状态库、模拟 MCP 服务及 OAuth 授权服务。R05 检查消息正文无连接路径、卡片只有一个连接入口、授权前没有业务读取、最终助理消息含真实服务响应、服务只被读取一次、队列只有一条续跑输入，以及会话、配置、模型请求与日志不含测试凭据。根项目和 Electron 类型检查通过，Web 生产构建通过。

前期有本地 Gateway 连接重置，以及业务断言通过后 Playwright 截图超时的样本。原始失败报告保留。最终评测使用非复用的本地 API 检查连接，将诊断截图失败一并写入报告。四个已通过场景的最终截图超时，初始卡片截图和功能断言均有证据。该轮数据用于确认链路与回归状态，样本不足以估计生产成功率。

## 产品修复

1. **来源引用投影**：`knowledge_search/get/read` 与 user-context 来源出口按同一遗忘边界过滤 provenance，包括证据 ID、消息 ID、conversation 引用。安全正文继续可用；屏蔽只表示原始证据片段不可自动披露，不表示仍有效的另一事实被撤回。at-rest 原始审计不改。
2. **副本边界传播**：遗忘会保护原始来源及执行遗忘的会话，涵盖删除前工具结果已进入会话的副本。明确重读在当前会话只写入规则 ID，后续普通回合与重启后重新屏蔽，不保存被读出的值。
3. **引用不授权删除**：删除操作除引用落在真实 user evidence 外，还校验未引用的作者指令。引用、代码块、blockquote 与否定不能成为变更授权；另保留真实 workspace/project 可见性与 grounded retention 校验。
4. **缓存快照复核**：在模型发送边界，对 `<user-context>` 中已被 suppression 指纹撤销的原样事实重新过滤，防止旧任务／会话快照继续注入；保留合法事实，原始记录的一次读取不因此被删。
5. **合法重读提示**：同一作用域、对象与日期／价格字段匹配当前作者请求时，生成无值、仅当前请求有效的授权说明，提示使用正确历史工具。不给其他对象／字段、引用或否定请求放行，不绕过源权限，不允许重新保存。

原始对话仍可在合法显式请求下读取；这是派生记忆与自动披露边界，不是删除原始对话。当前轮例外只支持 date_time／price，其他字段保持保守不放行。

## 协议补齐与真实路径

- 父运行一次冻结 config/defaults，A/B 共享 SHA-256。临时文件权限 0600，凭证仍走标准刷新，运行结束删除。
- 默认 Agent workspace 也指向隔离目录，避免子 Agent 使用外部工作目录。初始化剥离 catalog 存储元数据后再经严格 AgentEntry schema 更新，新增零模型请求的启动回归。
- Home 在临时评测配置中关闭；内存学习自然定时器停止，按历史／事件顺序显式排空。Gateway 使用 `taskDispatchEnabled:false`，从生命周期入口阻止惰性任务调度器重新启动；两边相同。前台提交与持久化仍保留，但异步接单不算最终交付。
- 不用给私有字段调用 stop 来假定未来不会惰性创建。后台 task allocation／Home 成功调用一旦出现，会导致 protocol audit 失败；所有可见实际模型调用保留。
- 保存初始准入见证、每个真实 live turn 的用户／助手／工具行与学习后状态，并传给裁判。真实模型输入按请求保存，检查普通回合是否已经接收禁用值；最终答案拒答不能抵消输入泄漏。
- 每次遗忘、重读后用真实写策略学习，随后问同会话普通问题；重启 Gateway／数据库，再用独立 QA 会话回顾。新 QA 仍禁止写入，不能仅凭 QA 无写入宣称普通可写聊天没有重存。
- 裁判只在空响应且有 transport/service error 时最多补两次，各自独立目录保存，接受第一个有效结果。有效低分与候选答案不重抽样。重验证器跟随已记录的首次有效裁判目录。

这条轨道测完成态，不测自然学习就绪时延、Home 建议、任务最终交付或全规模来源 ACL。真实 project/workspace 的组件保护与合成世界的语义分离分别报告。

B 共 16 个世界、64 个检查点：其中 14 个真实遗忘世界、2 个引用不删除对照。15 次合法单次重读均成功（含一世界重复授权）；检查的普通回合／重启后输入未观察到目标值泄漏，地点与负责人均保留。检查点不算 64 个独立用户；不能据此作全局安全或最优结论。

验证唯一失败是 `episode-validation-02`，不重抽样、不改判。原始事实是同一团队 **12 月 2 日参会**，并未证明论坛举办日期或年份；金标没有要求这些额外推断。该日期从 initial-learning 到每个 live checkpoint、最终学习快照一直存在，遗忘没有把它删掉；同会话两次普通回顾也答出了日期。但新会话只注入团队关系及地点／负责人等 7 条事实，未补查，最终漏答参会日期。

| --- | --- | --- | --- |

第三行 query hash 与原始 execution-context 审计完全一致；其余只是零模型的检索反事实，不是重生成答案。实际 `memorySearchQuery` 只取前 32 个去重词，前置英文时间说明与真实发送时间一起挤掉了末尾论坛词。原始预算 maxKnowledge=12，实际只找到 7 条，不应将其误归因为已用满的上下文名额。重复地点／负责人确实存在，但本例首要证据指向候选发现的查询污染，而非遗忘丢失事实。原始模型输入也确认没有参会日期。

回放证据：`.xopc-evals/memory-query-selection-replay-20261023-v3.json`、`.xopc-evals/memory-query-fts-probe-20261023-v2.json`。原裁判 7/8 保留；对相同原始裁判结果的零模型重验证仍为 7/8，没有新增验证错误。不能把“检索控制恢复日期”改写成“模型 QA 已经修好”。

**晋级决定：停止。** `gate.json` 为 validation=false、full184Started=false。没有本轮 184 条 A/B 分数，也不将历史 pi 1.1 的 88/120、52/64 充当本轮结果。P0 的已覆盖来源／副本通路有明确改善，但评测时间包装仍是阻断完整回归的协议问题。

下一步应先把历史题目时间与真正用户问题分开传递：时间仍对模型可见，但不混入检索 query 或当前作者授权判断；用 query hash、FTS 词与实际模型输入验证这种分离。不要为过分数扩大原文权限、放宽遗忘边界或直接提高 topK 掩盖包装噪声。本次 8 个验证世界已使用，转为开发回归；修改后另封存新世界，再过同样门禁后才启动原 184 条。

当前验收主要是 workspace 工作事实的日期／报价。真实 profile-only 遗忘、无可追踪来源的旧副本、其他缓存渲染方式、自然语言授权的所有表达、自然学习时延与大库容量，均不能由这 16 个世界外推。

所有相关提交仅包含本轮 memory 产品补丁、评测协议、测试和报告；并行工作流改动、原始模型产物、数据库与临时配置不进入提交。

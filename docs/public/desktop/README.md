# Desktop Media Assets

Place desktop app screenshots, GIFs, and videos in this directory. Files in this
folder are served by VitePress from `/desktop/<filename>`.

Reserved filenames:

- `desktop-first-launch.png`
- `desktop-model-setup.png`
- `desktop-chat-ready.png`
- `desktop-agents.png`
- `desktop-memory.png`
- `desktop-settings.png`
- `desktop-quick-start.gif`
- `desktop-overview.mp4`

Reference them from docs as `/desktop/<filename>`.

Capture guidance:

- Prefer 1440px-wide desktop screenshots unless a smaller crop makes the UI clearer.
- Do not include real API keys, tokens, private chat text, or local file paths that should not be public.
- Use `.png` for static UI, `.gif` for short flows, and `.mp4` for longer release/demo videos.

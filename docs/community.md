# Community

xopc grows through public, respectful collaboration. Choose the channel that matches what you want to do so useful answers remain easy to find.

| Channel | Use it for |
| --- | --- |
| [GitHub Discussions](https://github.com/xopcai/xopc/discussions) | Questions, ideas, architecture discussions, and knowledge worth keeping searchable |
| [Discord](https://discord.gg/ZmK8FzZHG) | Real-time conversation, project showcases, and contributor coordination |
| [WeChat community](#wechat) | Chinese-language discussion, onboarding help, and release updates |
| [GitHub Issues](https://github.com/xopcai/xopc/issues) | Reproducible bugs and actionable feature requests |

## Before posting

- Search the documentation and existing Discussions first.
- Remove API keys, access tokens, personal data, and private configuration before sharing logs or screenshots.
- Move confirmed bugs from chat to an Issue with reproduction steps.
- Summarize decisions and reusable solutions from Discord or WeChat back into a Discussion, Issue, pull request, or documentation page.
- Follow the [Code of Conduct](https://github.com/xopcai/xopc/blob/main/CODE_OF_CONDUCT.md) in every official xopc space.

## Discord

The Discord server is the fastest place for informal conversation. Start in `#welcome-and-rules`, use `#help` for setup questions, `#showcase` for things you built, and `#contributors` for repository work. Important technical conclusions should still be recorded on GitHub.

[Join the xopc Discord community](https://discord.gg/ZmK8FzZHG)

## Security and private reports

Do not post vulnerabilities, credentials, or sensitive personal information in public channels. Report security vulnerabilities through [GitHub Security Advisories](https://github.com/xopcai/xopc/security/advisories/new). For a private Code of Conduct report, email [lyxopc.ai@gmail.com](mailto:lyxopc.ai@gmail.com).

Community channels are maintained by volunteers. Responses are best-effort and there is no guaranteed support response time.

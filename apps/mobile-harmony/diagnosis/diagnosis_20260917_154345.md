## 根因分析

### 候选根因 #1（置信度：high）

测试代码机械替换弃用 API 时，将 TestKit 返回的旧 Context wrapper 传给新的 Stage-only application.createModuleContext。框架参数校验拒绝该对象，触发行为位于测试适配代码，不能归因于 Gateway/TLS/生产配对。

**证据：**

- 新调用编译成功，但运行时在读取证书前失败。
- SDK 区分 TestKit Context 与 Stage 应用 Context，官方文档明确新 API 的模型限制。
- 恢复 TestKit Context 自带的 createModuleContext 后，同一设备上 3 项安全测试和 TLS 配对测试全部通过。

**证据来源：**

- `code`: `entry/src/ohosTest/ets/test/Pairing.test.ets`
- `documentation`: 本机 API 26 SDK 声明与上述华为官方文档

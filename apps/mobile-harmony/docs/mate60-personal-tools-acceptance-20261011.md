## 观察与边界

- 首次联系人测试在系统选择器内等待超过约 120 秒，返回 `TOOL_TIMEOUT`。自动化未成功完成预定拒绝动作，此项不能算作拒绝测试；随后独立复测得到明确 `USER_DENIED`。Agent 首次自述“已拒绝”缺少现场依据，报告采用实际 UI 和工具结果。
- Agent 首次把日历窗口错误换算成上海时间 08:00，底层毫秒参数及系统确认窗口正确；在后续消息中已纠正。此为模型文字解释问题，不是日历工具范围错误。
- 当前日历结果仅覆盖 xopc 应用可访问日程。空结果不能证明用户全部日历没有安排，本次也没有验证非空事件、重复事件、全天事件和 50 条截断。
- 文件完整成功路径通过；联系人选定字段成功回传、照片选取上传、实际拍摄上传尚未完成真机验收。图库和相机取消通过不能代替图片内容及 EXIF 清理验收。
- 未覆盖 OS 拒绝及永久拒绝、锁屏、系统选择器内主动停止后的迟到结果、跨设备权限隔离与长时间重连。Android、iOS 真机仍需独立验收。
- 退后台时工具已经终止，回前台先出现“连接中断 · 正在恢复”，随后显示通用“请重试”提示；点击刷新后提示消失，没有重新执行文件调用。Gateway 输入队列为空、该轮 outcome 为 `partial`，九项工具仍已注册。取消后的聊天错误文案及自动恢复体验仍需改进，不能据此宣布所有断线恢复场景通过。

本次验证完成后删除手机上的自建下载测试文件；已进入验收会话的文本结果按既有聊天历史保留。

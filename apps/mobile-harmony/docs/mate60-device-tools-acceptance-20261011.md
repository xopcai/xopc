## 本次修复与验证

将不可主动关闭的 showDialog 改为 UIContext + ComponentContent；取消、超时、后台退出会结算拒绝并关闭本地确认，迟到的打开完成也会关闭。关闭后释放组件。OS 自有权限弹窗仍由系统管理，取消后的回调不能进入采样路径。新增 realtime 连接阶段诊断，仅记录阶段与受限错误码，不记录凭证或坐标。

鸿蒙 debug HAP 编译通过；相关 4 文件 19 项测试通过，取消测试增加确认关闭断言。git diff --check 通过。取消和后台的真实证据来自安装的修复版本；最终版本增加组件释放后再次覆盖安装，并重新验证调用确认与取消自动关闭。

# Ticket listing application
listTickets(tickets, options) returns original ticket objects in input order. Existing status, exclusive after cursor (JavaScript code-unit id comparison), default limit 20, zero limit, and RangeError validation must stay compatible. Add optional labels: when provided it must be an array of strings; every listed label must be present in ticket.labels (missing ticket labels count as empty). Empty requested labels match all tickets. Invalid labels raise TypeError. Combine labels with status BEFORE cursor and limit. Do not mutate input tickets, label arrays or options. Run node --test test/*.test.mjs.

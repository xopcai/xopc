# Define-goal objective rubric

Review a goal against these questions before creating it:

1. What will be observably true at completion?
2. Which artifact, service, workflow, or user experience is in scope?
3. What exact evidence proves success?
4. Which boundary prevents unrelated work from expanding the goal?
5. What missing information should stop execution and trigger a question?

Use binary evidence when possible: a test passes, an artifact exists, a report contains a decision,
or a reviewer accepts named criteria.

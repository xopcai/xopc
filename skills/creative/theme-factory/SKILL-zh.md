# Theme Factory Skill（主题工厂技能）

本技能提供一组精心策划的专业字体和颜色主题，每个主题都包含精心挑选的调色板和字体搭配。选择主题后，可将其应用于任何制品。

## 目的

将一致、专业的样式应用于演示幻灯片。每个主题包括：
- 包含十六进制颜色代码的协调调色板
- 标题和正文文字的互补字体搭配
- 适合不同上下文和受众的独特视觉风格

## 使用说明

要将样式应用于幻灯片或其他制品：

1. **展示主题预览**：展示 `theme-showcase.pdf` 文件，让用户直观查看所有可用主题。不要对其进行任何修改；仅展示文件供查看。
2. **询问用户选择**：询问用户要为幻灯片应用哪个主题
3. **等待选择**：获得关于选定主题的明确确认
4. **应用主题**：一旦选定了主题，将选定主题的颜色和字体应用到幻灯片/制品中

## 可用主题

以下 10 个主题可供使用，每个主题在 `theme-showcase.pdf` 中有展示：

1. **海洋深处（Ocean Depths）** - 专业且平静的海洋主题
2. **日落大道（Sunset Boulevard）** - 温暖而充满活力的日落色彩
3. **森林冠层（Forest Canopy）** - 自然质朴的大地色调
4. **现代极简（Modern Minimalist）** - 干净现代的灰度风格
5. **黄金时刻（Golden Hour）** - 丰富温暖的秋日调色板
6. **北极冰霜（Arctic Frost）** - 凉爽清新的冬季主题
7. **沙漠玫瑰（Desert Rose）** - 柔和精致的灰粉色系
8. **科技革新（Tech Innovation）** - 大胆现代的科技审美
9. **植物花园（Botanical Garden）** - 清新自然的园艺色彩
10. **午夜星系（Midnight Galaxy）** - 戏剧性的宇宙深色系

## 主题详情

每个主题在 `themes/` 目录中有完整定义，包括：
- 包含十六进制颜色代码的协调调色板
- 标题和正文文字的互补字体搭配
- 适合不同上下文和受众的独特视觉风格

## 应用流程

选定偏好的主题后：
1. 从 `themes/` 目录读取对应的主题文件
2. 在整个幻灯片中一致地应用指定的颜色和字体
3. 确保适当的对比度和可读性
4. 在所有幻灯片中保持主题的视觉风格

## 创建自己的主题

在没有现有主题适合某个制品的情况下，创建自定义主题。根据提供的输入，生成一个类似上述主题的新主题。给主题起一个类似的名称，描述该字体/颜色组合所代表的风格。使用提供的任何基本描述来选择适当的颜色/字体。生成主题后，展示给用户审阅和确认。之后，按照上述方法应用主题。
